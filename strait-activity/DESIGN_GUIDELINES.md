# 介面規則

實用查詢工具，省略英文眉標、口號、裝飾文案及無資訊意義的圖案。必要文字僅說明操作、單位、統計基準、資料來源與限制。

配色（2026-11-16 改版）：暖白底 #fbf8f1、深藍墨色 #16213e（頁首與觀測儀舞台）；共機寶藍 #2f5bea、逾越中線珊瑚紅 #e8364f、艦艇／具名軍演青色 #0b8a91；判讀四級 偏少綠 #2f9e44／一般藍／偏多橘 #f08c00／極高紅。年曆用跨色相色階：米 #f1eee4 → 黃 #ffe08a → 橘 #ffb347 → 橙紅 #ff7a45 → 洋紅 #e0336b → 紫 #6b1f8f，色階只代表數量，非風險。觀測儀標記：共機天藍 #8fb8ff、艦艇琥珀 #ffc94d。系統無襯線與等寬數字，無外部字體或 icon CDN，所有操作圖示採內嵌 SVG。

按鈕至少 44px 高，手機年曆格約 40px，橫向滑動保留可點按面積；表格與年曆各自溢出捲動，不將整頁撐寬。手機圖表使用下方資料表提供精確選日。

可讀正文允許選字；操作列、按鈕、年曆禁止意外選取。未採用原生 select、radio、checkbox、confirm 或 alert；選擇使用有 aria-pressed 的按鈕群，詳情使用自行設計的 dialog。日期為文字輸入，重播使用可觸控與鍵盤操作的 range。

Focus visible 以陶土外框；語意化導覽、主內容、標題、資料表與狀態提示。避免只用顏色，日期格可取得完整 accessible name。動態採低幅度慢速呼吸；prefers-reduced-motion 關閉動畫，Page Visibility 暫停播放。全螢幕保留資料、日期及署名。

首頁先用一句白話判讀（偏少／一般／偏多／極高，依過去 365 日分布），並說明今天在一年分布中的位置；接著是自動產生的重點卡與「30 秒看懂」名詞說明，詳細數字與圖表放在後面。具名軍演以陶土色標在走勢圖上並有大事記卡片，背景文字須為公開報導可查證的事實、不推論意圖。分級文字只描述數量，旁邊必須註明不代表衝突風險。
