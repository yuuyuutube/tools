# BEEP LAB

**Tiny sounds, endless possibilities.**

一個以 Nokia 3310 時代的單音編曲樂趣為起點，延伸到音樂明信片、遊戲與生成藝術的前端創作系列。

## 開發原則

1. **創作成就感優先**：核心價值是用簡單操作還原腦中的旋律，再分享與轉化。
2. **每次只完成一個可玩的垂直切片**，不要同時產出八個空殼網站。
3. **史實與現代擴充清楚分離**：Classic 模式以可查證的 Nokia 3310 Composer 行為為準；新功能只進 Studio 或其他作品。
4. **美學品質高，但先驗證互動**：每個階段保有可操作、可測試的版本。
5. **不要求後端**：第一階段完全在瀏覽器運作，資料預設留在本機。

### 操作

- 點畫面數字鍵，或使用實體鍵盤 `1–7` 輸入 C–B；新音符立即試聽。iPhone 需首次點擊音符／播放來啟用音訊，並確認媒體音量。
- `8` 縮短、`9` 延長游標左方事件。`0` 插入休止符，`*` 設定下一個音符八度，`#` 切換左方音符升音（E／B 除外）。
- 長按 `1–7` 450ms 建立一個附點音；亦可用「附點」按鈕或 `.` 切換左方音符附點。放開不會額外建立第二音。
- 左右箭頭移動插入點、Backspace 左刪除；點某個音符將游標放到它右方。新輸入永遠插入，橘框音符接受時值／升音／附點修改。
- 播放／停止，或空白鍵切換；Esc 停止。編輯與離開頁面會停止，快速重播不保留前次音源。可靜音，BPM 範圍 40–240。
- 先輸入音符，再點曲名命名，例如 `My First Beep`，按「儲存作品」。刷新後從「你的聲音收藏」載入。刪除會先確認。
- 「載入示範」提供自製 `Little signals`；「新旋律」開新作品。尚未儲存時切換會先確認。

這是現代復刻，並非原機完全模擬。長按門檻、八度序列、音高映射、音色、儲存容量、游標選取及附點便利按鈕等決策請見 [DECISIONS.md](docs/DECISIONS.md)。

### Studio 格點預覽與時值拖曳

滑鼠移到既有音符的欄位會顯示虛線框及目標音高，點擊才套用。選取音符後，拖曳右緣把手可調時值，放開才套用並試聽；Esc、手勢取消、失焦會保留原值。時值吸附 1、1/2、1/4、1/8、1/16、1/32，保留原附點及音高；每次完成拖曳只占一次復原。手機用把手拖曳，圖內其他位置仍可捲動。把手亦可用左右鍵調整，或使用原時值選單。

### 下一音欄、固定休止列與音符交換

Studio 最右側「下一個音符」欄支援滑鼠虛線預覽，點擊以四分音符加到旋律結尾。休止列固定在音高區下方、高度 54px；既有欄位點擊可改為休止符，最後的「新增休止」按鈕可在結尾加入休止。上下捲動音高區不會移動休止列，左右捲動則會與音符欄位同步。

拖曳音塊本體到另一欄，可交換兩個完整事件（含休止符、時值、附點）；右側把手仍只改時值。放開才套用，Esc／手勢取消保留原值。鍵盤可選取音塊後按 Alt＋左右鍵交換相鄰位置。每次交換或新增都可一次復原。

## M1：BEEP CARD 分享旋律

- Composer 的「分享」產生目前旋律的快照網址，可複製、預覽；支援 Web Share 時另有「系統分享」。複製不可用時可選取網址手動複製。
- 朋友開啟卡片可看曲名、音符、BPM 與長度，點播放才啟動聲音；支援停止、重播、靜音及音訊啟用重試。
- 「編輯這首」帶回 Composer 並建立新的本機 ID；自行按儲存才加入收藏，不覆蓋舊作品。
- 網址格式 `?view=card#melody=1.…`，包含曲名、BPM、音符，不包含本機 ID、時間戳或收藏。不使用登入、後端或雲端儲存；取得完整網址的人都能讀取旋律。
- 網址最多 2048 字元；512 個事件及 60 字中文曲名已測試可容納。無效、截斷或未支援版本顯示錯誤並可開啟編曲器。
- 分享後的編輯不更新既有連結，需重新產生分享。通訊軟體預覽沿用共用 OG 圖，無法動態呈現每首曲名。

### 旋律織紋

BEEP CARD 頂部會依旋律自動生成無文字的 SVG 幾何織紋。同一樂譜與 BPM 對應同一圖案與配色，不受曲名影響；播放時對應織帶會輕微亮起，停止後恢復。可由圖案選單切換風格，不需要額外設定。

### 聲音星圖與圖案切換

卡片的「圖案」選單只切換具體風格；隨機驚喜移到分享視窗。`art=weave`／`art=stars` 固定風格；`art=random` 開啟後抽選並把結果寫回網址，因此再分享時會保留同一風格。星圖以音高決定高度、累積時值決定位置、時值決定星點大小，休止中斷連線；播放時對應星點會亮起。

### 節奏構成

`art=rhythm` 或圖案選單選取「節奏構成」。紙色底上以直立色塊、圓形留白、細線及節拍條構成抽象海報，時值影響寬度、音高影響高度，附點形成底部小色點；休止保留空隙。隨機驚喜現在涵蓋三種風格，分享與編輯均保留選擇。

### 聲音地形

`art=terrain` 或圖案選單選取「聲音地形」。音高構成山脊高度，長音形成平台，休止切開岩層形成斷谷。霧藍、苔綠與岩粉的五層地景，以細等高線呈現；播放只點亮目前音符對應的山脊片段。隨機驚喜包含地形在內的四種風格。

### 旋律活版

`art=letterpress` 或圖案選單選取「旋律活版」。七種音名對應抽象幾何印章，八度決定方向，長短音決定大小與排列，休止保留空白，附點疊加第三層色印。兩層油墨以輕微錯位和 multiply 套色，搭配固定紙紋；沒有文字。同一樂譜始終產生同一幅圖。隨機驚喜包含五種風格。

### 音符標本

`art=specimen` 或圖案選單選取「音符標本」。休止分開枝束，每束最多八片葉；時值影響枝長與葉片間距，音名決定圓葉／細葉／裂葉，八度決定苔綠、灰藍或乾燥花色。附點會在葉尖長出小花苞。播放時對應葉片輕微亮起。隨機驚喜包含六種風格。

### 聲音窗景

`art=windows` 或圖案選單選取「聲音窗景」。旋律依長度構成一至三扇拱窗，時值分割玻璃高度，音高決定玻璃色彩；休止留下清透窗格，附點形成小圓玻璃。細窗框與斜向光帶呈現柔和透光感，播放時對應窗格會亮起。隨機驚喜包含全部七種風格。

### 分享圖案設定

卡片的圖案選單僅列七種具體風格。分享視窗新增「分享圖案」：預設保留目前圖案（Composer 沒有指定風格時使用旋律織紋），也可選「隨機驚喜」。抽選後顯示本次風格，支援重新抽選不同款式；預覽、複製與系統分享使用同一個已固定風格的網址，不改目前卡片。關閉再開啟會回到目前圖案。舊 art=random 網址仍相容，但新分享不產生隨機網址。

## M2.1：POCKET MUSIC BOX

開啟 `?view=box`，或從 Composer／BEEP CARD 的「音樂盒」入口進入。直接讀取既有本機收藏，不須遷移或重新儲存。

- 方形生成藝術封面依旋律穩定選出；點封面開啟分享卡片。封面延遲載入，避免一次繪製所有長旋律。
- 每首可試聽／停止、編輯原作品、分享及下載 WAV；切換試聽不疊音，離頁或失焦停止。
- 從音樂盒編輯保留原本 ID，儲存更新同一首。從分享卡片改編仍建立新 ID，兩個流程獨立。
- WAV 為 22.05kHz、單聲道、16-bit PCM，使用相同音高及節奏映射與單音方波近似音色。包含休止與附點，長度依 BPM 計算；背景 Worker 產生，不需要即時錄音或播放權限。
- 目前 WAV 最長 3 分鐘；超過會提示縮短旋律或提高速度，不會截斷。檔名使用曲名。手機可能顯示音訊預覽或下載選單，請依瀏覽器儲存；不提供自動設定系統鈴聲。
- 收藏仍僅存在同一瀏覽器，其他裝置不會同步。其他分頁儲存後音樂盒會更新。
- 這個小里程碑只包含瀏覽、試聽與 WAV；標籤、搜尋及更多整理功能尚未實作。

## M2.2：收藏標籤與搜尋

- 音樂盒每張作品卡片的「標籤」可新增、移除自訂標籤；每首最多 8 個、每個 20 字。可按 Enter 加入，或選擇現有標籤／建議標籤。按「儲存標籤」才保存；取消或 Esc 不寫入。
- 上方可依曲名或標籤搜尋，支援大小寫及全形／半形比對，多個搜尋詞需全部符合。標籤篩選可與搜尋同時使用，另有「未分類」入口；無結果時可一鍵清除篩選。
- 標籤以作品 ID 對應，另存本機版本化 metadata；不改 Melody／收藏 schema，不加入分享網址或 WAV。編輯原作品保留標籤，分享匯入的新作品不繼承原本的本機標籤。
- 多分頁更新會同步收藏畫面；同一首在舊視窗編輯時如遇衝突，會保留草稿並提示重開，不覆蓋新標籤。格式損壞時保留原始資料、暫停標籤寫入，其他旋律功能仍可用。

### Studio 專注模式

Studio 按 Header 的展開圖示後，只顯示 editor-panel，保留音高圖與編輯／播放控制，不再強制切回 Classic。html／body 不捲動，音高圖內仍可捲動。直向充分使用剩餘高度，短橫向將時值與新增控制並排。退出或按 Esc 保留 Studio 與歌曲；拖曳時 Esc 優先取消拖曳。Classic 專注模式仍顯示編輯器與數字鍵盤。

## M3.1：鈴聲考古第一關

開啟 `?view=archaeology`，或點頁尾導覽的「鈴聲考古」。第一個小里程碑提供一關完整可玩的音高修復，五關版本尚未完成。

1. **先聽原曲**：播放正確版本，再按「聽好了，下一步」。
2. **再聽錯誤版**：播放你的起始樂譜，比較差異，再按「開始修復」。
3. **修復樂譜**：點音符序號，調整該音的音高；可重聽原曲／自己的版本，或取用三層提示。首關只需改音高，時值／附點收在「節奏設定」。
4. **送出答案**：先試聽確認，再送出；錯誤時保留版本並引導返回修復。
5. **通關**：顯示明確完成畫面，可重玩、分享或帶回 Composer。現在只有第一關，不顯示無法使用的下一關按鈕。

步驟列可回到已開放步驟；播放成功後才啟用對應下一步，由使用者確認聽好了再前進。修改音符會清除舊通關狀態。支援復原／重做、左右鍵選取、Ctrl／⌘ Z 與 Shift Z；「還原起始樂譜」可復原，「再玩一次」則重新開始五步。離頁／失焦停止聲音，不自動播放。

這一關的進度暫存於目前頁面，不會覆蓋收藏，也沒有排行榜、計時或登入。

## 一個入口逛所有頁面

分享 `https://yuuyuutube.github.io/tools/beep-lab/` 即可。每個頁面的頁尾都有「編曲器／分享卡片／音樂盒／鈴聲考古」共用導覽；分享卡片入口提供 Little signals 示範，不需先有收藏或分享網址。任一張分享卡片網址也能作為朋友的入口。

導覽採同分頁切換；編曲器未儲存變更沿用瀏覽器離頁提醒。專注模式隱藏導覽，退出後恢復。朋友的音樂盒只顯示各自瀏覽器收藏，不會因為拿到入口網址就讀到分享者的本機作品；單曲仍透過「分享」傳送。
