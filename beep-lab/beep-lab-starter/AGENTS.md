# Codex Project Instructions — BEEP LAB

- 使用繁體中文回報；程式命名採英文，註解以必要且精準為原則。
- 優先閱讀 docs/PRODUCT_SPEC.md、docs/COMPOSER_REFERENCE.md、docs/ARCHITECTURE.md、docs/ROADMAP.md。
- **只處理當前指定 milestone**；不要擅自實作未來七個 app，也不要為其建立大量空白 UI。
- 尊重已確認的 Nokia 操作規則；原始資料未確認之處必須標為假設，不能聲稱 100% 原版還原。
- `Classic` 為歷史操作體驗；現代便利功能只能放 `Studio` 或明確標為擴充。
- 音樂資料模型必須與 UI 解耦。禁止以畫面文字作為唯一的旋律儲存格式。
- 不使用付費 API、不要求登入、不使用後端，除非使用者另行批准。
- 優先支援手機 Safari / Chrome，以及桌機鍵盤輸入。
- Web Audio 應由用戶手勢啟用；排程、停止、快速重播不可出現重疊或殘留聲音。
- 注意可及性：觸控目標、語意按鈕、焦點、鍵盤控制、動態偏好設定、狀態提示。
- 請為音符格式、輸入編輯、儲存還原、播放時間計算建立自動化測試。
- 不要自行 git push。若使用者未明確要求，也不要自行 commit。
- 每個里程碑完成時：執行測試、build、能執行則用瀏覽器實測，提供檔案摘要、操作方法、測試結果與待確認事項。不能實測要直說。
- 不要把 Demo 做成只有靜態畫面；可播放、可編輯、可儲存優先。

## UI 偏好（使用者指定）

- 產品定位為趣味實用工具，畫面只保留操作、狀態、作品資料與必要說明；不加入作品集標語、實驗編號、裝飾性英文或重複品牌文字。
- 所有圖示使用 SVG（自製或 MDI），不使用 emoji 或 Unicode 字形充當 icon。音符記法及數字鍵標籤不受此限。
- favicon／OG 圖沿用簡潔圖形；圖內不加入裝飾文案。
