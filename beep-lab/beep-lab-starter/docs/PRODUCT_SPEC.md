# Product Specification — BEEP COMPOSER

## 1. 願景

**BEEP LAB: Tiny sounds, endless possibilities.**

使用者最享受的是把耳熟能詳的歌曲逐音還原，然後收藏、分享；懷舊按鍵與 Nokia 綠色螢幕是情感入口，不是唯一價值。打造可隨時在手機打開、10 秒內輸入第一個音符的單音創作工具。

## 2. 使用者主要流程

1. 打開頁面看到「Composer」與清楚的播放／鍵盤入口。
2. 點選任一音符鍵以啟用 Web Audio，立即聽到聲音。
3. 用 1–7 加音符、8/9 改時值、0 休止符、* 八度、# 升音。
4. 在小螢幕觀看旋律代碼，透過方向鍵移動與刪除。
5. Play → Stop → 改編 → Play。
6. Save 命名、可在重開頁面後 Load。

## 3. M0.1 功能規範：本次 Codex 應實作

### 必做

- 專案可在本機啟動（以 package scripts 說明），手機寬度能完整操作。
- Classic 風格的**功能性** composer 畫面（先不需 1:1 美術復刻）。
- 螢幕顯示時值、附點、升記號、音名與八度，例如 `4c2`、`8.#f2`、`4-`。
- 可使用**畫面數字鍵**與**桌機實體鍵盤**操作。
- 可以插入音符／休止符，修改選取音符／休止符的時值，切換八度，改升半音。
- 按鈕清楚支援左右移動游標、刪除、播放、停止、BPM 調整。
- 至少一首示範旋律供使用者載入，避免首次進入只有空畫面。
- 音符按下即時單音預覽；整首播放時有目前播放位置提示。
- 使用者可命名歌曲、儲存、載入、刪除（刪除需確認）。
- 資料儲存於 localStorage，使用 versioned schema 和驗證。
- 對 iOS Safari 的音訊啟動限制有友善的提示與處理。
- 自動化測試涵蓋資料模型、音符編輯與持久化核心；執行 build 確認成功。
- 在文件標示哪些操作為「已核實原版」與「暫定現代行為」。

### 實作時自行選擇、寫入 DECISIONS.md

- 音符輸入游標是在插入點或既有音符之上；左右移動後按音符究竟插入或覆寫。
- 長按音符鍵加附點如何在觸控上可靠觸發、與短按互不衝突。
- 時值輪替邊界、八度循環次序、初始八度、可接受 BPM 範圍。
- 螢幕排版、超長旋律捲動與播放游標。

### 不包含在 M0.1

- 完整 Nokia 手機外殼 1:1 還原。
- Studio 視覺化編輯器、Undo/Redo（留 M0.3）。
- WAV/MIDI 匯出、分享網址、RTTTL、匯入音樂檔、自動抓歌轉譜。
- 生成花園、明信片、遊戲、排行榜、雲端同步。
- 任何付費 API、伺服器端資料庫、登入。

## 4. 視覺與互動方向

### Classic 風格（M0.1 先打底；M0.2 打磨）

- 參考古早 LCD 的低解析度與微對比，但所有文字在手機上仍清晰可讀。
- 外觀應是「致敬老式數位設備的當代設計」，不是直接複製 Nokia 商標與工業設計素材。
- 用明確的編輯焦點／游標、按鍵按下狀態與播放器狀態讓使用者知道發生什麼事。
- 音符間留足辨識間距；不強制使用無障礙性差的真低解析縮放文字。
- 美學目標：克制、具時代感、細節考究，避開廉價擬物陰影與雜亂霓虹。

### Studio Mode（M0.3 才做）

- 圖形化音高／時值編輯，保留 Classic 的節奏與邏輯。
- 需要支援 Undo/Redo、易懂的修改方式；共用同一 Melody model。

## 5. MVP 驗收情境（由 Codex 自測 + 回報）

A. 開啟頁面，點 `1 2 3 4 5`，畫面有五個音且各有預覽聲。

B. 選取一個音，按 8 / 9，顯示和播放長度變化正確；長按音符鍵可建立附點音（若選擇等價觸控操作需明確說明）。

C. 插入 0 休止符、* 切換八度、# 升音；E/B 不可升半音且有一致提示。

D. 按 Play 可依 BPM 播放、Stop 立即安靜、再次 Play 不疊音。

E. 儲存 `My First Beep`，刷新頁面後重新載入，音符、時值、BPM、標題完全一致。

F. 測手機寬度 375px，不水平溢出，主操作按鈕不誤觸；桌機實體鍵盤可操作。

G. 對非法 localStorage 資料有提示或自動恢復，不當機、不清空所有其他有效歌曲。

H. 若無法實際在 Safari / Chrome 驗證，明確列出尚未手動驗證項，不得宣稱全部通過。

## 6. 完成定義

- 用戶能在手機上重現「一步步編出旋律」的體驗。
- 無阻斷性 Bug；測試與 build 成功。
- 使用文件清楚；新接手 Agent 可知道現況。
- 沒有擅自實作後續作品。
