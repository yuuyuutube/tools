# BEEP LAB Roadmap

> 排序依賴關係：**完成旋律 → 收藏／分享 → 聽音遊戲 → 自由委託 → 生成藝術**。時間只是彈性估計，不是交付承諾。

| 里程碑 | 作品 | 依賴 | 完成定義 |
|---|---|---|---|
| M0.1 | BEEP COMPOSER — Functional | 無 | 手機可按鍵編音、調時值、播放、停止、存取 |
| M0.2 | Composer — Classic Polish | M0.1 | 綠色 LCD 視覺、按鍵回饋、忠於核實的規則 |
| M0.3 | Composer — Studio Mode | M0.1 | 視覺化編輯、Undo/Redo、與 Classic 共用歌曲資料 |
| M1 | BEEP CARD（已實作） | M0.1 | 用同一歌曲資料產生能分享、播放的卡片；不自動播放 |
| M2 | POCKET MUSIC BOX（核心功能已實作） | M0.1 | 收藏、標籤、試聽、WAV 匯出；不同音色可後加 |
| M3 | RINGTONE ARCHAEOLOGY | M0.1 | 5 關可完整通關，聽音修復與明確判定 |
| M4 | BEEP BEEP FACTORY | M3 核心可選 | 3 個完整委託、可解釋的規則評分、荒謬評語 |
| M5 | PLEASE HOLD | M4 共用委託概念 | 15–30 分鐘可通關的互動敘事小品 |
| M6 | BEEP GARDEN | M0.1 | 旋律決定植物形態，可播放並匯出靜態圖 |
| M7 | 12 KEYS, INFINITE WORLDS | M0.1 | 同旋律生成動態平面構成，可錄製／匯出（平台允許時） |

## 工作方式

- 先只做 **M0.1**，驗收後再開 M0.2，不要一次預生成 M0–M7。
- 每個里程碑先提出 1 個「10 分鐘內能玩到」的最小互動，再逐步打磨。
- 所有作品保留各自美術語言：不做八個外觀相同的模板站。
- 每個里程碑都有 Demo、測試、操作說明及未完成項目。
- M1 的網址分享先評估 URL 編碼的長度與隱私，避免大型歌曲網址超限；不把個人資料放入 URL。
- M2 的 WAV 匯出要在各瀏覽器測試；iOS 不保證網站能直接設定鈴聲。
- M6 / M7 的美術先定 art direction 再選 Canvas/p5/Shader，避免「能動但不好看」。

## 建議週次（非硬性）

- 第 1～2 週：M0.1–M0.3（核心精緻度最重要）
- 第 3 週：M1–M2
- 第 4～5 週：M3–M5
- 第 6～8 週：M6–M7

用作品完成品質，而非週次，決定是否進入下一階段。
