# Nokia 3310 Composer — 史實參考與驗證狀態

## 參考版本

目標是 **2000 年代初期的 Nokia 3310 原版 Composer（Menu 5-4）**，不是 2017 年後復刻機、其他型號，或 RTTTL 編碼格式本身。

## 已由 Nokia 3310 使用手冊文字核實

- 入口：**Tones > Composer (Menu 5-4)**。
- 用數字鍵輸入音符：`1=C`, `2=D`, `3=E`, `4=F`, `5=G`, `6=A`, `7=B`。
- 新音符輸入時會發聲（若手機音效未關閉）。
- `8` 縮短音符／休止符；`9` 延長音符／休止符；預設時值 `1/4`。
- **長按音符鍵**使音符時值增加一半（附點），如 `8.a`；這不是簡單地「按 9」。
- `0` 插入休止符，時值沿用前一音符／休止符；無前一個時預設 `1/4`；螢幕記號為 `-`。
- `*` 設定新音符的八度（畫面有 `e1` 一類標示）。
- `#` 將音符升半音，**E、B 不適用**。
- 方向鍵左右移動游標；Clear 刪除游標左方音符或休止符。
- Options 包含 **Play、Save、Tempo、Clear screen、Exit**。
- 範例格式：`16.a2 16d2 16#f2 16a1 16d2 16#f2 8a2 1- 8-`。

## 需進一步確認，不可擅自宣稱完全還原

1. 3310 不同市場／韌體的實際 LCD 版面、光標呈現、功能鍵文案。
2. 時值輪替的完整邊界與循環規則，以及附點和修改時值的交互。
3. `*` 八度循環的完整序列、插入與修改既有音符時的精確行為。
4. 輸入法的刪除／覆寫／插入及選取邏輯；手冊文字只能確定部分行為。
5. 原機的真實波形、音量包絡、音高映射與揚聲器特性。
6. 原版最多可輸入音符數與可儲存鈴聲數；不同年份／地區可能有差異。

以上若無可信證據，v0.1 應提供清楚、穩定且可測試的近似行為，並在 README 或產品內標為「現代復刻」，不要假裝是韌體級模擬器。

## 重要術語

- 畫面上的 `4c2`：四分音符、C 音、第二八度（名稱採原 Nokia 編碼慣例）。
- `8.#f2`：附點八分音符、升 F、第二八度。
- `4-`：四分休止符。
- **Composer 螢幕字串 ≠ RTTTL**。未來若支援 RTTTL，必須另寫 parser/serializer 與明確轉換規則。
- 原機八度標籤 `1/2/3` 與科學音高記號 `C4` 不能直接混同，播放映射要獨立定義且測試。
