# M0.1 實作決策

本作品是 **現代復刻**，並非 Nokia 韌體或聲學模擬器。只實作 Composer，無 Studio、後端、登入或其他七個作品。

## 已核實與參考來源

以專案 COMPOSER_REFERENCE.md 為基準，本次另讀 2001 Issue 3 手冊轉錄的 Composer 段落（印刷頁 65–67），並交叉檢視原廠 2004 Issue 5 PDF（印刷頁 76–78）。後者是另一版手冊，不能據此推定所有韌體相同。

- [2001 手冊轉錄](https://www.somanuals.com/html/23/Nokia-3310-User-Manual.html)
- [原廠手冊 PDF，Issue 5](https://www.instructionsmanuals.com/sites/default/files/2019-05/Nokia-3310-en.pdf)
- helpdoc 來源本次回應 403，未用它補推任何新行為。

核實行為：1–7 = C–B、輸入試聽、預設四分、8 縮短／9 延長、長按音符增加一半長度、0 插入休止並沿用前一時值、* 設定新音符八度、# 升音且排除 E/B、左右游標、Clear 左刪除，以及播放／命名儲存／Tempo。畫面記法使用 `4c2`、`8.#f2`、`4-`。

## 暫定現代規則（不聲稱已由原機證實）

| 項目 | M0.1 決策與理由 |
| --- | --- |
| 技術 | TypeScript + Vite + 原生 DOM；沒有框架執行時，互動面小、易追蹤。Vitest 測試純邏輯及音訊生命週期；不引入 monorepo。 |
| 游標 | 插入點範圍 0…事件數；數字鍵永遠插入，8／9／#／附點修改游標左方事件。點音符選取它並放游標於右方。橘框與插入線同時表示焦點。 |
| 音符時值 | 時值為 1、2、4、8、16、32；8 往短、9 往長，邊界停住而不循環。新音符與休止沿用插入點左方分母，開頭為 4；新輸入不繼承附點或升音。 |
| 附點 | 單指 Pointer Events、pointer capture；按住 450ms 只輸入一次附點音，放開不重複。短按於放開時輸入；取消手勢、失焦、隱藏頁面或停止都取消待輸入。長按實體 1–7 用同一個計時流程並忽略 key repeat。另提供明確標示的「附點」按鈕與 `.` 快捷鍵（現代便利功能）。 |
| 八度 | 起始標籤 2，* 依 2→3→1→2 循環，只影響後續音符，不修改既有音。載入歌曲時 UI 八度重設為 2；它不是旋律資料。 |
| 升音 | # 切換左方音符 sharp；E、B 及休止保持原狀並提示。降音使用再按一次 #。 |
| BPM | 預設 120、整數 40–240。滑桿與數字欄同步；超界或非整數不改 canonical model。修改節奏會停止播放。 |
| 音高／音色 | Nokia 標籤 1、2、3 分別映射科學八度 4、5、6：c1 = C4 ≈ 261.626Hz、a1 = A4 = 440Hz。等律，方波，短 attack/release 與 0.13 預設主增益；不是原機揚聲器重建。 |
| 播放 | 用 AudioContext 時鐘＋25ms lookahead ticker、150ms 規劃窗；ticker 只補排程，不作節拍。rAF 對照音訊時鐘標示播放音符（含休止），背景停播。單事件依 BPM 算時長，尾端留短間隔。Stop 6ms 淡出、8ms 結束；重播起點在淡出之後。非同步 unlock 有世代號，Stop 後不復活舊播放。 |
| 超長旋律 | 現代實用上限 512 事件，非原機限制。LCD 自動換行、內部垂直捲動，編輯與播放各自標示並捲到當前事件；不移動整個頁面。 |
| 儲存 | canonical Melody schemaVersion 1，localStorage `beep-lab:library:v1` 另包 schemaVersion 1；UUID 辨認作品，重存覆寫同 id，新旋律／示範產生新 id。每次寫入前重新讀取，降低跨分頁誤覆蓋；不承諾並行原子寫入。歌曲標題 1–60 字元，顯示一律用 textContent。 |
| 壞資料 | 逐首驗證，單首壞資料／重複 id 略過，其他有效歌曲保留。整包非 JSON 或未知版本不覆寫原始資料，暫停寫入並提示。未來升版需先加顯式 migration，再接受舊版；目前不猜測未知 schema。 |
| 失敗／資料保護 | localStorage 讀寫例外顯示提示。新建／載入在未儲存時要求捨棄確認；刪收藏必須確認。刪除收藏仍保留編輯區內容，能再存回。刷新只恢復已儲存收藏，不提供未存草稿自動保存。 |
| 行動版與可及性 | 手機依序為 LCD／編輯／播放／數字鍵／BPM 與儲存；主操作至少 44px、數字鍵至少 60px。鍵盤焦點可見、狀態 aria-live、對話框焦點管理交給原生 dialog、尊重 reduced-motion。不攔截文字／數值輸入框的音符快捷鍵。 |
| 示範 | Little signals，專案自製短旋律，不取用官方鈴聲、字型、商標或音效。首頁空白可直接按音，提供明顯的載入示範按鈕。 |

## 暫未實作

Composer 文字 parser（只有 display formatter 及經驗證的 JSON parse/serialize）、Undo/Redo、RTTTL、音訊匯出、雲端、分享網址、其他七個作品。後續作品應讀取 music-core Melody，不能解析 UI DOM 當資料來源。

## M0.1 UI 修訂：工具優先

- 依使用者要求移除作品集式 hero、標語、作品編號、英文區塊眉題及頁尾；保留單一產品名稱、曲名、狀態、時長／八度、功能名稱、收藏及可展開說明。
- 圖示統一使用 `src/icons.ts` 自製 inline SVG；不使用 emoji 或 Unicode 字形當圖示。數字、`*`、`#` 與音符記法是輸入資料，不是 icon。
- 手機編曲仍使用頁面自製按鍵，旋律區非文字輸入框，不呼叫電話鍵盤。曲名使用一般文字鍵盤，BPM 明確提示 `inputmode="numeric"`。暫不增加原生／自製鍵盤切換，以免同一編曲器出現兩套不同操作規則。
- 原生 `inputmode="tel"` 可以提示顯示 0–9、*、#，但網站無法把作業系統鍵盤改成附有 C–B 標示的編曲器，也不能據此保證原生按鍵的按住／放開事件能觸發本工具的附點操作。這是保留自製鍵盤的互動設計判斷。[MDN inputmode](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Global_attributes/inputmode)
- favicon 使用相同的單音方波 SVG，提供 ICO／16px／32px PNG 與 180px Apple touch icon。OG 為 1200×630 的純圖形 PNG，附 SVG 原稿，不含任何文字。
- 所有資產可執行 `npm run assets` 重建（開發期使用 resvg；網站執行時不載入）。分享 meta 已加入；正式網域確定後，以 `SITE_URL=https://實際網域 npm run build` 產生絕對圖片 URL。沒有設定時保留同源路徑，不猜測部署網域、不宣稱已通過社群平台線上抓取驗證。

## 音訊重試與推版

- 保持預設可發聲、不在進站時自動播放。首次音符／播放手勢嘗試啟用 Web Audio。
- `resume()` 拒絕、回傳後仍 suspended，或 1500ms 未完成時，顯示「啟用聲音」SVG 按鈕。按下後停掉待播聲音並在新手勢內重試；成功收起入口，需再按音符／播放，不補播舊聲音。
- 手動靜音與瀏覽器阻擋分開處理：靜音時不顯示重試提示；取消靜音也會嘗試恢復 AudioContext。缺少 Web Audio 時顯示不支援提示，不提供無效重試入口。
- 音訊從 running 進入 suspended／interrupted 時停止原播放並提供恢復；舊請求延遲失敗不覆蓋新手勢的成功狀態。Stop 仍會阻止尚未完成的播放請求發聲。
- 依使用者本次明確授權提交及推送此工具。沿用現有 tools Git 靜態發佈方式，不建立 Sites 雲端專案。source 保留 `beep-lab-starter/`，`npm run release` 產出可直接服務的 `beep-lab/index.html`、assets 與圖示；只替換此工具生成的 assets 目錄。
- Vite 使用相對 base，支援 `/tools/beep-lab/` 子目錄；正式分享 URL 由 `.env.production` 提供，支援帶子路徑且以 `/` 結尾的 SITE_URL。正式站是否成功更新需另查 HTTP／部署狀態，不能以 push 成功代替上線驗證。

## 專注模式

Header 的 SVG 展開按鈕切換瀏覽器內的專注版面，不要求 Fullscreen API 權限。只保留 editor-panel 與 keypad-panel；退出按鈕放在 LCD 右上角，Esc 可退出並停止播放。退出還原頁面捲動位置與按鈕焦點，不更動旋律或收藏。

模式使用可視 viewport 高度與 safe-area；直向上下排列、橫向左右排列，鎖住整頁捲動，長旋律仍可在 LCD 內捲動但隱藏捲軸。手機版隱藏曲名輸入，避免原生鍵盤佔用編曲空間；曲名／速度／儲存可退出模式後操作。不宣稱隱藏手機瀏覽器自身的網址列或系統 UI。

## 選取音八度（現代擴充）

新增 LCD 內的「選取音八度」按鈕，作用於游標左方被選取的音符，依 1→2→3→1 循環，修改後試聽並沿用現有儲存流程。無選取音／休止符停用。音高類別、升音、附點與時值保持原值；UI「下一音」八度與 * 的歷史輸入規則保持獨立。這是使用者要求的現代擴充，並非宣稱原機有此按鈕。

## M0.3 Studio Mode

使用者已驗收目前 Classic 打磨，並授權進入下一階段。本次只新增 Studio 與 Undo／Redo，不實作其他七個作品。

- Classic／Studio 切換只改 UI，共用同一 EditorState／Melody、播放器、收藏與儲存 schema；沒有複製成第二首歌曲。
- Studio 音高圖包含三個 Nokia 標籤八度的 36 個半音及休止列。每個事件依順序占一欄，音塊寬度反映時值；短音欄額外保留觸控空間，因此橫向位置不是精準秒數時間軸。點音塊選取、點同欄其他格改音高／休止，亦可使用 44px 原生表單精確編輯音高、時值、附點。
- 圖形編輯保留原事件的節奏，不意外把舊 pitch／sharp／type 蓋回新音高。所有更新由 music-core 驗證，E/B 不建立無效升音。
- 事件選取、刪除與新增沿用 Classic 插入點。新增預設四分音，選取音高沿用目前音符，沒有音符時 C2；休止符不發聲。
- Undo／Redo 跨 Classic／Studio 共用，最多保留 100 個內容變更快照。游標移動、播放、模式切換與儲存不額外占歷史；載入歌曲／示範／新建會清空歷史。復原後的新編輯清除重做分支；連續曲名輸入／速度調整合併為一次，失焦或其他內容編輯分隔群組。
- 曲名、BPM 與事件一起還原；恢復到最後儲存內容時顯示已儲存。歷史不持久化，不影響 canonical schema。
- 鍵盤 Ctrl／⌘ Z 復原、Ctrl／⌘ Shift Z 或 Ctrl／⌘ Y 重做；文字／數值輸入框保留原生文字編輯快捷鍵。所有圖示為 SVG。
- 專注模式繼續提供 Classic 編曲鍵盤，退出恢復原模式。短螢幕隱藏歷史按鈕，避免壓縮音符與按鍵區；退出即可復原／重做。

## Studio hover 與 resize

滑鼠格點預覽使用不攔截指標的虛線框，顯示同欄待修改音高；移出、捲動或開始拖曳時收起，touch 不模擬 hover。只有選取音提供獨立 24×44px resize 按鈕，Pointer capture 追蹤；移動只改視覺預覽，放開以單次 updateSelected 提交。取消／Esc／失焦／頁面隱藏會恢復音塊與把手位置，沒有歷史紀錄。拖曳保留附點，吸附既有分母，不增加資料格式。極長音可用選單或鍵盤精確選擇，不實作任意秒數時值。

## 下一音與固定休止列／交換

下一音是獨立尾欄，不占 canonical event；點擊無論原游標位置皆 append 到歌曲結尾，預設 1/4、無附點，音高取點擊格。空旋律也可直接點格開始。既有列仍修改原事件。

休止符從第 37 個音高列改成圖下方 54px 獨立列，水平捲動跟隨音高區，垂直捲動獨立；休止時值仍能拖曳。音塊本體以水平移動超過 6px 啟動交換，觸控垂直移動仍可捲音高區。交換採 swap（不是搬移後推擠其他事件），整個事件一起換位；落在尾欄／區域外不交換。提交前不改資料，取消／失焦清除預覽。新增、交換及時值更新沿用單一歷史管理。

## 休止新增入口合併

移除獨立 rest-add，將下一音欄與固定休止列的交會格作為唯一尾端新增休止入口，使用語意 button、整格可點、hover／鍵盤 focus 顯示紅色虛線；Space／Enter 沿用原生按鈕啟動，不誤觸播放。既有事件欄仍可點擊轉休止。每個音符欄位在實際時值寬度外預留 16px，把手保留在該欄內，使新格與上方下一音欄對齊，且不與前一把手重疊。

## 四分音符時間格線

Studio 以四分音符 80px 的連續時間軸排列音符及休止符，移除欄位最小寬度與額外間距。背景格線從音符起點 42px 開始，休止列共用刻度；附點依 1.5 倍寬度顯示。縮放把手置於音塊右下側並限制在其時間範圍內，短音符可另外透過時值欄位或把手方向鍵精確調整。

## Studio 取消選取與下一音設定

Studio 選取與 Classic 插入游標分離：以獨立的暫時 UI 狀態保留 Classic 操作。點外部空白或 Esc 取消選取，互動控制項不會觸發取消。未選取時欄位設定下一音；已選取時修改既有音，兩者設定分開。新增欄與新增休止格寬度共用下一音的時值及附點。把手改為音塊右緣中央的透明兩直條，短音改單線，仍保留鍵盤及時值選單。

## Studio 十字定位高亮

Studio 加入音符時間欄的淡色直向高亮，音高區與固定休止列共用欄位起點及時值寬度。滑鼠 hover 優先顯示所指欄位；離開後回到已選取欄，無選取則隱藏，觸控也能保留選取欄提示。拖曳時值或交換音符期間隱藏高亮，結束或取消時恢復；圖層不攔截指標事件。

## M1：BEEP CARD

使用者已驗收 Composer 並授權進入 M1。新增獨立卡片入口，使用相同 canonical Melody 與 AudioEngine，不開發其他作品。entry.ts 依 query 分載 card-page 或 Composer，保留 GitHub Pages 子路徑，不需要伺服器路由。

分享格式為 `#melody=1.<base64url UTF-8 JSON>`，內容為 `[title,bpm,compactEvents]`；每事件兩個 base64url 字元，分別表示音高／休止及分母／附點。分享格式獨立版本化，解碼先限制長度，再驗證結構、範圍與 canonical model。不以 innerHTML 呈現曲名。網址最多 2048 字元；hash 不送往靜態 HTTP 主機，完整網址仍可轉傳作品內容，並非私密分享。

編輯卡片會產生新本機 ID，載入後清除匯入網址，不自動寫入收藏。分享為快照，不回寫既有連結。複製與系統分享各有按鈕，取消系統分享不視為錯誤。卡片不自動啟用音訊，離頁或失焦停止播放。靜態 OG 預覽沿用共用圖，不聲稱能動態顯示曲名。

## BEEP CARD：旋律織紋

使用者指定先新增一種生成藝術風格。使用原生 SVG，無點陣圖、外部 AI 或新依賴；音高決定色彩／位置／織帶厚度，時值決定相對寬度，休止保留留白。六排交錯鏡像構成圖案，BPM 決定直向紋理密度。四組策展式紙色配色由音樂內容的穩定雜湊選出，不受曲名、ID、時間戳或物件屬性順序影響。

藝術圖置於卡片頂部，不加任何文字。播放時僅點亮對應織帶，停止恢復；尊重 reduced-motion，生成與播放不改 Melody／分享格式。全休止曲以留白和直紋呈現。此版僅有旋律織紋，不提前新增其他風格或作品。

## 聲音星圖與風格網址

使用者追加第二種聲音星圖，使用 SVG 深藍底、米金／霧藍／陶粉星點及細軌道。全部事件依累積節拍定位，休止中斷連線。共用播放位置回呼與 reduced-motion 設定。`art` query 僅接受 weave、stars、random；未知值回到 weave。random 在卡片開啟或選單選取時抽選一次，replaceState 固定結果，再分享與帶回編輯保留風格；不把視覺設定加入 canonical Melody。

## 節奏構成

新增第三種 SVG 風格 rhythm，沿用 Melody、風格 query 與播放器回呼。以累積節拍排列矩形色塊，時值決定寬度、音高決定高度，圓形留白及深色節拍條形成平面構成；休止不繪製，附點以色點呼應。配色為朱紅、鈷藍、赭黃、森林綠與陶粉。新增共用 createCardArt 分派函式；隨機從三種風格等機率選取並固定網址，既有 weave／stars 連結不變。

## 聲音地形與後續創作節奏

使用者指定四個主題按順序逐一製作、每個完成直接推版並停下等待欣賞，只有明確說繼續才做下一個。順序為：聲音地形 → 旋律活版 → 音符標本 → 聲音窗景。本次僅完成聲音地形；其餘三個未實作。

terrain 使用獨立 SVG 模組，依 canonical Melody 計算累積時值及音高山脊，以平滑曲線連接音符平台，休止分割成獨立山脈。五層霧藍、苔綠、岩粉地層與細等高線，沒有文字或外部素材。播放回呼僅點亮當前音符的山脊段；停止清除，尊重 reduced-motion。加入風格白名單及四種等機率隨機選取；分享、編輯都保留 art=terrain。

## 旋律活版（四個主題中的第二個）

使用者說「繼續」後，本次只製作旋律活版，不開始音符標本或聲音窗景。letterpress 為獨立 SVG 模組：以音名選七種幾何印章、八度旋轉、升音偏轉 8 度、時值控制印章大小與節拍位置、休止留白、附點加第三層印記。紙色底、固定微粒紙紋、兩層 multiply 油墨與輕微套色錯位。只依樂譜產生，不含文字；單音作品置中，512 事件採自適應密度且不增殖假音符。共用播放回呼及 reduced-motion。

加入 art=letterpress、圖案選單與五種風格隨機；分享及匯入編輯保留選擇。完成推版後停下等待，下一個待使用者說繼續才實作的是「音符標本」。

## 音符標本（四個主題中的第三個）

使用者再次說「繼續」，本次只完成音符標本，不實作最後的聲音窗景。specimen 為獨立 SVG 模組，不含任何文字。休止拆分枝束，每束至多八音；累積時值決定沿曲線枝幹的葉片位置，音高及音名決定形狀、角度、顏色，長音延長枝束，附點形成小花苞。葉片原點取主枝的實際 Bézier 座標避免脫枝。暖白紙色、灰藍、苔綠、乾燥花粉，加入細葉脈與無文字固定紙條。大量音符採自適應比例，保留每個音符一次。

共用播放定位、reduced-motion、分享及匯入流程；增加 art=specimen、選單與六種隨機結果。完成推版後停下等欣賞；下一個需使用者說繼續才製作「聲音窗景」。

## 聲音窗景（四個主題中的第四個）

使用者再次說「繼續」，本次只完成聲音窗景。windows 使用獨立 SVG 模組：依事件數配置一至三扇拱窗，每扇內依累積時值分割玻璃高度，音高決定灰藍、鼠尾草綠、岩粉等玻璃色彩，休止保留清透留白，附點增加圓形玻璃。使用局部 clipPath、細窗框及兩道半透明斜向光帶，不含文字、不使用外部圖像。每個事件均保留獨立播放高亮，停止清除，尊重 reduced-motion。

加入 art=windows、圖案選單及七種隨機結果，分享與編輯保留風格。四個追加主題「聲音地形 → 旋律活版 → 音符標本 → 聲音窗景」均已完成；按使用者指示，推版後停下等待欣賞，不自行開發其他主題。

## 隨機只保留於分享設定

使用者希望卡片圖案選單不包含隨機，改由分享視窗安排。本次卡片只列七種風格；分享視窗以「目前圖案／隨機驚喜」兩種設定分離欣賞與分享。Composer 無指定風格時顯示旋律織紋預設。隨機在設定變更時抽選一次並產生具體 art 值，顯示本次風格，可重新抽選且排除上一次結果；預覽、複製與系統分享不再重抽，不修改目前卡片。每次開啟擷取旋律快照、重設為目前圖案。舊 art=random 網址仍可解析。

抽出 art-styles 輕量風格清單與名稱，避免分享設定載入全部 SVG 生成器。資料模型仍不包含視覺或分享 UI 狀態。

## M2.1：音樂盒第一個小里程碑

使用者已驗收 M1 並授權第一個音樂盒小里程碑：瀏覽、試聽、編輯及 WAV 下載，先不做標籤。新增 ?view=box 獨立入口，直接共用 readLibrary／Melody／AudioEngine，沒有建立第二份收藏或修改 storage schema。Composer 的入口開新分頁，保留未儲存編曲。BEEP CARD 也有音樂盒入口。

封面由相同旋律及 BPM 穩定選出七種藝術之一，不依賴標題／ID／時間戳，並以 IntersectionObserver 延遲繪製。點封面帶風格開卡片；分享視窗沿用該封面風格，仍可隨機。編輯收藏用本機 song ID 載入並清理網址，保留 ID／已儲存狀態；儲存更新原作品。共享連結匯入仍建立新作品，不與收藏編輯混用。

WAV 為無依賴、可測試的 PCM 合成器，沿用 frequency／eventSeconds canonical 映射，以帶限奇次諧波近似方波，短 attack／release、音間留隙及固定振幅。單聲道 22.05kHz／16-bit little-endian RIFF；休止輸出零值，附點與 BPM 保留。Worker 背景產生並 transfer ArrayBuffer，主執行緒僅建立 Blob 下載。限制 180 秒，在配置記憶體前檢查；超長不截斷。一次一份下載，離頁取消 Worker 並恢復狀態，Blob URL 延後釋放。iOS 不宣稱自動設為鈴聲。

播放沿用單一引擎，試聽按鈕與全域停止同步；快速切換、停止與 pending unlock 由 request token 防止舊請求更新 UI。失焦／隱藏／離頁停止；storage 事件與 bfcache 返回重新讀取收藏。此階段沒有登入、雲端、標籤或新音色。

## M2.2：標籤與搜尋

使用者說繼續，承接上一階段預告的標籤整理功能。本次只做本機收藏的自訂標籤、曲名／標籤搜尋及單標籤／未分類篩選，不開發其他作品。

標籤儲存在 beep-lab:tags:v1，採版本化 entries 陣列，以 songId 對應，不修改 canonical Melody 或現有收藏 schema。以 Map 避免物件鍵注入；限制每首八個、每個二十字，去除空白並依 NFKC／大小寫去重；顯示保留第一個使用者命名。分享與音訊均不包含標籤，原 ID 編輯保留 metadata、新 ID 改編不繼承。

標籤視窗編輯本地草稿，儲存前可新增／移除，取消／Esc 不寫入；儲存時納入尚未按加入的輸入，中文輸入組字時 Enter 不誤送。儲存前重讀 metadata，合併其他作品的新資料，同一首若與開啟時不同則拒絕覆蓋並保留草稿。損壞／未知版本保留原始值並停寫，收藏仍能使用。

搜尋與標籤採 AND 組合，支援曲名／標籤、NFKC、大小寫及多個空白分隔詞。未分類為沒有標籤的現有作品；篩選選項只統計仍存在的作品。變更篩選時停止試聽並重繪結果，保留搜尋輸入焦點；標籤編輯後如作品離開篩選結果，焦點回到搜尋欄。

## Studio 專注模式修正

使用者要求 Studio 進入全螢幕樣式時只剩 editor-panel，body 不出現捲軸。本次移除進入專注模式時強制切 Classic 的邏輯，保留目前 viewMode，不再需要 modeBeforeFocus。Studio 使用單一 minmax(0,1fr) 編輯區，固定視窗並限制整頁 overflow，音高圖以剩餘高度提供內部捲動。隱藏重複游標／附點工具及說明，保留 Studio 表單、固定休止列、播放與退出按鈕；短橫向將欄位與新增操作並排。Classic 原版面保持 editor＋keypad。

Esc 在 Studio 拖曳取消已 preventDefault 時不退出專注；一般 Esc 退出並停止播放，不再繼續觸發取消選取。退出保留 Studio 與歌曲。既有 ?focus=1 直連仍依初始 Classic 模式進入，不擴充新的模式網址參數。
