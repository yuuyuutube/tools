# 藝術指導：ROTARY STORIES 與《地球仍有四季》

## 0. 一句話

**圖書館是一間安靜的獨立出版社目錄室；《地球仍有四季》是一艘住了六十三年的船，船上的每個房間有自己的光。**

不做：藍色科技 Dashboard、雷達動畫、霓虹描邊、紫藍漸層、玻璃擬態、圓角卡片牆、emoji。所有圖像以程式繪製（SVG／Canvas），沒有外部圖片素材。

---

## 1. 圖書館

### 1.1 空間

不是書架擬物。是一張攤開的出版目錄：米白紙面、細黑線、留白很多。畫面中央是一個「轉盤」：書沿著一道淺淺的弧排列，當前的書正面朝向讀者、露出完整封面，其他書只露出書背，往兩側退後、變窄、變暗。

旋轉時，整道弧以彈簧物理移動：每一格會略微過衝再停穩。快轉時書背連續掠過，停手後慢慢靠岸。停止操作約六秒後，當前封面極緩慢地「呼吸」（陰影深淺變化），像放在窗邊的一本書。

畫面下方有一個細線構成的圓形索引環，刻度數等於書的數量，指針指向當前的書。觸控裝置上，這個圓環就是 click wheel：手指沿著它畫圈即可瀏覽。

### 1.2 字體

| 用途 | 字體 |
|---|---|
| 中文書名、內文 | Noto Serif TC（400／600／900） |
| 西文刊頭、書名副標 | Cormorant Garamond（斜體為主） |
| 目錄編號、數字、標頭 | IBM Plex Mono |

### 1.3 色彩

| Token | 值 | 用途 |
|---|---|---|
| paper | #ECE6DA | 紙面 |
| ink | #1E1C19 | 文字、線 |
| ink-soft | #6B655B | 次要文字 |
| rule | #C9C0AF | 細線 |
| vermilion | #B8432C | 只用在目錄編號與當前指示 |

### 1.4 封面系統

每本書有自己的封面，不共用版型。共通的只有：書背上方的 RS 編號、底部的出版社小標。

**RS 001《地球仍有四季》封面：**
- 米白厚紙底，帶紙纖維噪點。
- 中央一個大圓：由上到下分成四條水平色帶（春：淡青綠、夏：深海綠、秋：赭黃、冬：灰），每條色帶裡是同一條頭汕地平線剪影（學校、廟的燕尾脊、水塔、木麻黃）。最下面那條（冬）裡，水塔不見了。
- 圓的下半部被幾片深灰色的弧形遮光板蓋住，只露出上面三分之二。
- 書名直排在右側，Noto Serif TC 900。英文書名小號斜體在底部。
- 色彩印刷感：四條色帶有輕微的錯版位移（1–2 px），像孔版印刷。

**籌備中的書背：** 素色牛皮紙書背、直排書名、灰色的「籌備中」。不畫封面。

## 2. 《地球仍有四季》總體

### 2.1 船的質感

- 漆過很多次的金屬：暖灰綠（#3A3E37）、邊角磨出底漆（#7D776A）。
- 標示：米白銘板（#E3DBC6）、刻字黑色、IBM Plex Mono 與 Noto Sans TC。
- 有生活痕跡，但不是古董：膠帶貼的公告翹起一角、登記表的字跡不同、防滑地板的漆磨掉。
- 船上的螢幕一律是**低反光的反射式顯示器**：米灰底（#D8D2C2）、深墨字（#2A2925），像印刷品。沒有發光的藍色介面。這也符合世代船的設計（低耗電、長壽命）。

### 2.2 每個房間的光

| 章 | 主光 | 色溫 | 情緒 |
|---|---|---|---|
| 一 觀測艙 | 琥珀夜燈 → 南門二 A 的刺眼點光 | 2400K → 5800K | 寧靜、孤獨 |
| 二 影像檔案室 | 檯燈、天花板間接光 | 3500K | 專注 |
| 三 聲音資料庫 | 同一間檔案室，只開檯燈 | 3000K | 親密 |
| 四 植物培育室 | 植物燈，偏暖的白 | 4500K，略帶洋紅 | 溫暖、潮濕 |
| 五 通訊站 | 低色溫的冷白 | 5000K | 距離、等待 |
| 終 觀測站 001 | 新行星的日光 | 5800K | 開闊 |

### 2.3 地球影像（第二、五章）

- 用 Canvas 程式繪製，同一個場景函式依「年份」與「季節」產生畫面，保證六十年間空間位置完全連續。
- 風格：不是照片寫實，而是**帶顆粒的平塗印刷風景**——像一張以孔版印刷重製的觀測照片：色塊平整、邊緣乾淨、有顆粒、天空有細微的色階帶。
- 每個季節有自己的天光：春（清、偏青）、夏（硬光、高飽和、雲塊大）、秋（天高、空氣透、偏暖）、冬（灰、低對比、風把木麻黃吹斜）。
- 舊相機（2073–2132）色彩偏暖、略帶暗角；新相機（2133）偏冷、更銳利。這個差異很小，但看得出來。
- 地物標註用極細的白色引線與小編號，不搶畫面。

### 2.4 顯微影像（第四章）

- 落射照明的質感：背景暗、葉面灰綠、帶蠟質反光。
- 鹽結晶是白色、半透明、方形，有銳利的高光。
- 景深以分層模糊呈現：每一層預先繪製，依對焦位置混合不同模糊程度的版本。
- 輕微的色差邊（紅青分離）與暗角，像真的光學系統。

### 2.5 新行星（終章）

- 天空：淡藍，近地平線偏白。不使用紫色。
- 地面：深色玄武岩砂、白色鹽殼、淺水；淺水裡深褐色的層疊石圓丘。
- 遠景：緩坡台地、遠山（藍灰）。
- 南門二 A：白中帶黃的刺眼光點，有光暈與鏡頭眩光；南門二 B：偏橙的亮點。
- 登陸區：兩艘著陸器、白色艙體、車轍，小小的人影。
- 相機畫面：淺景深依對焦距離變化；望遠端有輕微的大氣霧化。

## 3. 動態原則

1. **機械有重量。** 艙門與遮光板有慣性，慢慢起步、慢慢停。
2. **精密的東西反應快。** 相機對焦、顯微鏡對焦即時跟手，沒有延遲。
3. **離散的東西有刻度感。** 年份滾輪、選帶輪每一格有一點點過衝。
4. **沒有裝飾性動畫。** 沒有漂浮粒子、沒有呼吸光暈。會動的東西都有理由動（星空因為居住環自轉而轉、木麻黃因為風而動、水因為潮汐而動）。
5. 「減少動態」設定開啟時：取消過衝、取消星空旋轉以外的環境動畫，換場改為直接淡入。

## 4. 聲音原則

1. 每個設備的轉動聲不同（見 interaction-design.md 的對照表）。
2. 沒有配樂。整部作品沒有音樂。
3. 地球的聲音（第三章）是最豐富、最細緻的聲音；船上的聲音是低的、穩定的、機械的。
4. 安靜是設計的一部分：第一章開場、第五章提交後、終章歸檔後，都有刻意的安靜。
5. 所有聲音都在瀏覽器中即時合成或離線合成，沒有錄音檔。合成的地球環境聲在作品中以「錄音」的身分出現，製作文件與 README 中清楚標示為合成。
