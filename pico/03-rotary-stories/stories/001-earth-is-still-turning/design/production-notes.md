# 《地球仍有四季》製作紀錄

## 1. 素材來源（重要）

**本作品沒有使用任何外部素材。** 所有圖像與聲音都由程式即時或離線產生。

| 類型 | 內容 | 製作方式 |
|---|---|---|
| 地球觀測影像（E-017、E-031） | 頭汕漁港、汕尾溪口六十年的影像 | `art/earth.js` 以 Canvas 程式繪製。頭汕、汕尾溪、北寮皆為虛構地名 |
| 新行星風景 | 觀測站 001 的 360° 海岸 | `art/planet.js` 程式繪製 |
| 顯微影像 | 海茄苳葉面、鹽腺、鹽結晶 | `art/micro.js` 程式繪製 |
| 星空 | C-2 觀測窗外 | `art/sky.js` 程式繪製 |
| 「地球環境錄音」A-1～B-3 | 海浪、蟬、雨、鐘聲、鳥、雷 | **全部為合成聲音**（`audio/soundscapes.js`）。作品中它們以「錄音」的身分出現，目錄卡上的錄音者、日期是故事設定，不是真實錄音的來源 |
| 設備聲 | 棘輪、滾輪、對焦、快門…… | `audio/ship-sounds.js` 合成 |
| 字體 | Noto Serif TC、Noto Sans TC、IBM Plex Mono、Cormorant Garamond | Google Fonts（SIL Open Font License） |

### 1.1 合成聲音的做法

每一卷「錄音」都是時間的確定函數：給定同一個時間點，永遠產生同樣的樣本。所以 12～15 分鐘的錄音不需要預先產生，播放時只在播放頭附近產生 4 秒的片段，可以在任何位置暫停、倒帶、快轉。

| 聲音 | 合成方式 |
|---|---|
| 風 | 粉紅雜訊，低通濾波器隨陣風曲線開合；左右聲道不相關 |
| 浪打消波塊（A-1） | 每一道浪是一個事件：低頻撞擊＋長的沖刷聲＋退水時碎石被拖回的細碎顆粒 |
| 浪打垂直海堤（B-1） | 拍擊＋短而悶的撞擊，沒有碎石聲 |
| 繫繩摩擦 | 黏滑摩擦的脈衝列通過兩個共振峰 |
| 台灣熊蟬 | 七隻蟬：各自的帶通雜訊被快速脈衝切割，每隻蟬有自己的長音起伏與位置 |
| 下課鐘聲 | 西敏寺鐘聲（台灣學校常見的版本），以模態合成鐘聲，經走廊擴音器頻寬限制與川堂殘響 |
| 雨打鐵皮 | 每秒數百顆雨滴，每顆是兩個金屬共振的極短衰減，加上寬頻雨聲 |
| 舷外機 | 兩次拉繩失敗、發動、逐漸遠去：點火脈衝列＋機身共振 |
| 泥灘 | 稀疏的細碎爆裂與氣泡聲 |
| 水鳥 | 高蹺鴴（短促帶諧波的「kek」連串）、東方環頸鴴（短促下滑音）、小白鷺（粗啞叫聲）、遠處哨音 |
| 雷 | 布朗雜訊的長滾動 |

**限制：** 合成無法產生可信的人聲。A-2 的「下課人聲」以模糊的帶通雜訊表現，劇本因此寫成「依錄音規範降低處理」——這是一個符合世界觀的處理，也誠實地對應了技術限制。

## 2. 真實知識查核

| 項目 | 依據／處理 |
|---|---|
| 南門二距離 4.37 光年，A 為 G2 型、B 為 K1 型 | 天文常識 |
| 110 AU 處南門二 A 的視星等約 −17 | 以絕對星等 4.38 計算 |
| 0.072c 的時間膨脹 0.26% | γ = 1/√(1−v²) |
| 光行時間、接收日期 | `data/archive.js` 以同一個航行模型計算，`tests/story001.test.js` 驗證沒有任何資料早於光可能抵達的時間 |
| 海茄苳鹽腺、鹽結晶、隱胎生、蟲媒花 | 植物學常識；鹽結晶畫成立方體（氯化鈉） |
| 海茄苳開花季節 | 台灣約夏季。劇本的光照季節依此設定（冬至後第 42 日時，前一次開花落在模擬的夏季）。世界觀不宣稱特定的開花訊號機制 |
| 黑面琵鷺 | 冬候鳥、白天多休息、很少鳴叫——錄音 B-2 因此沒有琵鷺的聲音 |
| 北緯 23° 冬至後 42 日日照約 11 時 06 分 | 天文計算 |
| 學校鐘聲 | 西敏寺鐘聲。採「mi-do-re-sol／sol-re-mi-do」開頭的常見版本；第三、四句的音序依記憶，**待使用者以耳朵確認** |

## 3. 已知取捨

- 地球影像是印刷風格的插畫，不是照片寫實。理由：程式繪製的「假照片」很容易落入廉價的寫實感；印刷風格能保持六十年間每一年的空間一致。
- 第五章接收總帳原本設計成「延遲越來越斜的線」，經審核刪除（見 narrative-audit.md 第二輪第 7 項）。
- 合成錄音沒有經過人耳逐卷調校，只做了音量平衡與數值檢查（峰值、接縫）。見 README「待驗證項目」。
