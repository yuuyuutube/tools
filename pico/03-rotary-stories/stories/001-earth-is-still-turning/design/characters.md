# 《地球仍有四季》人物

> 原則：先是一個可信的人，然後才是故事角色。
> 每個人只透過「本來就會存在的東西」出現在玩家面前：工作紀錄、系統日誌、登記表、目錄、規範條文。

---

## 1. 玩家：檔案員 07

| 項目 | 設定 |
|---|---|
| 身分 | 環境資料組檔案員，第三代，27 歲 |
| 職務代號 | 檔案員 07（玩家可在設定中改成自己的名字，影響終章紀錄表的署名） |
| 家庭 | 祖父母是第一代（祖母已過世，祖父住在居住環 B）。父母是第二代 |
| 工作 | 進組四年。日常工作是接收後歸檔、維護地物標註、檢聽錄音目錄 |
| 對地球的認識 | 熟悉基準版教材。知道海浪、蟬、雨、蚵棚是什麼；看過很多次 E-017 的基準版影像，因為頭汕是教材裡「沿海漁村」單元的例子 |
| 從沒做過的事 | 用肉眼看窗外。站在沒有屋頂的地方。聞過雨後的泥土 |

玩家沒有台詞、沒有內心獨白。玩家的性格只透過「怎麼操作」表現：在哪裡停留、轉多快、拍什麼。

文字一律用「你」稱呼玩家，或者不稱呼。不使用性別代名詞。

### 玩家在故事中的變化（不寫出來，只讓操作帶出來）

- 開頭：標註衝突就是「錯」，要找出哪一邊對。
- 中段：發現衝突的另一邊有地球端的紀錄、有人簽名、有日期。
- 結尾：把衝突一筆一筆分段，兩邊都留下。然後在新行星上拍下一個新的「基準版」。

## 2. 蔡沛涵

| 項目 | 設定 |
|---|---|
| 出生 | 2045 年，台灣頭汕 |
| 家庭 | 父親蔡文雄在潟湖養蚵。母親在鎮上的郵局工作。有一個弟弟蔡承佑，留在地球 |
| 學歷 | 頭汕國小（2051–2057）。大學讀地理，碩士讀環境資訊 |
| 出發前 | 觀測網台灣區中心技術員。2072–73 年為基準版補錄音 |
| 出發時 | 29 歲，單身。船上第 9 年與輪機組的陳立衡結婚，有一個女兒（第二代），女兒現在 53 歲，在醫療組 |
| 船上工作 | 環境資料組研究員（第 0–20 年），組長（第 20–46 年） |
| 現在 | 92 歲，退休，住居住環 B。行動慢，但每次資料包到，都會用唯讀權限看 E-017 和 E-031 |
| 玩家認識她嗎 | 知道名字（前任組長，很多舊紀錄是她寫的）。沒有共事過，可能在走廊見過 |

### 2.1 她為什麼請求 E-017

- 這是她長大的地方。這個理由她不寫在任何地方。
- 她能寫在紀錄上的理由是真的：E-017 是基準版裡影像最完整的東亞沿海點，而且是教材範例，持續追蹤有教學價值。
- 兩個理由同時成立。這就是一個普通人使用工作權限的方式。

### 2.2 她怎麼變（只透過工作紀錄看出來）

| 時期 | 她的工作紀錄長什麼樣子 |
|---|---|
| 第 0–10 年 | 每一包 E-017 都看。標註一律「沿用基準版」。紀錄簡短、正確 |
| 第 15–17 年 | 頭汕國小變成社區活動中心。她先寫「疑為標註錯誤」，地球端確認後寫「依規定基準版標註不改」。照規定做，沒有多說 |
| 第 15 年 | 設定 E-031 定期請求，指定冬季。她開始看一個基準版只有兩張影像的地方 |
| 第 26–41 年 | 開始在更新資料上「新增」地物：海茄苳林、光電板、新住宅、木棧道。描述寫得比早期詳細，因為這些東西她沒見過，只能從影像判斷，要寫清楚根據 |
| 第 37 年 | 為 E-031 的海茄苳申請活體對照紀錄 LC-212，親自拍第一張對照影像 |
| 第 39 年 | 提案修訂整理規範第 4 條：衝突依年代分段，各段保留。提案理由全是工作上的理由 |
| 第 46 年 | 退休。保留唯讀權限與通知訂閱 |
| 第 63 年 | 仍在讀取每一包新資料 |

**她沒有一次在紀錄裡寫自己的感受。** 唯一接近私人的地方，是 2073 年錄音開頭的口述標記（轉寫保存在目錄附註），那時她 28 歲，還在地球上，說話比較隨意。

### 2.3 她的文字聲音

- 工作紀錄：短句。主詞常省略。日期、編號一定寫完整。
- 判斷會標明根據：「依 2112-02-07 影像判斷」「地球端異動紀錄第 3 項」。
- 不用形容詞表達感情。只在描述影像時用形容詞（「葉色偏黃」「灘地積水」）。
- 2073 年口述標記：口語，有地方腔的語序，偶爾有一句跟工作無關的話（「蟬很大聲」「今天風有夠大」）。

### 2.4 禁止事項

- 她沒有死。不寫她的死亡，也不暗示。
- 她沒有留任何東西給玩家。她不知道玩家是誰。
- 她不說人生道理。
- 不是每一份她的紀錄都有深意。大多數只是工作。
- 她的私人物品不出現在故事裡。

- 只透過兩樣東西出現：交給玩家的工作分派單（第二章開頭），以及錄音 B-3 的目錄（她寫的，風格和蔡沛涵不同：更簡短，不寫口述標記，因為 B-3 是地球端錄的）。
- 說話方式：工作分派單上的語氣，清楚，偶爾一句實際的提醒。

### 交接紀錄的語氣

觀測網的交接紀錄是表格與條列，不寫感想。最多一句實務上的提醒，例如「北堤支架螺栓易鏽，每季檢查」。
