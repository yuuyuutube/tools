# 鏡・墨・紋 — 設計意圖

INFINITE KALEIDOSCOPE — CLAUDE EDITION
副標：三種讓世界重複的方法 / Three Ways to Repeat the World

## 概念

萬花筒的本質不是「花」，而是「一個物件 + 一種會不斷重複的轉換」。
傳統萬花筒用的是三面鏡子。這件作品把萬花筒拆成三種物理現象，各自是一種獨立的重複方式：

| 模式 | 物理 | 重複的方式 | 旋鈕的身體隱喻 |
|---|---|---|---|
| 鏡 REFLECT | 反射 | 三面鏡子圍成的三角形，在雙曲平面上無限鋪滿 | 在無限的鏡廊裡往前走，同時讓晶格變形 |
| 墨 DIFFUSE | 流動 | 墨滴落在水面，以對稱的方式一圈圈推開彼此（流し墨／水拓） | 攪動水盆；倒轉就把墨「攪回去」 |
| 紋 INTERFERE | 干涉 | 兩張印著細線的透明片疊在一起，產生摩爾紋 | 轉動上面那張圓形透明片 |

三種模式使用完全不同的演算法、構圖與材質，不是同一個 shader 換色。

## 美術語言：印刷工作室

整件作品被當成「一間會自己印刷的工作室」：

- 色彩是「油墨組」：每組只有一張紙色 + 四色油墨（主墨 key、A、B、C）。不使用 RGB 漸層或彩虹。
- 淺色紙用 multiply 疊印，深色紙用 screen 疊印，模擬真實油墨疊加。
- 絹印的套色偏移（misregistration）、網點、紙張纖維、靜態顆粒。顆粒是靜態的，不會閃爍。
- 鏡：圓形觀景窗（萬花筒目鏡）置中，四周留白。
- 墨：滿版，像一張剛撈起的水拓紙。
- 紋：滿版底紙 + 一張圓形透明片，透明片的邊緣有微微的陰影。

## 演算法

### 鏡 REFLECT — 雙曲三角鏡群（Coxeter triangle group）
- Poincaré 圓盤模型。兩面直線鏡（過原點）與一面圓形鏡（與單位圓正交）圍成內角 π/p、π/q、π/r 的三角形，1/p+1/q+1/r<1。
- 每個像素反覆反射回基本三角形，記錄反射次數（奇偶）與保角縮放（用於反鋸齒，讓線條在無限邊緣自然淡出）。
- 面的分割用 Wythoff 構造：在三角形內取一個生成點，連到三面鏡子的垂直測地線把三角形切成三塊 → 三種面的均勻鋪磚。生成點移動時，鋪磚在正規、截角、截半、全截角之間連續變形。
- 攝影機是雙曲等距映射 `z → T_a(u·σ(z))`，以閉式合成。旅行路徑是固定步長的分段積分，每步之後用群對稱把攝影機摺回基本區域，所以可以無限前進而沒有浮點溢位，而且結果只由 (seed, 時間, 旋鈕值) 決定。

### 墨 DIFFUSE — 數學水拓（Jaffer 等人的 ink-drop 映射）
- 墨滴是保面積映射：`p' = c + (p−c)·√(1 + r²/|p−c|²)`，反向映射可解析計算。
- 每個像素沿著「操作列表」倒著追溯回最初的位置，找到它屬於哪一滴墨。
- 墨滴以 k 重對稱的方式落下（中心一滴、外圈 k 滴交替），對稱性來自物理，而非鏡射複製。
- 在每一輪墨滴之間插入「渦旋」操作（只依半徑旋轉 → 保面積、可逆）。旋鈕值乘上每輪不同的權重，所以轉動時每一層墨以不同速度扭轉，出現羽毛與大理石紋；反轉旋鈕就把墨攪回原狀。
- 墨滴內部的濃淡噪聲在墨滴自己的座標中取樣，所以紋理會跟著流體被拉扯。

### 紋 INTERFERE — 摩爾干涉
- 兩層線條網屏，類型包含同心圓、放射線、平行線、阿基米德螺線、對數螺線、菲涅耳波帶片。
- 線條使用箱型濾波的脈衝波（analytic box-filtered pulse），避免與螢幕像素再產生不受控的疊紋。
- 旋鈕以 1:50 的減速比轉動透明片：一格只轉 0.36°，但干涉條紋會大幅改變 —— 像精密光學儀器。

## 色彩系統（6 組油墨）

1. 朱藍 Vermilion Press — 朱紅、鈷藍、金盞黃、靛黑，米色紙
2. 螢光孔版 Riso — 螢光粉、孔版藍、黃，象牙紙
3. 岩彩 Mineral — 孔雀石綠、朱砂、赭金、墨，暖紙
4. 夜印 Night — 深藍黑紙上的骨白、珊瑚、青綠、金
5. 墨 Sumi — 三階灰墨 + 一點印章紅
6. 藍曬 Cyanotype — 普魯士藍紙上的白與淡藍

每個模式都把 C 墨當成點綴色（面積最小），所以即使 Sumi 的紅也只會出現在少數位置。

## 動畫原則

- 慢。環境時間只負責「呼吸」：鏡廊緩慢前行、墨滴每 2.8 秒落下一輪、透明片極慢漂移。
- 旋鈕值都經過臨界阻尼平滑，限制最大角速度，避免頻閃。
- 轉場：
  - 切換模式 = 刮刀拉過（絹印的動作），一條墨線斜斜掃過畫面，後面露出新的印刷。
  - 新宇宙 = 一滴墨從中心暈開，邊緣帶著不規則的墨緣。
  - 換色 = 0.7 秒的油墨交叉淡化。
- 減少動態：環境時間停止，轉場改為短淡入淡出。

## 互動映射

| 輸入 | 鏡 | 墨 | 紋 |
|---|---|---|---|
| 旋轉 | 前進／後退 + 生成點變形 | 攪動（可逆） | 轉動透明片 |
| 短按 | 下一個模式（刮刀轉場） | ← | ← |
| 長按 | 新宇宙（新 seed，墨滴轉場） | ← | ← |

所有輸入（Pico、滑鼠、觸控、鍵盤）都只呼叫同一個 ArtController。藝術引擎不知道 Web Serial 的存在。

## 可重現性

狀態 = (模式, seed, 色盤, 三個模式各自的旋鈕值, 時間 t)。所有隨機都由 seed 經 hash + mulberry32 產生，畫面是這些值的純函數。分享連結把這些值寫進網址 hash；PNG 檔名也帶 seed 與 t。
