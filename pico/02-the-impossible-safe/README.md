# THE IMPOSSIBLE SAFE

**A Very Serious Vault for Very Unimportant Things.**
無用物品保護局 · WEIRD LAB / 02

一款以旋轉為核心的保險箱解謎與收藏遊戲。玩家是「無用物品保護局」的新進保險庫管理員，依照極其嚴謹的程序開啟保險箱、確認內容物仍然存在、建立鑑定紀錄、存入典藏室。內容物是一顆馬鈴薯。

整個遊戲可以只用一顆實體旋鈕（Raspberry Pi Pico 2 WH + KY-040）完成；沒有硬體時，也能用滑鼠、手指畫圈、鍵盤完整遊玩。

---

## 作品概念

- **操作非常認真**：轉盤有累積旋轉量、方向、圈數、跨零點、旋轉歷程，判定精準到每一格。
- **機械非常精密**：每一格都有喀噠聲，每個階段都有鎖定聲，門有三道鎖栓。
- **儀式非常隆重**：鎖栓依序解除、把手轉動、厚重的門緩緩打開、內部一片黑暗、燈光逐漸亮起、先看見剪影，最後才看清楚。
- **獎品非常荒謬**：半截吸管、空信封、昨天的空氣、兩公分的星期二。

幽默只來自內容與形式的反差。所有官方文件與首席保管官封存仁的發言，都保持乾燥、克制、一本正經。

## 啟動方式

不需要安裝任何套件，任何靜態伺服器皆可。Web Serial 需要安全來源，`http://localhost` 即符合。

```bash
cd tools/pico/02-the-impossible-safe
node serve.mjs
```

開啟 <http://localhost:5175/>（可用 `node serve.mjs 8080` 指定埠號）。

專案根目錄的 `.claude/launch.json` 也有 `impossible-safe-claude` 設定。

**選單手感**：清單是一個轉經過紅色指標的「鼓」，以彈簧物理逐格停靠（略微過衝後收住）；快轉時自動加速瀏覽；到底會有阻尼回彈與低沉的碰撞聲；每移動一格，左邊的保險箱轉盤也同步轉動十分之一圈。

**滑鼠**：在保險箱上任一處沿圓周拖曳即可轉動；滾輪轉動；點一下中央旋鈕＝短按，按住中央旋鈕 0.65 秒＝長按；點把手也可以拉動把手；清單項目可直接點選。

**手機／平板**：手指直接沿轉盤畫圈，像 iPod Click Wheel。以相對轉盤中心的角度差計算旋轉量，正確處理 ±180° 接縫、連續多圈與反向。清單也可以上下滑動。畫面下方另有四顆按鈕（左轉、按下、右轉、返回），左右按鈕可按住連續轉動，中央按鈕可短按或長按。

**鍵盤**：方向鍵旋轉（Shift＋方向鍵一次十格）、Enter／空白鍵確認、Esc／Backspace 返回或開啟輔助選單。

**旋鈕齒輪比（設定 → 旋鈕靈敏度）**：慢慢轉時永遠是一格對一格，可以停在任何刻度；只有快速旋轉時才借用較高的齒輪比（標準最高 3 倍、快速最高 5 倍、精密固定 1 倍），不必為了轉三圈而真的轉十五圈實體旋鈕。選單加速與轉盤齒輪是兩套完全獨立的計算，快速瀏覽選單不會影響開鎖判定。

## Pico 連線方式

使用 `01-infinite-kaleidoscope/firmware/main.py`（已安裝於 Pico 的 `/main.py`），**韌體與接線都不需更動**。協定：

```json
{"type":"rotate","delta":1}
{"type":"press","kind":"short"}
{"type":"press","kind":"long"}
```

1. **先中斷其他頁面的 Pico 連線**（例如萬花筒網站），並**關閉 VS Code 的 MicroPico**，否則序列埠會被占用。
2. 用 Chrome 開啟本遊戲，按右上角插頭圖示（或主選單「旋鈕連線」），選擇 Pico。按住 Shift 再點插頭，可列出所有序列埠。
3. 之後重新整理頁面時，會自動重新開啟曾授權過的 Pico，不必再選一次。
4. 若實體旋鈕的方向與畫面相反，在設定中把「旋鈕方向」改為「反轉」。

說明：

- `delta` 可能是累積整數（例如 `3`、`-4`）。轉盤會逐格處理每一格，不丟棄任何位移，所以跨零點、閘口共鳴、圈數計算都不會因為封包合併而遺漏。
- 韌體沒有提供逐格時間戳，速度與節奏是用「收到時間 × delta」在 260–300 ms 的視窗內估算。
- 串流分段、過長行、非 JSON 雜訊（例如 MicroPython 開機訊息）都會被安全略過；拔除後狀態顯示為「中斷」，插回同一塊板子會自動重連。連線、斷線都不會重置遊戲進度，斷線後可立即改用滑鼠、觸控或鍵盤。
- 瀏覽器音訊必須在使用者手勢後才能啟動。Pico 的按鍵不算手勢，因此如果頁面是自動重連的，請先點一下畫面任一處（右上角喇叭圖示會閃爍提醒）。
- 不支援 Web Serial 的瀏覽器（Safari、Firefox）仍可完整遊玩。

## 關卡規則

### 本局標準程序 BSP-3

`R2·15` 代表：**向右**（順時針，讀數增加）旋轉，**至少完成 2 整圈**，最後**停在 15**，按下確認。`L` 為向左。字母後沒有數字時代表不需繞圈。

- **行程**是本階段朝正確方向累積的「淨」轉動量，每滿 100 格算一圈。轉過頭時小幅倒轉不會遺失已完成的圈數（寬鬆行程制）。
- **嚴格行程制**：反方向轉超過 3 格，該階段行程歸零。
- 全部階段完成後，門上的指示燈全亮、鎖定窗由紅白斜紋變為綠色，再按一次拉動把手。
- 對齊後若又轉動轉盤超過 3 格，最後一個階段會重新打開，回到正確刻度再確認即可。
- ACT 2 起大部分保險箱在確認錯誤時會使全部階段重設（防止逐格暴力試錯），文件中會註明。

### 閘口共鳴機構（本遊戲虛構的感官線索）

當轉盤**朝該階段的方向**、**以適當速度**（每秒 24 格以下）經過**該階段的正確刻度**時，箱內會發出一聲空心的「咚」。同一刻度、同一方向，永遠得到同一反應；轉太快時不作動並提示放慢。每個閘口只在所屬階段作動。

每一種聲音線索都有視覺替代：

| 聲音 | 視覺 |
|---|---|
| 閘口共鳴（空心「咚」） | 共鳴計指針擺動、轉盤指標燈亮起並微震、記錄紙出現尖峰 |
| 預響（漸強） | 指針小幅擺動、記錄紙小尖峰 |
| 雙響區／死點 | 記錄紙小尖峰／向下凹陷，指針下沉 |
| 低音／高音 | 藍色／紅色的指標燈、記錄紙與指針顏色 |

設定或輔助選單中的「**視覺線索輔助**」會在記錄紙上直接標出共鳴發生的刻度。Android 裝置另有震動回饋。

### 日常委託（無限）

完成第 003 號後開放。每天以日期為種子生成 3 件委託，完成後還有無限的「加班委託」。同一天、同一編號永遠產生相同的保險箱、文件與答案。8 種題型：完整程序、遮蔽文件、打字機偏移（±1–3）、交接日誌、共鳴、預響、死點、清點表。藏品偏好尚未獲得的物品（約 65%），以稀有度權重抽出；三件特殊保險箱專屬藏品不會出現在委託中。重複藏品會累計數量並附上局內說明，例如：

> 本局現已保管兩顆普通馬鈴薯。安全風險評估維持不變。

**聲音**（全部即時合成）：Dial Tick（銷釘喀噠＋鋼環＋低頻頓挫，速度越快越輕）、Menu Tick（乾淨的電子音）、Mechanical Resonance（三種音高的空心木質共鳴）、Stage Confirm、Lock Engaged、Lock Released（三道鎖栓）、Handle、Door Creak（黏滑摩擦＋低頻隆隆）、Artifact Reveal（三聲鐘＋緩慢展開的和弦）、Stamp、Error、Ambient（選用的機房低鳴）、以及個別保險箱的鼾聲、嘆氣、驚醒。主匯流排上有限幅器；轉盤喀噠聲限制在每秒約 90 次、每次最多排程 8 聲並分散在約 30 ms 內，所以快速轉動不會爆音或塞滿音訊執行緒。

**轉盤手感**：邏輯位置立即更新（判定永遠精準），畫面以約 38 ms 的臨界阻尼滑行跟上；快速旋轉時繪製數層半透明殘影維持視覺連續性。三層快取（外圈、刻度盤、固定高光），每幀只做合成。

## 存檔方式

- 使用 `localStorage`（鍵名 `bureau-of-unnecessary-protection/save`），無後端、無登入。
- 保存：主線進度與失敗次數、收藏品與重複數量、首次獲得時間、獲得紀錄（每件最多 50 筆）、日常委託進度、統計、音量、環境音、旋鈕靈敏度與方向、視覺輔助、減少動態、開箱演出偏好、震動回饋。
- 版本化格式（`format: "bup-save"`, `version: 1`）：讀取時逐欄位與預設值合併，未知欄位保留，損毀的資料回退為新存檔。日後新增關卡、藏品或設定不會讓舊存檔失效。
- 設定中可**匯出／匯入 JSON 存檔**，以及**重設進度**（需以旋鈕再次確認；設定會保留）。匯入需要以滑鼠或鍵盤選擇檔案。

## 已知限制

- 第一次啟動音訊必須點擊或按鍵；只用 Pico 自動重連時，需先點一下畫面。
- 「匯入存檔」使用瀏覽器檔案選擇器，無法只用旋鈕完成。
- KY-040 沒有力回饋，阻力與齒輪感只能以聲音、視覺與規則模擬。
- 速度由事件接收時間估算，USB 延遲抖動可能讓少數邊界情況的「速度過快」判定略有誤差；閘口速度門檻刻意設得寬鬆（每秒 24 格，害羞的保險箱為 7 格）。
- 中文字型使用系統字型（macOS 宋體／楷體最佳）；其他系統會退回 Noto Serif TC 等。英文字型 Bodoni Moda、IBM Plex Mono 來自 Google Fonts，離線時退回系統字型。
- 震動回饋僅 Android Chrome 支援。
- 保險箱圖鑑未製作（依需求優先完成典藏室）。
