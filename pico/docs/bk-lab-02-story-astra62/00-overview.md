# THE IMPOSSIBLE SAFE｜六份主線故事提案

六案各自是一條可以單獨製作的二十關主線。都從普通馬鈴薯開箱，最後都由玩家用自己的典藏紀錄開啟第 000 號。不同的是，二十次轉動之後，這個人取得了什麼資格。

| 路線 | 一句話故事 | 第 004 關留下、到第 015 關才看清的東西 |
| --- | --- | --- |
| [揪心｜兩邊都算到了](01-heartache.md) | 姊弟請新進員查清兒時一場沒見到面的探視，兩張到場單上都有真章。 | 退件桿上一句折住的「過點放行」，要等兩張返程車單到手，才讀得出人被放往哪裡。 |
| [感動・親情｜晚一點吃的人](02-family.md) | 三戶人家公開替晚歸家人留飯的方法，讓一向守鍋的春枝有一晚能先吃飯、再去唱歌。 | 「先動筷」的戳起先只剩一個「先」字，立起來以後，字面朝向廚房裡的人。 |
| [感動・故鄉｜下車請喊洗衣店口](03-hometown.md) | 港邊舊路拆了，店家借出還有人在喊的名字，讓新住戶也找得到明天的車。 | 老招牌缺了個「衣」字。新站簽填得上，還得有人肯在新的地方聽見這個名字就停車。 |
| [感動・地球｜盆放在下面](04-earth.md) | 生在世代船的管理員借齊幾戶自願交來的盆、管與溝圖，辦成一場人能伸手去接的雨。 | 被遮掉的「公」字。等水滿了，手必須夠快，才送得到下一個人的盆。 |
| [細思極恐｜請留在原位](05-dread.md) | 新進員替前班重做一套標準手勢，讓一張提前見證的空白證書終於有了可用的工號。 | 椅背底下的字牌說明，人離席以後，在席時數該怎麼算。 |
| [悵然若失｜夜間窗口](06-longing.md) | 兩名夜班員把有人守候的窗口交給全天自存櫃，最後一次收窗時，兩只杯都已洗好。 | 燈罩故意往外偏了半寸。值簿上那個被遮住的字，是一位每晚把車停好才走過來的人。 |

## 我最推薦《夜間窗口》

它先給玩家一個真能坐下來的地方。第二關有人量過你的手才剪短窗繩，第六關你還得看著收件盤，封存仁說「水我關了。」到搬桌時，他說「放手，我接著。」玩家已經知道他接得住，也知道桌子一搬走，兩個人就少了一件明晚可以一起做的事。這份感情可以落在既有的拉把手、開半扇門、短按收存上。

新櫃通宵收件，許姐也真的想改開早班。讓最後一次交接辦得順利，是玩家做成的一件好事；正因如此，很難替自己的捨不得找個冠冕堂皇的理由。這和作品原有的乾燥語氣很合。寫這一案最要守住的是前半段的相處時間，如果玩家還沒認得窗外的第二下敲聲就開始撤桌，結局只會像下班通知。

若想先試兩種很不一樣的手感，《兩邊都算到了》的第 015 關讓人想停下來等，《晚一點吃的人》的同一關則讓人想趕快把熱菜遞出去。可以直接並讀兩案第 7 節的該關，再翻第 18 節，看希望封存仁最後把哪一張紙交給玩家。
