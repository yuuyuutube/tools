## 我的推薦：01 揪心

以「劇情連貫且有情緒厚度」為最高準則，我推薦**揪心**，原因：

1. **最連貫。**二十關全部屬於同一個家、同一位父親。所有密碼都是這一家人的日期：結婚、出生、過世、門牌、電話。
2. **玩家的位置最強。**玩家不是旁觀者，而是那個被遺忘的孩子。員工編號從標題畫面就是探望次數。
3. **真正的抽絲剝繭。**第 016 號健忘的保險箱，必須靠玩家自己記得第 004、005 號的數字才能打開。那一刻，玩家比他更記得他的家。
4. **現有機制幾乎每一種都有唯一的情感理由**：打字機多打 1 是最早的症狀，嚴格行程是那天不能回頭，害羞是他不好的日子，急性子是已經過世的妻子。
5. **日常委託的重複藏品也有了理由**：看護 Siti 在馬鈴薯壞掉時偷偷換一顆一樣的。
6. **結局不靠煽情**：最重的一句話只有兩個字：「歡迎。」

**第二推薦：04 地球。**規模最大，最符合「大愛」，現有藏品的冷笑話幾乎都能直接翻轉成感動，且最容易與先前討論的奇幻、科幻方向銜接。

**如果想要話題性：05 細思極恐。**改動最小、現有台詞一字不改，且「依玩家自己的遊玩紀錄生成一座保險箱」是只有這款遊戲做得到的事。

## 寫作上的共通原則

- 幽默是手段，不是目的。局的乾燥語氣保留到最後，情緒發生在語氣的縫隙裡。
- 每一份提案都至少有三段「重讀改變意義」的文本，且大多直接沿用現有遊戲裡已經寫好的台詞。
- 感動路線的三份提案都以「申請書」「清冊」等自願託付的官方表單承載情感，避免偷窺感。
- 所有提案都沒有超自然力量，藏品也都沒有變得真的有用。
