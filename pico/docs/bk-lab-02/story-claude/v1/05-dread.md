# 細思極恐：本局現已保管一名保險庫管理員

## 0. 一句話

無用物品保護局保管「已經沒有人需要的東西」。它錄用的每一位管理員，都經過審慎評估：緊急聯絡人一欄，必須是空的。

**玩家關掉遊戲時的感受：**沒有被嚇到，只是過了幾分鐘，突然想回去重讀第一封聘用通知書，然後背脊發涼。

---

## 1. 情緒命題

細思極恐的關鍵是：**當下一切正常，恐怖只存在於回想。**

這款遊戲原本的笑點，幾乎每一句都可以被重新讀成恐怖：

- 「目前沒有證據顯示箱內物品有逃逸意圖。」
- 「請不要和它們建立私人感情。」
- 「本局將假裝從未見過閣下。」
- 「請勿站在門的旋轉半徑內。」
- 「本局現已保管兩顆普通馬鈴薯。安全風險評估維持不變。」

這個故事不加入任何血腥、怪物或驚嚇。它只做一件事：讓玩家在最後發現，「無用」的定義包括人。

而且這款遊戲握有一般恐怖作品沒有的東西：**玩家自己的遊玩紀錄**。最後那座保險箱的密碼來自玩家的典藏室，而玩家變成的那座保險箱，個性來自玩家實際的操作習慣。

---

## 2. 世界的真相 vs. 玩家一開始以為的世界

| 玩家一開始以為 | 真相（從不明說） |
|---|---|
| 一個荒謬的機構，保管沒人想要的東西 | 它保管的是「已經沒有人需要的東西」，包括人 |
| 七座特殊保險箱有奇怪的個性 | 它們是第 0011、0014、0015、0016、0017、0018、0019 號管理員 |
| 前任管理員被調任到 B4 停車場 | 本棟大樓只有 B1 到 B3 |
| 員工編號是隨機的 | 0001 到 0216 號都已「入庫」。你是 0217 |
| 首席保管官是嚴肅的上司 | 他自 1957 年起就是首席。他是真心相信「被保護是好事」的人 |
| 聘用是因為能力 | 聘用條件是：沒有人會來找你 |

**本故事的鐵則：以上任何一條，都不能在遊戲中被直接寫出來。**

## 3. 人物

### 封存仁（首席保管官）

- **身分**：1957 年本局成立時即為首席。人事資料的「出生年」欄為空白。
- **欲望**：讓每一樣無人需要的東西都被好好保護，不再遺失。
- **他的信念**：一樣東西之所以會消失，是因為沒有人在找它。本局在找。所以在本局，沒有東西會消失。
- **他對玩家**：從頭到尾都很溫和、很照顧。這是最可怕的部分。他是真心的。
- **弧線**：他沒有弧線。他和第一天完全一樣。改變的是玩家對他每一句話的理解。
- **文件聲音**：與現在遊戲完全相同。一個字都不需要改。

### 第 0216 號管理員（前任管理員，不在場）

- 寫交接日誌的人。日誌愈後面，愈像寫給下一個人的提醒。
- 最後一頁只寫了一句話，而且被撕掉了一半。

### 七座特殊保險箱

每一座都有一份「行為觀察紀錄」，用的是人事考核的語言。

| 保險箱 | 觀察紀錄（摘錄） | 原為 |
|---|---|---|
| 害羞 | 「入庫前習慣在午休時間獨自用餐。」 | 第 0011 號 |
| 急性子 | 「入庫前曾三度申請提早下班。」 | 第 0015 號 |
| 健忘 | 「入庫前經常忘記自己的編號。」 | 第 0016 號 |
| 睡著 | 「入庫前於值班時入睡，至今未醒。」 | 第 0017 號 |
| 套娃 | 「入庫時攜帶家屬兩名。」 | 第 0018 號 |
| 退休 | 「服務 47 年後申請退休。本局核准。」 | 第 0019 號 |
| 第零號 | — | 第 0217 號 |

### 玩家（第 0217 號管理員）

- 聘用通知書的評估欄：「緊急聯絡人：無。」玩家第一次看到時只會覺得是表單沒填。
- 玩家不需要有任何背景。這個故事的力量在於：玩家本人就是這個角色。

## 4. 玩家的位置與弧線

1. **ACT 1**：好笑、溫暖、一切正常。
2. **ACT 2**：一些小細節不太對：員工編號、樓層、名牌。都可以有合理的解釋。
3. **ACT 3**：特殊保險箱的觀察紀錄像是在寫人。玩家可以選擇不往那裡想。
4. **000**：密碼來自玩家自己的紀錄。箱子裡是玩家的東西。
5. **結局**：玩家親手蓋章，把自己存入典藏室。

玩家最後失去的：「這只是一個好笑的遊戲」的感覺。
玩家最後得到的：一座以自己為原型的保險箱，留給下一位管理員。

## 5. 語氣與文件聲音

**這個故事的語氣規範只有一條：任何一句話，都必須同時可以被讀成無害的。**

| 文件 | 寫法 | 範例 |
|---|---|---|
| 局的官方文件 | 與現在完全相同 | 「已確認仍具有馬鈴薯的所有主要特徵。」 |
| 行為觀察紀錄 | 人事考核的語氣，描述保險箱 | 「入庫前習慣在午休時間獨自用餐。」 |
| 交接日誌（0216） | 一開始是工作紀錄，後來開始提醒 | 「如果你在讀這個，記得每天打一通電話給任何人。」 |
| 人事文件 | 表格，有些欄位是空的 | 「緊急聯絡人：無。」 |
| 樓層指引 | 一張普通的公告 | 「B1 檔案室　B2 機房　B3 典藏室」 |

### 封存仁的台詞

**一個字都不改。**這是本故事最重要的設計。玩家在結局後重讀，每一句的意思都會自己改變。

唯一新增的台詞，在結局：

> 本局現已保管一名保險庫管理員。安全風險評估維持不變。

這句話的句型，玩家從日常委託的重複藏品裡已經看過幾十次了。

## 10. 重讀改變意義

1. **聘用通知書**：「經本局審慎評估，閣下已獲錄用。」——前：例行公文。後：評估的是沒有人會來找你。
2. **001**：「本局認為，這正是需要加強保護的證明。」——前：冷笑話。後：沒有人來查看，就是被收進來的條件。
3. **連續失敗的台詞**：「目前沒有證據顯示箱內物品有逃逸意圖。」——前：笑話。後：它們真的想逃過。
4. **013**：「請不要和它們建立私人感情。」——前：官僚笑話。後：它們曾經是你的同事。
5. **重設進度**：「本局將假裝從未見過閣下。」——前：功能說明。後：本局對 0216 號做過的事。

## 13. 結局

1. 000 的開箱演出照常。燈光亮起，剪影出現。
2. 剪影的形狀是一個名牌夾。
3. 燈亮：玩家的員工名牌、一支原子筆、一罐空氣。
4. 證書頁：
   > **CERTIFICATE OF AUTHENTICITY**
   > 保險庫管理員　第 0217 號
   > RARITY：普通
   > CONDITION：管理員狀態
   > 已確認仍具有保險庫管理員的所有主要特徵。
5. 最後一個操作：按下旋鈕，存入典藏室。這一下是玩家親手蓋的章。
6. 封存仁：
   > 本局現已保管一名保險庫管理員。
   > 安全風險評估維持不變。
7. 回到標題畫面。員工編號：**0218**。
8. 主線任務列表的最後多了一座保險箱：**第 0217 號**。它的個性由玩家的遊玩紀錄決定：
   - 快速旋轉次數最多 → 「急性子」
   - 失敗次數最多 → 「健忘」
   - 慢慢轉、很少失敗 → 「害羞」
   - 很久沒有玩 → 「睡著」

   它的觀察紀錄用玩家自己的數據寫成，例如：「入庫前曾以每秒 41 格的速度旋轉轉盤，共 23 次。」

**最後一行字**（新的聘用通知書底部）：

> 評估項目：緊急聯絡人。結果：無。

## 17. 風險與界線

- **說破**：任何一份文件出現「人被變成保險箱」「他們被關起來」之類的句子，整個故事就失敗了。
- **惡意**：封存仁不是反派。他從頭到尾都在照顧玩家。
- **玩家真的感到被冒犯**：「沒有緊急聯絡人」可能刺痛真的孤單的玩家。結局的最後一個畫面可以留一個溫度：新的聘用通知書上，緊急聯絡人欄是**可以填寫的**（玩家可以轉動轉盤選字，或直接略過）。填了，第 0217 號保險箱就不會出現。這讓恐怖有一個出口，也是唯一一處「告訴」玩家該做什麼的地方，只用一個空欄位。
- **太難察覺**：線索要足夠多，至少有一半玩家能在結局前感到不對勁。
