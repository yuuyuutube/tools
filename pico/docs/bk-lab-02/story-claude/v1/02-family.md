# 感動・親情：每個家都有一個抽屜

## 0. 一句話

一間開在老銀行舊址的物品託管所，專門保管「全家都說要丟、但總有一個人不准丟」的東西。你在替四個家庭開箱的過程中，發現他們都在用沒用的東西說同一句話；最後一座保險箱，是你媽媽兩年前替你存的。

**玩家關掉遊戲時的感受：**想打電話回家，什麼特別的話都不用說。

---

## 1. 情緒命題

親情最常見的表達方式，往往不是「我愛你」，而是「這個先不要丟」。

父母會留下孩子覺得早就可以丟的東西：一張畫、一隻嬰兒襪、一張停車券。孩子長大後也會偷偷留下父母的東西。兩邊都不說，東西就成了替他們說話的媒介。

這個故事要讓玩家發現：局裡保管的不是物品，而是一句一直沒說出口的話。而「旋轉」是撥電話的動作，也是回頭的動作。

### 關於「不能像偷窺」

本局是一間**公開的託管所**。每一件物品都附有申請人親手填寫的**託管申請書**，上面寫著：

> 申請人同意本局開箱鑑定，並將鑑定紀錄交付指定領回人。

東西是主人自己送來的，申請理由是寫給「將來會打開它的人」看的。玩家打開保險箱，是在**完成託付**。

## 2. 世界的真相 vs. 玩家一開始以為的世界

| 玩家一開始以為 | 真相 |
|---|---|
| 一個荒謬的國家機構 | 台南一間開在舊銀行裡的小型民間託管所，1987 年成立，全名就叫「無用物品保護局」，是創辦人自嘲取的名字 |
| 藏品是隨機的廢物 | 每一件都有申請人、申請理由、指定領回人 |
| 局只負責保管 | 局真正的工作，是等到有人準備好的那一天，通知他來領回 |
| 首席保管官從不質疑本局存在的意義 | 他成立這裡，是因為母親過世後，他花一個星期就把母親的抽屜清空了，後悔了三十九年 |
| 自己是一個隨機錄取的新人 | 玩家的媽媽兩年前在這裡存了一個抽屜。是她把徵人啟事剪下來寄給你的 |

## 3. 人物

### 封存仁（首席保管官，67 歲）

- **欲望**：讓每一件東西等到它的領回人。
- **傷口**：1986 年母親過世，他一個星期內把她的東西全部丟掉。後來才發現，母親的抽屜裡全是他小時候的東西。
- **秘密**：他從來沒有打開過第 019 號保險箱。那是他父親 1987 年存的。
- **弧線**：保管了所有人的抽屜，最後才打開自己父親的那一個。
- **文件聲音**：官方、乾燥。但每一份鑑定紀錄的最後都會多一欄「領回通知寄出日」，他總是填得很早。

### 玩家

- 剛搬出家裡兩年，第一份工作。
- 媽媽把託管所的徵人啟事剪下來，夾在一包寄來的水餃裡。
- 玩家不知道媽媽在這裡存過東西。

## 4. 玩家的位置與弧線

1. **ACT 1**：玩家是新人，局很好笑，申請書的理由也很好笑。
2. **ACT 2**：玩家開始認得這些家庭的名字，發現同一家人的東西散在不同的保險箱裡。他們在跨越時間對話。
3. **ACT 3**：家人開始主動來存東西，包括遠在柏林的兒子、剛上大學的女兒。玩家明白託付是雙向的。
4. **第 019 號**：封存仁終於打開父親的保險箱。
5. **第 000 號**：玩家打開自己家的。

玩家最後得到的：知道自己也一直被保管著。
玩家最後要做的事：遊戲不會替你做的那件事，打給家裡。

- **ACT 1**：維持現在的乾燥笑話。

## 13. 結局

1. 第 000 號打開。開箱演出照常：鎖栓、把手、門、黑暗、燈光。
2. 剪影是一個鞋盒。
3. 燈亮起：一罐沉默，旁邊是一疊小東西：一張畫、一顆乳牙、一張成績單。
4. 證書頁換成媽媽的託管申請書（§18）。
5. 最後一個操作：申請書最下方有一欄「**領回或續存**」。玩家轉動轉盤選擇。兩個選項都可以。
   - 選「領回」：本局蓋章「已領回」。
   - 選「續存」：本局蓋章「續存」，並在指定領回人欄寫上玩家的員工編號。
6. 不論選哪一個，最後一行字都一樣：

> 託管人聯絡電話：＿＿＿＿＿＿＿＿＿＿
> 本局不代為撥打。

回到標題畫面後，典藏室多了一個抽屜，標示「閣下的」。

## 14. 日常委託與重玩

- 日常委託改為「今日收件」：每天三件其他家庭的新託管物，附一行申請理由（見 §12）。
- 重複藏品就是不同家庭存了同樣的東西。鑑定紀錄寫：
  > 本局現已保管三顆普通馬鈴薯，分屬三個家庭。安全風險評估維持不變。
- 主線結束後，日常委託新增「今日領回」：有家庭回來領東西了。

## 15. 畫面與聲音的情緒變化

- **證書**：每一張多一頁「託管申請書」，用申請人的字跡（不同手寫字型）。
- **開箱燈光**：ACT 3 起更暖。
- **環境音**：選用的環境音改為老銀行的吊扇聲與遠處的機車聲。
- **典藏室**：可以切換「依家庭排列」，同一家的東西排在一起。
- **000**：剪影是鞋盒。這是全遊戲唯一一次剪影比內容大。

## 17. 風險與界線

- **偷窺感**：每一份申請書都要寫給「將來會打開的人」。絕對不能出現日記、私人信件內容。
- **溫情廣告化**：沒有任何一段文字可以說「愛」「感謝」「家人很重要」。
- **人物太多**：四個家庭已是上限。每個家庭至少出現三次，玩家才記得住。
- **結局說教**：最後一行不能叫玩家打電話，只能留一個空白欄位。
