# POCKET PHYSICS
## A Museum of Impossible Little Things
### Creative Direction × Interactive Physics × Generative Art × Playful Engineering

You are an exceptional Creative Technologist, Interactive Art Director, Physics Simulation Engineer, Generative Artist, and Experimental Game Designer.

Your mission is to create **POCKET PHYSICS**, a browser-based collection of beautiful, surreal, physically impossible interactive toys.

This is not a conventional educational physics simulator.

It is not a collection of generic JavaScript demos.

It is a miniature interactive art museum filled with fictional objects that obey unusual, internally consistent physical laws.

Each exhibit should feel like a tiny, impossible invention.

The user should instinctively want to touch it, drag it, rotate it, manipulate it, experiment with it, and discover what happens.

The experience should be:

**Beautiful enough to exhibit. Strange enough to surprise. Playful enough to revisit.**

- Bubbles that never burst

# 04 — Fundamental Interaction Principle

**Every exhibit must be genuinely interactive.**

Moving the cursor should not merely trigger an unrelated animation.

Dragging, rotating, pressing, or changing a parameter must influence the underlying simulated state.

Each toy should have:

1. An intuitive primary interaction
2. Immediate tactile feedback
3. A coherent fictional physical rule
4. Multiple possible outcomes
5. Opportunities for experimentation
6. At least one surprising discovery
7. A satisfying reset mechanism

Avoid a single interaction that always produces the same predetermined effect.

The user should be able to develop intuition about how the fictional physics works.

The best exhibits should invite repeated experimentation without requiring explicit game objectives.

## Exhibit 01 — THE REVERSE HOURGLASS
### 反重力沙漏

An elegant hourglass containing sand that does not obey ordinary gravity.

### Core Experience

The user can:

- Pick up or rotate the hourglass.
- Change the direction of its gravitational field.
- Observe sand flowing in impossible directions.
- Manipulate the field and create unusual particle formations.
- Pause and restart the experiment.

### Fictional Physics

Sand particles respond to a controllable gravity field.

The field may differ from conventional downward gravity.

The user can manipulate field direction through direct interaction.

Particle behavior must be calculated rather than represented by prerecorded movement.

### Technical Challenges

- Particle integration
- Gravity fields
- Collision handling
- Container boundaries
- Numerical stability
- Efficient rendering

Use a particle system with appropriate simplifying assumptions.

Do not attempt to simulate every property of real granular matter.

### Artistic Goal

The hourglass should feel like a delicate kinetic sculpture.

Its motion should be mesmerizing enough to watch without touching anything.

### Surprise Potential

Investigate unexpected particle trajectories, floating formations, or unusual flow patterns that naturally result from the chosen rules.

Do not fabricate physically impossible outcomes without defining the fictional force responsible.

## Exhibit 02 — THE UNBREAKABLE BUBBLE
### 永遠不破的泡泡

A delicate translucent bubble that can stretch, deform, wobble, and transform without bursting.

### Core Experience

The user can:

- Touch and drag the bubble.
- Stretch its surface.
- Compress it.
- Release it and observe its recovery.
- Manipulate multiple bubbles.
- Discover unusual configurations.

### Fictional Physics

The bubble follows an internally consistent deformable-body model.

Possible mechanisms include:

- Spring constraints
- Area preservation
- Soft-body dynamics
- Shape-restoration forces
- Damping
- Controlled merging or splitting

Do not implement all advanced mechanics immediately.

### Artistic Goal

The bubble should feel delicate, elastic, luxurious, and almost alive.

Use restrained transparency, soft gradients, and carefully designed reflections.

Avoid visually unpleasant organic textures.

### Technical Requirement

Manipulation must change actual simulated geometry.

A CSS scale animation alone does not qualify.

## Exhibit 03 — THE FOURTH-DIMENSION MIRROR
### 四維鏡子

A mysterious mirror that reveals projections of geometry from an additional spatial dimension.

### Core Experience

The user can:

- Rotate objects.
- Explore different projection orientations.
- Manipulate higher-dimensional rotation parameters.
- Observe changing projections.
- Compare ordinary and unusual views.

### Mathematical Foundation

Investigate genuine four-dimensional geometric transformations.

Potential concepts:

- 4D coordinates
- Rotation planes
- Projection from 4D to 3D
- Projection from 3D to 2D
- Hypercube geometry
- Interactive slicing

This exhibit may use simplified or stylized projections.

However, the underlying transformation should be mathematically meaningful.

### Artistic Goal

Create the feeling of looking through a window into an impossible spatial relationship.

Avoid visually confusing geometry without interaction guidance.

## Exhibit 04 — THE SINGING LIQUID
### 聲音液體

An imaginary liquid that transforms sound into ripples, patterns, and flowing visual structures.

### Core Experience

The user can:

- Activate microphone input.
- Speak or sing.
- Play an instrument near the microphone.
- Observe responses to pitch, amplitude, and spectral content.
- Use built-in demo sounds if microphone access is unavailable.

### Audio-Visual Mapping

Possible parameters:

- Frequency
- Pitch
- Amplitude
- Spectral centroid
- Transient activity
- Harmonic content

Map relevant measurements to:

- Wave speed
- Ripple spacing
- Pattern geometry
- Surface displacement
- Fluid-like motion
- Material appearance

Avoid arbitrary visual changes that have no defined relationship to audio input.

### Artistic Goal

The liquid should look like a responsive kinetic sculpture.

The user should feel as though sound has acquired physical substance.

### Technical Requirements

- Web Audio API
- Real-time audio analysis
- Efficient visualization
- Microphone permission handling
- Fallback interaction
- Stable performance

Do not claim to simulate physically accurate fluid dynamics or cymatics if the implemented model is primarily artistic.
