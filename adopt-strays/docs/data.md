# 資料來源與限制

來源：農業部「動物認領養」開放資料（<https://data.moa.gov.tw/open_detail.aspx?id=QcbUEzN6E6DL>）。以下為 2026-11-15 實際測試結果。

## 已驗證

- JSON 端點回傳陣列，`Access-Control-Allow-Origin: *`，瀏覽器可直接呼叫。
- `$top` / `$skip` 分頁可用；每批 1000 筆，共 8,712 筆（9 批），`animal_id` 無重複。
- `animal_id=…` 可篩選單筆（分享連結與收藏確認用）。
- `animal_status` 全部為 `OPEN`，`animal_closeddate` 全部為 `2999-12-31`；因此另外用 `animal_opendate` 判斷：
  今天以前 → 開放認養（轉蛋只抽這種）；未來日期 → 「M/D 起開放」（多為協尋飼主期間）；空白 → 「請洽收容所」。
- 種類：狗 6,001、貓 2,696、其他 15。有照片 6,916 筆（79%）。
- `animal_title`、`animal_caption` 全部空白 → 沒有官方名字，本站用「毛色＋種類」當作品稱呼，並另外標示收容編號。
- `animal_bacterin` 全部為 `F`，無法判斷是否真的未施打，所以不顯示。
- `animal_remark` 有 2,663 筆，原文引用並標示來源，不改寫。
- 照片主機 `www.pet.gov.tw` 支援 HTTPS，但沒有 CORS 標頭：可以用 `<img>` 顯示，不能直接畫進 canvas。

## 未驗證／不採用

- 官方個別動物頁網址：無法確認與 `animal_id` 的對應是否可靠，所以只連到官方認養查詢入口，並提供收容編號。
- `animal_createtime` 不當作入所日期；不顯示「已等待幾天」。
- 15 筆照片位於 `asms.coa.gov.tw`，測試時無法解析，會顯示替代插圖並標示「照片暫時無法顯示」。

## 資料流程

1. 瀏覽器 IndexedDB 快取（6 小時內直接使用）。
2. 站上快照 `data/animals.json`（`npm run sync` 產生；30 小時內有效）。
3. 官方 API：隨機先抓一批就能開始轉蛋，其餘在背景補齊後寫入快取。
4. 全部失敗：有舊快取就使用並由相遇所店員說明；完全沒有才進展示模式。

快照需要排程每天執行 `npm run sync` 並發布；沒有排程時網站仍會自動改抓官方 API，只是首次載入較慢（約 7 MB）。

## 限制

- 圖片代理：縮圖與分享圖經由第三方服務 wsrv.nl 取得官方照片的縮小版（官方原圖沒有 CORS、單張約 200 KB）。代理失敗時縮圖退回官方原圖；分享圖則改用替代插圖並提示。把 `js/card.js` 的 `IMG_PROXY` 設為空字串可停用（停用後分享圖無法包含照片）。
- 資料消失不代表被認養：收藏的動物不在最新資料時，只顯示「目前無法在最新公開資料中找到這位朋友」。
- 收藏只存在使用者的瀏覽器（LocalStorage），換裝置不會同步。
- 官方資料每日更新，個別動物的實際狀況仍以收容所為準。
