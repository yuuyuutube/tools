# 美術設計規格

延續 `stamp-tour`（集章站）與 `retro-printer`（印印）的語言：米色紙底、三色 Riso 油墨、扁平幾何、少量錯版，直角的墨黑按鈕與圓形紙白圖示鈕。已實際開啟兩個網站並閱讀其 CSS／角色 SVG；Laundry Weather 參考圖未取用。

## 色盤

| 用途 | 色碼 |
| --- | --- |
| 紙底 / 卡紙 | `#e8e4dc` / `#fbfaf6` `#f7f4ee` |
| 墨黑 / 次要文字 | `#24221f` / `#6b6760` |
| 粉紅 / 藍 / 黃 | `#FF48B0` / `#0078BF` / `#FFE800` |

大面積只用紙色；三色油墨留給轉蛋機、相遇所店員、櫃台與卡片色塊。盆栽葉片與卡片錯版用 `multiply` 疊印出第二層顏色。

## 場景

- 櫃台：沿用集章站的藍色直條紋櫃台，全寬壓在畫面底部，主要按鈕在櫃台正面。
- 轉蛋機：桌上型、藍色蓋子有一對耳朵、粉紅機身（右下露出黃色錯版）、黃色旋鈕、墨黑出口。
- 相遇所店員「阿糰」：原創角色，黃色圓臉小生物、頭頂藍色的芽、粉紅圍裙。表情：眨眼、說話、開心、發呆、驚訝。
- 圖鑑（藍色立書）、小冊子（粉紅，有收藏時出現黃點）、相遇條件吊牌、盆栽（寬螢幕才出現）。
- 手機與桌面共用同一組物件，以機器高度為單位重新排位，不是整張縮放。

## 相遇卡

色塊底＋拱形照片窗＋偏移的錯版拱形；左上編號。收藏時才會蓋上相遇章（圓章、腳印、收藏日期）。配色由動物編號決定四組之一，與動物本身無關。沒有照片時用只代表「種類」的幾何插圖，並標示「目前沒有照片」。

## 動態

轉蛋約 3.5 秒：旋鈕 → 機器晃動 → 滾出 → 跳到中央 → 落地擠壓 → 停頓 → 搖晃 → 打開與彩屑 → 卡片彈出。任何時候可跳過；Reduced Motion 時直接顯示卡片。待機：眨眼、頭上的芽與吊牌輕晃、偶爾一顆轉蛋跳一下、發呆與閒聊。

## 介面原則

沒有眉標與裝飾性文字；能用圖示就不寫字（圖示為 MDI 與自繪 SVG，無 emoji）。全站 `user-select:none`（備註、編號等資料可選取）。下拉、單選、勾選、確認／提示視窗皆為自訂元件。
