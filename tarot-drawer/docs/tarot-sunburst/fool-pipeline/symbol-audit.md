# 愚者新流程試樣：圖像象徵查核

2026-11-17。對象為 `assets/fool-sunburst-sample.png`（黏墨 0.5），不是全副 22 張的驗收。本次僅查核與提出修訂，不改已偏好的筆觸或圖稿。

依據：Waite《The Pictorial Key to the Tarot》[愚者章](https://sacred-texts.com/tarot/pkt/pktar00.htm)、[大牌結語的行囊補述](https://sacred-texts.com/tarot/pkt/pkt0203.htm)、[歷史占卜牌義](https://sacred-texts.com/tarot/pkt/pkt0303.htm)，及 Smith 原牌圖。原典的靈性敘事、原圖實物、現代解牌及本案視覺判斷分開處理。

## 已保留

零號；向遠方／天空望的年輕旅人；輕快步姿；一朵手持白花／白玫瑰；另一手的肩杖及肩後行囊；躍起白犬；背後太陽；遠山、高地與懸崖。白犬未畫成狼；玫瑰不是地上背景花；行囊也不是單獨手提包。上述核心物件沒有明顯整項遺失。

## 需優先修正：懸崖與步伐的關係

Waite 描寫旅人停在崖緣、仍帶向前行進的動勢，同時望向天空而非下方。本圖有懸崖，但前方靴子與崖尖之間尚有一段寬裕岩面，讀起來更接近安全地走在高地。這是本案對畫面的判斷：元素存在，敘事關係仍不足。

建議保留仰望與步姿，將崖緣靠近前腳，或讓前腳更接近實際落差；不要改成已經墜落，也不需要增加戲劇化恐懼表情。此項優先於再加裝飾。

## 遺漏的原典細節：行囊符紋

原典明說行囊有繡飾，另於結語說明袋上的隱約符號與靈魂儲存的潛意識記憶相連。本圖主要只有束口、布褶與暗面，缺乏可辨的繡飾／符紋。

建議在受光面補少量清楚但不搶眼的紋樣；不能將任意新增符號宣稱為唯一正統圖樣，也不必自行加入神名字母。

## 次要差異與辨識問題

- **衣袍較素**：原典及原牌有華麗服飾。本圖保留衣袍、帽與羽飾，但表面幾乎全由排線構成。可加入少量衣緣繡飾或植物紋；不需逐個複製原牌裝飾。
- **白玫瑰可讀性**：白花仍在，並非遺漏；0.5 黏墨後花瓣較抽象。可只整理花瓣與花心，保留其他部位使用者喜歡的黏墨。
- **額外腰間配件**：人物右側畫面有狹長配件，可能讀成小袋，也可能誤讀為刀鞘。它不是愚者辨識所需；沒有露出刀刃，不能直接認定畫了武器。若保留，建議明確畫成柔軟布袋。

## 可保留，不列錯誤

朱橘服裝、金色太陽、藍色天空、木刻陰影、深色靴子、3:5 牌框與文字版式，均可作為本組的造型調整。若追求逐色忠實復刻 RWS，應另列原牌色彩差異；本案是重新詮釋，不將所有配色差異直接判為牌義錯誤。

不要求任意的太陽光芒數量、額外無限符號、固定占星標記、或每顆裝飾的神秘學對應。路徑可以保留作旅程意象，但不能代替臨崖的未知與風險。白犬的警示／陪伴有不同解讀，不當作 Waite 原文明說的唯一功能。

## 牌義表達與結論

現代常見的開始、開放與冒險，在本圖已可讀；需要靠臨崖關係補足未知及輕率的可能。Waite 的 Part III 歷史占卜詞彙比現代「新開始」更偏向愚行與失序，不能把兩者混稱為同一段原文，也不需為逆位另畫一張跌倒圖。

建議修訂順序：① 前腳／崖緣關係；② 行囊符紋；③ 少量服飾紋樣及白玫瑰辨識；④ 腰間配件澄清。其餘主體、構圖方向與黏墨 0.5 可保留。現階段仍為待修訂樣張，不能僅因符號都有出現就標示整張已通過象徵驗收。

## 使用者決定與後續修訂

使用者確認目前已足夠靠近崖緣、腰間配件已可讀成軟袋，因此上述兩項視覺建議不執行，保留原樣。行囊與服飾補紋樣，但明確要求不改線畫；白玫瑰只整理花瓣／花心辨識。

本次以色版新增行囊上的小型植物／菱形繡飾、衣領／袖緣／衣襬的金色色帶及胸前少量植物紋。白玫瑰維持白瓣，以淡冷色瓣部與小金色花心提升辨識。不增加黑色線條，不修改墨線 PNG 或 N 版；黏墨維持 0.5。這些裝飾是本案設計，並非宣稱原典規定唯一符紋。
