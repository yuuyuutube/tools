## 資產與處理責任

1. **平滑原稿**：`../line/0-smooth-aligned-rays.png`，保留原始 819 × 1229。
2. **木刻墨線**：`ink-generated.png`，1024 × 1536。使用內建 image_gen 編輯原線稿，以彩色示範作風格參照；完整實際提示見 `prompt.md`。加強人物主輪廓、細化遠景，加入衣褶、毛髮、行囊、靴與岩壁的方向性刻線。這是影像生成修整，局部輪廓可能改變，並非逐像素線稿濾鏡。
3. **語意遮罩**：`src/print/sunburst/fool-masks.js`。人工指定各物件區域與三色濃度。封閉白區由墨線分區後，以至少 75% 的多數標籤校正；大型或開放的地景保留手工遮罩。這份遮罩是本張專用，並非通用的自動理解模型。
4. **渲染器**：`src/print/sunburst/fool-pipeline.js`。將原稿與色版做同一等比例映射，使用既有 `printFrame()`，保留網站原有框色及中英文文字。PNG 黑線轉為墨量，保留反鋸齒；白底不當作不透明白紙蓋在色版上。
5. **套印**：沿用 `src/print/press.js`，新增每次呼叫可選的 `tune`，預設維持既有所有牌的設定。新試樣單獨調低抖動與偏移。墨線版有獨立的輕微模糊／黏墨控制，依使用者最新補充保留適量排線黏合，不追求完全乾淨向量線。
6. **最終圖**：`assets/fool-sunburst-sample.png`。本目錄亦保存四階段 3:5 PNG，以及可供後續再印的色版與透明墨線。

原稿到牌面映射為 `x = 8 + sourceX × 0.278`、`y = 44 + sourceY × 0.278`。採等比例排版，不把 2:3 人物強制拉長成 3:5。插畫之外的空間由天空／地景色版延續，牌框使用原本拱窗裁切。

## 驗收重點與限制

- 主角一人、一隻白犬；手持白玫瑰；肩杖與行囊、羽飾帽、太陽放射線、遠山、懸崖與路徑保留。
- 太陽光芒的黃版同時從其他色版挖空，避免與藍天疊出綠邊；框線與文字獨立印製。
- 木刻細線先保留原始解析度，再以可調強度製造適量黏墨。臉、手與玫瑰設局部減噪區；它減少飛白，不代表能自動修復不正確的解剖。
- 這張證明製作流程可行；不宣稱和原彩色圖逐像素一致，亦不代表其餘 21 張遮罩已完成。
- 目前主輪廓與木刻排線合在同一墨線母稿。原平滑線稿仍獨立保留；若往後需要單獨調整每一處排線方向／密度，仍應在美術母稿拆出排線層，不能只靠印刷滑桿。
- 預設試樣待使用者確認，不自動替換正式牌組、圖鑑或現有已確認版本。

現有 28 項測試通過；另以瀏覽器實際檢查四階段載入、900 × 1500 輸出、遮罩與套印效果。技術測試不能代替美術驗收。
