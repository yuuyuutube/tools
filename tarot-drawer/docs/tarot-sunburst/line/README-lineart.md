- 第二批：4.png、5.png、6.png

已移除卡牌邊框與文字、印刷網點和紙紋。遮蔽與截斷區域依原圖景物延伸補線。這些檔案是影像生成版本，細部與原圖可能有差異，並非逐像素複製。

每張交付尺寸與對應原圖一致：12 號為 1024 × 1536，其他為 819 × 1229。原始彩色檔未修改。
