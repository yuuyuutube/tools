## IV 皇帝

牌義以秩序、承擔與現世執行為主，成熟統治者坐於硬石座，與皇后的滋養形成對照。[Waite 原典](https://sacred-texts.com/tarot/pkt/pktar04.htm)

| 檢查項 | 最終成圖觀察 |
|---|---|
| 成熟戴冠人物、鬍鬚與石座 | 皆有，膝部抬起、袍褶下垂、甲靴落地，可辨坐姿 |
| 四公羊頭 | 座背兩個、扶手兩個，合計四個；作為雕飾連於石座 |
| 左右器物 | 人物右手／觀者左持安卡形杖；人物左手／觀者右托寶球 |
| 紅袍與甲冑 | 紅外袍、胸甲、兩條護脛與靴分層 |
| 岩山與河流 | 左右岩山、觀者右側彎河均在；山地較皇后乾冷 |
| 結構與線條 | 握杖手包住杖幹；托球手在球下；鬍、袍、石與甲有分向排線 |

待判斷：密刻加黏墨後，面部及胸甲暗面較濃，羊頭的細毛亦會合墨。四頭及器物輪廓仍可辨；是否減少細部墨量屬美術判斷，不自行降低已確認的 0.5。

## V 教皇

牌義為制度、傳承、教導與外顯的信仰秩序。兩門徒與祝福、鑰匙一起表現傳授關係。[Waite 原典](https://sacred-texts.com/tarot/pkt/pktar05.htm)

| 檢查項 | 最終成圖觀察 |
|---|---|
| 正面坐者與兩柱 | 膝、座背、台階可辨，柱上無 B/J |
| 三重冠、三橫杖 | 冠三層、杖三橫，各自可以清點；冠頂小十字另計 |
| 祝福右手、持杖左手 | 觀者左為兩指向上的祝福手；其餘手指彎曲，拇指分出；觀者右握杖 |
| 兩門徒 | 皆跪在前景；左衣玫瑰、右衣百合，各有獨立造型 |
| 兩把交叉鑰匙 | 前方兩門徒之間，雙環、雙幹與齒端完整 |
| 禮袍與十字 | 紅袍、淺色中帶、三胸前十字皆保留 |
| 手部與衣料 | 手掌大小相近，腕接袖口，袍在膝部形成坐姿起伏 |

待判斷：祝福手的彎曲無名指與小指，在套印後縮圖容易合成一個暗面；完整墨線有手指結構，120px 不能可靠點數。門徒背部繡紋較原彩色參照集中於大花，屬紋樣變化。

## VI 戀人

牌義為關係、坦誠、價值與選擇，保留人物—伴侶—上方有翼者的視線層次；不將畫面縮成愛心或牽手。[Waite 原典](https://sacred-texts.com/tarot/pkt/pktar06.htm)

| 檢查項 | 最終成圖觀察 |
|---|---|
| 兩成人與展臂有翼者 | 共三人，翼根接於上方人物背部；雲帶分出上下層 |
| 太陽與中央山峰 | 頂部光輪放射線與下方單峰山可辨 |
| 知識樹、果實、蛇 | 觀者左，蘋果與蛇均在 |
| 生命樹 | 觀者右，以火舌形枝葉表現原典的十二果實；不是另畫十二個蘋果 |
| 人物與樹的對應 | 已改正輸入線稿的男女配置：女人在知識樹一側、男人在生命樹一側 |
| 視線鏈 | 女人仰望上方；男人朝女人一側；不是兩人同看觀者 |
| 手與地景 | 開放手掌、腳落地，山、河與草地有景深 |

**需使用者判斷的差異**：本版採完整古典衣袍，與 RWS 的坦露人物不同，會減弱「毫無遮蔽」的直接圖像表現。圖像工具的第一個版本請求遭拒絕，最終以完整衣裝完成，未將此差異隱藏。右樹的細火舌與葉簇在黏墨後容易相連，十二單元的成圖辨數不足以宣稱嚴格通過；如需逐枚清點，應另整理枝葉，而不是只按提示詞認定十二。
