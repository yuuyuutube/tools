塔羅平塗修色・Light Paint 專案

22 張牌，1024 × 1536；沒有網點、紙紋、套印位移、牌框或牌名文字。上層是透明墨線，下層是可修改的純平塗。

  1. 下載需要的分層專案 JSON，在 Light Paint 按「載入專案」。
  2. 選擇「色版・在這層修色」，使用吸色與硬圓筆修正。顏色已附在專案色票中。
  3. 填色工具只參照目前圖層，不會參照上層墨線；兩區若同色相連，填色可能一起改色，請復原後用筆刷。
  4. 保存 JSON。輸出純色版 PNG 前，先隱藏「墨線」；輸出完成後可再顯示墨線。

畫布是完整圖面母稿，網站會沿既有圖窗裁切。完成後保留 JSON 與純色版 PNG，便可交回整合、重新分色與套印。
