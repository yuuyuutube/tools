# 正式牌面：純插畫 WebP ＋ Web 介面

2026-11-19。依使用者要求，正式牌面的 WebP 只含插畫；插畫以外的所有卡牌介面都由網頁產生。

## 資產與組版

- `assets/faces/<card-id>.webp`：654×870 的純插畫，對應 300×500 牌面中的 x=41、y=76、218×290 圖窗。不含圖窗描邊、框外紙底、卡框、牌號、牌名或框外裝飾。
- `src/art/frame.js`：使用 SVG 產生紙底、程序紙紋與所有介面圖層，並在共用圖窗內裁切插畫。紙紋使用 SVG filter，不是背景圖片。
- `src/print/sunburst/layout.js` 的 `sunburstFrameLayers()`：介面各部分的共同來源；既有套印參考 PNG 仍使用相同幾何。抽牌及海報使用同一份 SVG 組版。
- 插畫內的符號、卷軸字樣與繪畫裝飾屬於插畫，不會從圖中移除。

每張前景 SVG 有獨立的 `data-card-layer`：`paper`、`illustration`、`border`、`accent-border`、`window`、`number`、`rule`、`title`、`subtitle`、`ornaments`。各圖層分別控制展框、拉線與牌名浮現，不會縮放插畫內容。

## 保留插畫質感

印刷引擎在插畫 Y/O/B/N 完成、FO/FN 介面印版尚未套印前取得快照，再裁切出圖窗的矩形範圍。如此不會把圖窗的深色描邊烘進 WebP。插畫中的網點、墨線黏墨、紙齒、紙面顆粒與套色偏移保留；少量紙纖維也以同一批隨機參數繪到插畫快照，不含後續介面色版。

Web 圖窗負責圓角裁切。純插畫不會以整張牌面的比例伸縮，且各牌原本的圖面擺位及裁切維持不變。

## 匯出與驗證

[純插畫匯出頁](../../illustration-assets.html?batch=01)：`batch=all` 可產出全套；`batch=00` 是愚者，`01`～`07` 為既有批次。匯出 PNG 存入 `fool-pipeline/fool-illustration.png` 或 `batch-XX/N-illustration.png`；WebP 存入 `assets/faces`。未來也可用 `scripts/export-faces.py` 從這些純插畫 PNG 重建，該腳本不接受完整卡片當來源。

[資產驗證](illustration-assets-validation.json)記錄所有圖檔尺寸、雜湊與畫面回歸結果。愚者另比較同次渲染在啟用／停用快照回呼時的結果，檢查回呼不改變套印。與既存愚者 PNG 的差異另外保留，不能把歷史快照差異當成新增重繪。

新增測試核對正式 SVG 僅含一張插畫圖片、介面以獨立 SVG 圖層存在、文字實際是 text 節點，以及海報多張牌的裁切／紙紋 ID 不衝突。海報仍先將插畫內嵌為 data URL，避免 SVG 載成圖片時漏掉外部插畫。

完整牌面參考 PNG 與 Light Paint 編輯專案仍保留各自用途；正式網站不再把完整牌面 WebP 當作一張不可分拆的圖片。


實際瀏覽器驗證：正式流程完成單張翻牌，檢查到一個插畫 image 與三個獨立文字 text 節點；1080×1620 分享海報成功下載並確認紙底、插畫及 Web 框字完整。31 項測試通過。

## 翻牌微動態

圖窗的「外框線」展開，插畫內容本身不位移、不縮放、不淡入。`src/ui/window-reveal.js` 直接逐影格計算 SVG path 的 `d`，不使用 CSS／SVG scale。

- 圖窗寬高由 94% 展開至 100%，歷時 420ms；固定點為圖窗的 x=50%、y=100%，即卡面座標 (150, 366)。底部高度與水平中心全程不變。
- 外框線寬全程保持 2.8 卡面單位；圓角座標依框格大小重算，沒有對描邊做縮放。
- 插畫 image 固定為 x=41、y=76、width=218、height=290；裁切 path 與框線使用同一組座標，框格展開時只揭露更多內容，不移動內容。
- 展開開始 180ms 後，裝飾橫線由中央向兩側伸展，歷時 220ms。
- 開始 360ms 後，中英文牌名以 280ms 柔和淡入，由下方 2 個卡面單位移回原位。

展開開始時間為翻牌時間的 60%（目前 468ms），整組在開始後 640ms 完成。外層卡片邊框與牌號保持固定；逆位使用原本外層旋轉。返回或重抽會取消尚未完成的 path 動畫並還原完整圖窗。

插畫在牌背顯示時開始解碼，翻面前等待就緒。減少動態設定會直接套用完整圖窗，沒有逐影格展開；分享海報與圖鑑保持靜態完整圖窗。

測試驗證：不同進度均固定底部中央、最終 path 與共用 WINDOW 相同；動畫只寫入 `d`，不改 `stroke-width` 或 `transform`；取消、重抽與零時長狀態都會還原完整圖窗。

## 手指與滑鼠的牌扇操作

手指／觸控筆拖曳使用 1.6 個牌距換一張，恢復使用者要求的靈敏度；滑鼠按住拖曳使用 3.2，放開不繼續慣性滑動。既有手指慣性的摩擦與上限維持不變。

窄版面的滑鼠 hover 只抬牌，不會把牌扇中心自動改成游標下的牌，避免牌扇位移後觸發下一張 hover 的連鎖跳動。鍵盤方向鍵仍會把焦點牌捲入視野。輸入政策集中在 `src/ui/fan-input.js`，測試覆蓋觸控與滑鼠速度比例、事件拆分與 hover 不移動牌扇中心。

窄版面瀏覽器檢查：390px 下滑鼠按住拖曳可正常移動，仍保留 22 張待選牌，未誤抽；放開前後的牌面 transform 維持不變，確認沒有滑鼠慣性續滑。手指與滑鼠的位移比例另由單元測試驗證。新版展開與窄版面抽牌檢查通過，全部 34 項測試通過。

框格動畫瀏覽器比對：已讀取 94% 與完成狀態的實際 path；框線／裁切同步改變，線寬兩次均為 2.8，插畫 x／y／width／height 完全相同，沒有 image transform。紀錄為 `window-reveal-browser-check.json`。全部 38 項測試通過。


## 暈墨與揭牌順序（2026-11-19 更新）

正式 Web 卡面及分享海報的框線、牌號、裝飾與文字，使用相同的靜態 SVG 暈墨。保留原始清楚筆畫，在底下合成少量膨脹、紙齒擾動與柔化的墨層；框線較明顯、中文牌名較輕、牌號與英文最輕。濾鏡使用固定種子與卡面座標，不會逐影格更換紙齒；插畫 image 及紙底均不套此濾鏡，也沒有更改 WebP。

| 卡片翻轉 | 0 | 780 |
| 圖窗外框展開 | 468 | 888 |
| 裝飾橫線 | 648 | 868 |

本次驗證：39 項測試通過；瀏覽器完成正式單張抽牌，確認插畫未套暈墨濾鏡、描邊仍為 2.8、各 Web 圖層依種類使用獨立暈墨，控制台無錯誤。畫面存於 `web-ink-bleed-preview.jpg`。


## 窄版牌扇的橫向捲動

選牌中的窄版牌扇可用觸控板左右滑、滑鼠橫向捲動或 Shift＋滾輪操作。WheelEvent 無法可靠區分滑鼠與觸控板，因此依橫向捲動意圖處理，不依裝置名稱猜測。以水平為主的 deltaX 或 Shift＋deltaY 換算成牌距，並統一像素、行、頁三種單位；靈敏度沿用滑鼠的 3.2 個牌距。

直向捲動、Ctrl／觸控板縮放、拖曳中、完整寬版牌扇與結果畫面均不介入。橫向操作會中止原先手指的慣性，不另加第二層慣性；兩端以牌組範圍限制。原有手指 1.6、滑鼠拖曳 3.2 及 hover 只抬牌的規則維持不變。新增單元測試驗證方向、三種單位、Shift、垂直排除與縮放排除；全套 41 項通過。

`poster-preview.html` 直接使用正式 `posterBlob()`，可檢查單張、三張（含逆位）的輸出並下載 PNG；正式抽牌結果的分享圖也使用同一份生成流程。本次瀏覽器輸出為 `share-poster-single.png`、`share-poster-three.png`；已目視確認日期沒有溢出章框，牌名、關鍵字與章框互不遮擋，控制台無錯誤。


## 暈墨編輯介面

`ink-editor.html` 可逐張預覽 22 張牌，並排比較舊版輕暈墨與調整後結果。三個獨立滑桿分別控制框線／裝飾、中文牌名、英文／牌號，範圍 0～600%；100% 對應第一版輕暈墨，0% 僅保留原始主線。預覽倍率可選 100%、150%、200%。

`src/art/ink-settings.js` 集中管理設定、數值驗證及本機儲存。新版預設分別為 200%、200%、150%；固定種子的擴散層依倍率加重，清楚的主線與插畫保持不變。`faceSVG(..., {inkBleed})` 可明確傳入預覽值；未指定時讀取同來源瀏覽器的 `tarot-ink-bleed-v1` 設定，因此正式抽牌與分享海報會使用同一組參數。

「儲存並套用」會保存在目前瀏覽器；已開啟的抽牌或分享預覽頁需重新整理，以免沿用既有卡面／海報快取。匯出／匯入 JSON 可在別台電腦或瀏覽器搬移設定；匯入先預覽，需再儲存才套用。不會由瀏覽器直接改寫全站預設檔。

驗證：44 項測試通過，涵蓋無本機儲存、損壞設定、數值邊界、零暈墨與最大倍率。瀏覽器實際測試滑桿至 600% 可即時更改濾鏡，主線仍為 2.8，重新整理後可讀回已儲存值；測試後恢復建議加重設定。已確認全關閉、換牌、200% 放大及 390px 手機排版（頁面無橫向溢出）。預覽紀錄為 `ink-editor-preview.jpg`。


## 乾式印刷質感（紙齒缺墨、墨邊毛刺、少量乾墨）

`ink-editor.html` 已改名「卡面印刷質感調整」。乾式三個滑桿範圍為 0～100%，獨立於原有濕式暈墨；濕式控制保留在可展開區域。「建議乾式」預設為紙齒 55%、毛刺 50%、乾墨 18%，濕式三種倍率均為零。尚未儲存新六項設定的瀏覽器，編輯頁會先展示乾式提案，但不會自動覆寫原先抽牌設定；使用者按「儲存並套用」才生效。

乾式濾鏡使用固定種子的紙齒遮罩、細微邊緣位移及水平拉長的低濃度缺墨。紙齒與乾墨以 alpha 遮罩挖除墨層，不疊紙色或模糊光暈；小字降低處理強度。乾式預設沒有高斯模糊擴散，插畫 image 與圖窗幾何不變。與濕式同樣用於 Web 卡面及分享輸出。

設定檔升為 version 2，包含 tooth、edge、dry；仍可匯入 version 1，新增乾式參數歸零。保留既有儲存 key，以便讀回先前濕式設定。新參數會限制在 0～1，原有三種濕式倍率維持 0～6。

驗證：45 項測試通過；瀏覽器確認毛刺拉至 0 可移除邊緣位移、乾式預設三種模糊半徑皆為 0，愚者與隱者的卡框、文字、圖片顯示完整。調整頁及 200% 放大比較已檢視，控制台無錯誤。比較畫面為 `dry-print-editor-preview.jpg`。


## 使用者選定的正式預設

依使用者提供的 version 2 設定，正式預設更新為 line=1.5、text=2、fine=1.8、tooth=0、edge=0.7、dry=0。抽牌與分享圖共用此設定；既有瀏覽器的自訂設定仍優先。編輯頁初次開啟使用全站預設，不再自動載入乾式提案；「全站預設」按鈕可取回這組值，「建議乾式」仍保留作為另一個預設。可攜設定檔為 `print-texture-default.json`。
