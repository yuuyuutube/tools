## 木刻陰影與結構檢查

參照已確認愚者的「2 · 主次墨線＋木刻陰影」，比較相同縮放下的暗部份量、細線與主輪廓之間的區分、明亮留白及陰影的轉折，而不是在整張圖鋪同一種斜線。

- 皇帝：披風與膝袍依原衣褶分區；甲片陰影順脛部轉折，鬍鬚沿毛流，石座有側面與底部陰影。四個羊頭、兩手器物與臉部保留清楚輪廓。
- 教皇：袖口、兩膝、垂落的中段衣襬各有獨立排線；門徒背、袖與跪膝分開處理。持杖手的三條內線局部收細，以實際黏墨輸出檢查分指。
- 戀人：已撤掉先前交叉、零碎的排線。兩翼逐片處理羽片交疊處，衣服沿原有袖褶與斜披布的曲線排列；每組排線在轉入受光面時收尖。兩成人的皮膚使用較輕的轉面陰影，不沿用石材的線距與方向。
- 全組：主輪廓加重只作用於原墨線附近；不把選區路徑當成新的人物輪廓。手指與臉部設有減重／保護區。排線不應跨出原有物件輪廓。

這些檢查說明處理方式與可見差異，不代表美術品質已獲使用者認可。精緻度、疏密及墨量仍請以完整墨線與成圖自行判斷。

| 坦露與垂布 | 保留原稿的成人軀體及腰部垂布，未改成完整衣袍 |
| 手、足、翼根、衣褶 | 未更動原位置；加工只增加線重與物件內陰影 |

**需使用者判斷的原稿差異**：

1. **人物與樹的對應相反**：原稿為觀者左男性／知識樹與蛇、右女性／生命樹；RWS／Waite 是女人在知識樹旁、男人在生命樹旁。本次不擅自交換，只明確記錄。
2. **視線鏈不完整**：原稿兩人互看，女人沒有明確抬頭望向上方有翼者；因此「男人→女人→上方」的視線關係未成立。
3. **生命樹十二單元辨識**：原典文字稱十二果實，附圖常呈火舌狀。這份線稿的葉片與火舌混在一起，目前不應宣稱已嚴格通過十二枚清點，若要整理須另經使用者決定。
4. **日光位置**：本稿以有翼者的放射光環兼作日光，與原圖獨立位於頂端的太陽有所不同，屬造型簡化。
