## 修正方式

`src/print/sunburst/colour-repairs.js` 在既有標籤、區域調整完成之後、分色印版產生之前執行。以原始平滑線稿辨識物件邊界，避免木刻排線把同一件物體分成碎色；開放的地面與雲層採人工描出的範圍，不讓矩形填色跨過自然邊界。這些是 Web 色版規則，不是重畫人物或重新生成插畫。

- 12：光環外碎色、草地延伸、誤色樹葉。
- 20：頂部天空色帶、雲下錯色天空、棺木正面色帶。
- 17：星形色版重新建立清楚輪廓，整理水岸與岩石碎色。
- 21：花環內外背景填齊，移除上下色帶及雲內碎色。
- 10：天空顏色統一，雲層使用獨立形狀，清理漂浮色點。
- 16：保留暴風雲明暗，移除雲內小色島、整理岩面。
- 19：清理太陽光芒以外的天空色點。
- 14：鳶尾花瓣分色，限制小區域填色以保護河道，整理岸邊石頭。

星形維持參考圖的配置，本次沒有處理牌義符號數量、審判旗十字或人體結構；這些和色版修正分別審閱。
