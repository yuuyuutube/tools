## 命運之輪

依 RWS 原圖：上 T、右 A、下 R、左 O，依圓周方向旋轉；四個斜角依序 י（右上）、ה（右下）、ו（左下）、ה（左上）。為避開本稿既有斜輪輻，希伯來字母在各斜角扇區內順時針偏 10°，不改字序，不鏡像。

參照：https://commons.wikimedia.org/wiki/File:RWS_Tarot_10_Wheel_of_Fortune.jpg

用 scripts/repair-wheel-letters.swift 的獨立手寫字形路徑，補到原 1024×1536 透明墨線。像素驗證：新增／增強墨線 3515 像素，移除墨線 0，字母區以外 alpha 變化 0（pixel-verification.json）。原平塗 PNG 未改。

重建 10 號正式插畫與翻牌 N 墨線版，Y/O/B/paper 檔案保留原位元組，沒有變更任何其他牌圖。preview.png 同步原平塗＋修正墨線，並不是正式網點圖。

before/ 保存修改前墨線、預覽、正式插畫與五色版。review.html 可看正式圖前後對照與 120px 縮圖。Light Paint JSON／ZIP 和歷史 batch 圖沒有重打包；既有烘焙入口讀取目前平塗和透明墨線，可保留補字。

本輪不補四煉金符號，也不繼續上一批構圖修正。沒有把補字當作命運之輪所有符號均已通過。
