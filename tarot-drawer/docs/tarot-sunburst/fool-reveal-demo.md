# 愚者：墨稿到彩色的套印翻牌試作

試作頁：`fool-reveal-demo.html`。獨立展示 0 號牌，不接入正式抽牌流程。

## 動態時序

以重播開始為 0ms：翻牌 0–780；圖窗外框從第一眼就可見，468–888 展開；黃版 700–930、朱橘版 850–1080、藍版 1000–1260；分層疊印淡回完整原始插畫 1260–1420；橫線 648–868；牌名 828–1108。整段時間軸縮短為 1600ms（前版 3300ms），三色之間與卡面動效均有重疊。時間軸可自由停留、倒退，另有慢速與墨稿／完成狀態按鈕；墨稿按鈕停在 600ms，所有色版仍為 0。

## 來源與對齊

`buildFool({captureInkLayers:true})` 透過 printCard 的可選 onInkPlate 回呼，在同一次套印運算擷取紙底及 Y、O、B、N 的實際墨色覆蓋率。不是重新繪圖，也不是將彩色圖轉灰階。墨線的黏墨、木刻、紙齒與各色版錯位，和本次成品共用取樣及隨機種子。

所有階段以 illustrationAsset 裁切成 654×870，置於卡面 x41/y76/width218/height290。墨線全程位於各色版上方，各色版以 multiply 混合；插畫本身不縮放／位移。框線及裁切用既有 windowFrameAt 的 path 幾何展開，線寬保持 2.8。固定圖片底下保留完整、不透明的原插畫，分層淡出後即為完整原圖，避免雙向淡入淡出讓紙底穿透而閃亮。

## 驗證

瀏覽器以 ?verify=1 比較擷取印版開／關：成品差異 0 個 channel。中間分層與完整圖的每色頻平均差約 0.387/255，最大差 79，包含 alpha 量化與後加紙纖維；最終畫面使用完整原插畫，沒有保留這些中間合成誤差。墨稿／完成兩端的插畫座標、尺寸與 transform 一致。已檢視墨稿、兩色套印途中、完成卡面，控制台無錯誤。既有 46 項測試通過。

頁面首次載入會即時計算原始印版；減少動態設定下直接顯示完成卡面。此試作以獨立預覽頁保存並發布，尚未接入正式抽牌流程。

加速並行版瀏覽器確認：600ms 色版皆為 0、圖窗外框 opacity=1、線寬 2.8；920ms 黃版約 95.7%、朱橘約 30.4%、牌名約 32.9%，確認上色與文字同步進行。
