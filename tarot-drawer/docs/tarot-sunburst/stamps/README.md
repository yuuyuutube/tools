# 九款牌背日期印章

設計預覽：`stamp-preview.html`；可切換九款、日期、乾墨缺損、22 張預覽牌面及單張／三張分享圖，並下載 PNG 或獨立 SVG。

原牌背目錄有九款，包括目前七款輪替以外的雪境雙狐與朱砂雙鶴。每款均使用對應主體與各自的單色、框線：星冠八角、花葉橢圓、貝形波浪、莊園卷葉、扇紋切角、冰晶尖拱、如意雲紋、花瓣曲線、回紋八角。

`src/poster/stamps.js` 定義可編輯的 SVG 日期章；`posterSVG()` 只有在 result.stampId 明確指定時才使用新章，未指定仍使用原本眼睛日期章。尚未自動綁定正式抽牌的牌背。新版日期水平排字，不含網站名稱，徽記在日期上方。缺墨採固定紙齒遮罩及少量邊緣擾動；每枚章的濾鏡 ID 獨立。

本資料夾含九枚獨立日期章、catalog.svg 全套向量總覽、preview.jpg 網頁總覽、兩份實際分享 PNG 樣張與 catalog.json 配色／名稱資料。樣張日期為 2026.11.20。

驗證：49 項測試通過；確認九款皆有獨立框形、對應牌背資產、有效 SVG、不同濾鏡 ID，單張／三張可組版。瀏覽器核對九款日期均在內框範圍中，夜蛾單張／雙鶴三張實際 PNG 可下載，命運之輪四字牌名不碰章框，0% 可關閉缺墨。390px 排版沒有頁面橫向溢出，控制台無錯誤。
