# 新流程第一批：1–3 號最終成圖查核

日期：2026-11-17。狀態：**本批成圖待使用者判斷，尚未 approved／integrated**。0 號愚者已確認；4–21 號尚未執行這個新流程。本紀錄不沿用舊 SVG 版本的核准狀態。

本批以使用者線稿為輸入，內建 image_gen 編輯為歐洲寓言木刻墨線，再用手工語意遮罩、封閉區域校正與 Web 套印製作。三張各自的實際提示見 `1-prompt.md`、`2-prompt.md`、`3-prompt.md`。保持網站 3:5、900 × 1500，黏墨 0.5。畫面、字體及框色延續愚者；原始參照、原線稿與已確認愚者均保留。

## 查核依據與分界

- Waite《The Pictorial Key to the Tarot》[魔術師章](https://sacred-texts.com/tarot/pkt/pktar01.htm)、[女祭司章](https://sacred-texts.com/tarot/pkt/pktar02.htm)、[皇后章](https://sacred-texts.com/tarot/pkt/pktar03.htm)，並對照章節連結的 Pamela Colman Smith 原圖。
- 既有 `docs/redraw-plan.md` 逐牌清單與網站現代牌義。
- 原典文字、原圖上看得見的符號、現代解讀與美術判斷分別記錄。不為無來源的小裝飾附加唯一神秘學意義。
- 查核對象是 `assets/sunburst-1-final-3x5.png`、`sunburst-2-final-3x5.png`、`sunburst-3-final-3x5.png`，不是只看提示詞或未上色墨線。

## I 魔術師：意志、資源與上下傳導

| 必核項目 | 成圖處理 |
|---|---|
| 人物右手舉杖向天、左手指地 | 觀者左上舉、右下指地；不是鏡像交換 |
| 桌上四器 | 杯在觀者左；五芒星幣在左中；劍橫置中間；植物木杖斜置右側。上舉法杖另計，不拿它代替桌上權杖 |
| 無限符號 | 頭頂橫向 8，完整可見 |
| 銜尾蛇帶 | 腰部閉環，有蛇頭與口尾接合造型 |
| 玫瑰與百合 | 上方玫瑰藤；下方花園含紅玫瑰與白百合 |
| 紅外袍、淺內衣、人物與桌 | 保留上下動勢及桌前資源展示，不以舞台戲法角色取代 |

**留給使用者判斷**：黏墨 0.5 下，蛇頭與口尾相接的細節較容易併成厚暗線；物件存在，但縮圖可能只讀成橢圓腰飾。五芒星幣中心也較厚。這是辨識風險，不把「數量都有」當作最終驗收結論。

**本案造型差異**：上舉法杖為兩端圓飾；花園與桌面重新組織，仍保留四器。沒有新增必須依特定數量解讀的花朵數。

## II 女祭司：靜觀、隱秘知識與門檻

| 必核項目 | 成圖處理 |
|---|---|
| 安靜端坐、左右雙柱 | 觀者左黑柱、右淺白柱 |
| B／J 字母 | 左 B 挖白、右 J 深墨；由程式排字，不依賴影像生成文字 |
| 書卷 TORA | 膝上橫卷，TORA 可讀；雙手與卷軸接觸 |
| 胸前十字 | 保留直交十字 |
| 月角冠與中央圓球 | 頭頂兩側月角與中間球體分明 |
| 足邊弦月 | 下方前景金色弦月 |
| 石榴與棕櫚帷幕 | 頭後及肩兩側可見重複植物紋，不用普通空白幕取代 |
| 水域、流動衣袍 | 柱外水線與長袍保留 |

**明確需要使用者決定的差異**：卷軸兩端及大部分表面仍完整露出，主要由雙手遮住；「披衣半遮卷軸」表現不充分。Waite 特別把半遮連到部分言明、部分隱含，因此這項不能直接視為無關裝飾。建議考慮增加衣料遮住一端，是否修改由使用者決定。

**其他造型差異**：月角畫為左右月形裝飾；胸十字著金色，並非要求完全復刻原圖色彩。柱上有雕刻與排線，不能讓墨線紋理干擾 B/J 的辨字。

## III 皇后：滋養、豐饒與可見世界

| 必核項目 | 成圖處理 |
|---|---|
| 十二星冠 | 原王冠輪廓與冠上飾紋保留；清除原外弧十一星，沿同一條對稱橢圓弧重新繪製十二顆五芒星 |
| 金星心盾 | 觀者右下，心形內完整 ♀（圓、直幹、橫畫） |
| 頂端球體權杖 | 人物右手持球杖，觀者左側 |
| 放鬆坐姿與軟墊 | 有扶手、座背與軟墊，長袍鋪在膝上 |
| 石榴袍紋 | 胸前及裙面四處果實／枝葉紋；數量不是原典指定數字 |
| 成熟麥田 | 前景穗粒、莖與葉完整 |
| 森林與瀑布 | 左側有跌水與下游，兩側樹林保留 |

**依使用者回饋修正**：使用者確認冠上的飾紋不會誤認為外弧星星，要求還原原王冠。本次已撤銷冠形重畫，保留原輪廓與飾紋；撤掉偏於右側的補星，改將外弧整組重新繪製為十二星。十二顆星使用相同尺寸，沿頭頂對稱橢圓弧排列；墨線階段、上色階段及最終印版同步修正。原生成墨線另留存供追溯。

**造型紀錄**：十二星仍採原設計浮於頭頂的環弧，王冠本身的飾紋保留。已在完整墨線與最終套印輸出確認外弧十二星，兩端對稱；不再將冠飾列為需要修正的問題。黏墨維持使用者指定的 0.5。
