# 塔羅牌面：審核意見與具體改善方向

日期：2026-11-16  
用途：交接繪圖者／SVG 實作者，作為既有牌面修訂與逐張驗收的工作文件。  
審核對象：目前 `gallery.html` 已登記、可實際載入的 **11 張新版正面 PNG**。本文件所稱「現稿」均指這些作品，不是圖鑑 BEFORE 欄的最初舊版，也不包含後來已撤銷的節制、星星、太陽草圖。  
本次交付：僅新增此文件；不修改圖稿、網站、牌義文字或核准狀態。

## 1. 給接手繪圖者的核心要求

使用者指定方向：

> 不要火柴人畫風。要有寓言故事的神秘感、比較歐風的角色風格，有一點點擬真。整體線條粗細與力道應與「隱者」相近，陰影須使用木刻排線。人物、動物與空間的立體結構必須合理，不可漏掉或搞錯大阿爾克那的牌義及圖像象徵。實作使用手寫 SVG，不使用圖片生成。

執行時請落實以下要求：

1. **先建立形體，再畫輪廓。** 必須能交代頭顱、肩帶、胸腔、骨盆、關節與重量，不能把輪廓畫完後才以幾條線假裝有解剖結構。
2. **略帶擬真不等於照片寫實。** 可保留寓言式的簡化與延長比例，但手腳必須接在合理位置，器物握得住，坐者坐得下，動物的物種與關節方向必須明確。
3. **以隱者校準畫風與線重。** 參照它的輪廓力度、冷暖主次、衣袍形體和敘事焦點；不是照抄它的紅袍、側臉、鬍子或構圖，也不是把它每個局部都視為無須改善。
4. **手寫、可編輯的 SVG。** 人物、動物、器物、地景與排線應可分層修改。不可用 `<image>` 嵌入點陣圖冒充 SVG，也不可將生成圖片自動描圖後當作手繪成果。
5. **符號存在和畫得清楚是兩回事。** 路徑或測試顯示元素存在，不代表完整牌面能辨識其數量、方向、文字與關係。
6. **先做一張代表作確認。** 不要將尚未通過的人體、手型、坐姿或動物模板擴散到整批。

| 優先級 | 定義 | 處理原則 |

## 3. 整組共通審核

### 3.1 應保留的成果

- 墨藍／朱橘框色、紙底、中英文字體與版式已有一致性，具有牌組辨識度。
- 每張可有獨立插畫色盤，現有冷暖差異值得延續，不必全組改用同一組人物或背景色。
- 隱者的燈光、袍形和山景共同服務「在黑暗中尋路」的敘事，適合作為焦點安排的參照。
- 皇后的自然與軟墊、皇帝的荒岩與硬石座已有性格區分，不應為了統一而抹平。
- 既有修訂已補足許多識別元素，重畫結構時要保留清單，避免退回只有角色、沒有塔羅語意的裝飾插畫。

### 3.2 必須改善的共通問題

| 面向 | 現稿觀察 | 具體改善方向 | 驗收方式 |
|---|---|---|---|
| 體積 | 部分肩袖、膝部與手掌像平面形狀拼接；內部排線沒有充分說明轉折 | 先標胸腔、骨盆與四肢體塊，決定前後和朝向，再畫衣服外形 | 暫時隱藏色塊與印刷紋理，仍可讀出姿勢和體積 |
| 重量與接觸 | 坐姿膝蓋隆起、人物落地、器物持握有時只靠相貼輪廓 | 明確畫出接觸面、壓縮、遮擋與承重方向 | 可指出坐骨落點、足底支撐、手掌握持面；物件沒有浮空或穿體 |
| 手部 | 某些手呈分層圓套、封閉小拳或扁掌，缺少掌骨、拇指對握及指節 | 先畫腕軸與掌體，依器物尺寸安排拇指和折指，不以放大拳頭代替修正握法 | 放大能理解掌心朝向和握法；縮圖看得到手的動作，不需讀每根指頭 |
| 表情 | 女祭司、皇后、皇帝、教皇的垂眼與嘴形接近 | 使用眉弓、眼瞼、視線、嘴角與頭部角度區分人物性格 | 遮住皇冠與器物後，仍可感到靜觀、滋養、權威、教導的差異 |
| 網點 | 天空、臉、衣服和背景常有接近的紋理強度 | 用局部減噪和色版濃度分出主次；保留重要處的乾淨形狀 | 第一眼先看到角色與核心器物，而非紙紋或滿版網點 |
| 木刻陰影 | 部分長直排線偏像條紋，未充分跟隨表面方向 | 袍褶順布料轉向，毛髮順生長方向，石面順轉折；用疏密形成明暗 | 陰影能交代形體背光、接觸與地景轉折，且沒有穿出遮罩 |
| 器物與背景 | 細線、網點和背景有時削弱小符號辨識 | 為小字、杯口、劍刃、吊線等保留局部留白和明度差 | 完整尺寸能辨字、數件、追蹤連線；不要求120px也能讀清所有小字 |

**結構未通過時，不得以多加刻線、加深色塊、紙紋或套印效果當作修正。**

### 3.3 線條與色版基準

以 300×500 牌面單位作起點，沿用既有規格：主輪廓約 2.2–2.8、結構線約 1.3–1.8、木刻排線約 0.8–1.1、必要小物約 0.7–0.9。這些數字不是完成品質的替代品；實際須與隱者同尺寸比較，計入滲墨後的視覺重量。

外框、牌號、牌名與裝飾固定使用既有墨藍 `[30,40,74]`、朱橘 `[255,84,46]`；插畫獨立配色。不要為單張新配色改掉全組牌框。符號承擔識別時，要維持可辨的色相或明度差。

## 4. 逐張審核意見與具體改善方向

### 4.1 0 愚者／The Fool — P1

現稿：[fool-sample.png](../assets/fool-sample.png)  
來源：[fool.js](../src/print/fool.js)

**保留：** 崖邊、白犬、玫瑰、肩後行囊與亮天空已構成可辨識的啟程場景；人物和犬的相對位置可以沿用。

**審核意見：**

- 人物較像站定展示玫瑰，兩腳與軀幹缺少向未知踏出的動勢。
- 胸前手部和衣飾擁擠，持杖手與杖的連接不夠直觀，容易讀成胸前裝飾。
- 肩、胸與骨盆的方向較平，臉雖朝外，身體沒有同步建立輕盈而有支撐的姿勢。
- 白犬的抬腿／前躍與警覺關係可以更清楚；不能僅靠白色剪影說明動作。

**具體修改：**

1. 先決定負重腳在崖內、試探腳靠近邊緣；畫出髖部位移與肩軸，避免兩腳平均承重。
2. 將持杖手、杖、肩後行囊作為一組重新畫清楚，手指必須包住杖；杖不得穿頭頸。
3. 玫瑰手與胸前花紋拉出空隙，使「手持白玫瑰」一眼能讀懂。
4. 頭略向遠方或天空開放，胸廓呼應頭部，而不是只旋轉臉。
5. 犬先建立肩胛、胸腔、前後腿關節，再調整靠近人物的提醒動作。

**符號複核：** 一朵手持白玫瑰、一隻小白犬、手持杖與肩後行囊、懸崖落差、背後太陽、遠山、花紋衣及羽飾。

**驗收標準：** 不看牌名也能讀成「帶著純真與風險啟程」；能追蹤兩手各自的來源及用途，腳沒有踩空、崖面沒有誤接到遠山。

### 4.2 I 魔術師／The Magician — P1

現稿：[magician-sample.png](../assets/magician-sample.png)  
來源：[magician.js](../src/print/magician.js)

**保留：** 上舉與下指的雙向構圖、紅外袍與淺內衣、上下花園的呼應。

**審核意見：**

- 舉杖手的分層橫線使手像套在杖上的圓套，不像有掌體與指節的握持。
- 指地手貼近桌緣，容易和桌面、柄或裝飾線合併。
- 桌面條紋與重暗桌沿搶走器物輪廓；四器雖有安排，劍與木杖仍須花時間辨認。
- 袖子、肩部與前臂的轉折偏硬，削弱「主動運用資源」的身體感。

**具體修改：**

1. 分別建立兩臂的肩、肘、腕軸；舉杖手先畫掌塊與拇指對握，再畫折指。
2. 指地食指與其餘折指分清，手腕和桌緣之間留負空間，不把指尖藏入桌面。
3. 用略俯視桌面分開四器：杯口與杯底、劍柄與刃、木杖端面、幣的五芒星各自可辨。
4. 刪減器物周圍桌面條紋，以局部留白交代接觸，避免靠加粗每件器物解決競爭。
5. 身體背光與桌下可以保留較重排線，但手臉及四器應成為視覺焦點。

**符號複核：** 以人物自己的左右為準，右手舉杖、左手指地；桌上權杖、聖杯、寶劍、錢幣四器；頭上無限符號、銜尾蛇腰帶、玫瑰與百合。

**驗收標準：** 能逐件指出四器，手的動作不靠文字解釋；上與下的視覺傳導通暢，器物不被花朵、桌紋或指地手遮掉。

### 4.3 II 女祭司／The High Priestess — P2

現稿：[high-priestess-sample.png](../assets/high-priestess-sample.png)  
來源：[high-priestess.js](../src/print/high-priestess.js)

**保留：** 冷色、對稱雙柱、中央靜觀者，以及月冠與足月的上下呼應。

**審核意見：**

- 雙手像攤貼在卷軸正面，腕、掌與手指承接關係不夠自然。
- 卷軸讀感偏向小牌匾，卷邊厚度和半遮的布料關係不夠強。
- 左側黑柱的 B 被印刷噪點侵蝕，辨字較吃力。
- 閉眼與下垂嘴形容易顯得睡著或疲倦；靜觀意圖可以更精準。

**具體修改：**

1. 從袖口畫出手腕，安排掌根接觸卷軸，手指順卷面下垂；拇指須與其餘手指區分。
2. 加強卷端、卷芯與紙面弧度；讓披衣確實遮住卷軸的一部分，不只貼在外緣。
3. B 字周圍局部減噪，修字腔與筆畫間距，保留黑柱與白字的對比。
4. 可使用微開或下望的眼瞼、穩定眉弓及放鬆嘴形，表現清醒的內省。
5. 降低靠近冠、手與卷軸的帷幕細線競爭，保持中軸主體明確。

**符號複核：** 觀者左黑柱 B／右白柱 J；TORA 半遮卷軸；胸十字、角形月冠及中央球、足邊弦月、棕櫚與石榴帷幕、幕外水域。

**驗收標準：** 完整尺寸可讀 B/J/TORA，卷軸看得出是卷軸；人物靜而不疲弱，手與卷的接觸有厚度。

### 4.4 III 皇后／The Empress — P2

現稿：[empress-sample.png](../assets/empress-sample.png)  
來源：[empress.js](../src/print/empress.js)

**保留：** 森林、軟墊椅、麥田、水景與獨立暖色氣氛；與皇帝硬石座的差異。

**審核意見：**

- 肩胸偏窄、頸較長，人物體積與豐盛主題不完全匹配；這裡需修的是胸廓與承重，不是單純增加身材寬度。
- 坐骨、骨盆與膝部的關係較弱，長袍仍帶直立人物套上裙子的讀感。
- 膝上手及前臂偏扁，手掌順膝面的轉向不足。
- 眉眼和嘴形較疲倦；人物旁樹幹線條與臉、肩和權杖競爭。

**具體修改：**

1. 先畫胸廓、骨盆與大腿，再決定袍形；讓臀部有壓入坐墊的接觸，膝部朝前而非往下拖。
2. 校正頸長及肩寬；以放鬆的肩軸、微側身與穩定頭部表現舒適和尊嚴。
3. 重畫肘—前臂—腕—掌的連續體塊，手指順膝面自然放下，避免一片扁掌。
4. 眉嘴放鬆，視線具有溫暖與生命力；不必改成誇張微笑。
5. 椅框、扶手、座面與腿保留連續結構；降低貼近頭肩的樹幹對比，水面與岩岸用不同線性處理。

**符號複核：** 十二星冠、含完整 ♀ 的心形盾、球頂權杖、麥田、森林、流動水與瀑布、石榴袍紋及軟墊。

**驗收標準：** 不依賴皇冠也能讀出有重量的坐者；盾符號不被麥穗遮掉，星冠可在完整圖點清十二顆。

### 4.5 IV 皇帝／The Emperor — P1

現稿：[emperor-sample.png](../assets/emperor-sample.png)  
來源：[emperor.js](../src/print/emperor.js)

**保留：** 石座、四羊頭、紅袍、甲腿與荒岩環境的權威感。

**審核意見：**

- 雙膝像兩個獨立圓鼓包，腰與髖沒有充分連到向前的大腿。
- 膝下甲腿偏像直接接到袍襬的直筒，坐姿大腿深度不足。
- 左右過度對稱，使人物比較像標誌或玩偶；低垂眼神也削弱清醒承擔的氣質。
- 王座座面、骨盆與膝部的遮擋仍可更明確。

**具體修改：**

1. 先在王座透視內放骨盆，標出坐骨、座面高度及兩側大腿往前的方向。
2. 以髖部受力褶延伸到膝面；膝上亮面、膝下暗面應屬於同一條腿，不畫兩塊分離圓形。
3. 甲片隨膝與小腿方向轉折，靴底接地；甲腿寬度與藏在袍下的大腿相容。
4. 以輕微左右差異、肩軸和手掌承托增加活人體積，不必破壞正面穩定構圖。
5. 修眉眼視線，表現警醒、經驗和責任，避免用怒目代替權威。

## 5. 交給下一位繪圖者的實作流程

### 階段 A：構圖與符號配置

先提交一張白底、無網點、無紙紋的配置稿。列出每個必要符號的數量、方位、大小與前後關係。圖上空間不足時先調構圖，不能先刪符號。

### 階段 B：骨架、體塊與接觸

另附可切換或獨立的結構輔助層：人物胸腔／骨盆／關節、動物頭顱／胸背／四肢關節、座面或地面透視、器物軸線。不要求將輔助線放進最終牌面，但必須能據此檢查承重。

本階段只檢查：比例、透視、姿態、接觸、遮擋、視線與主題。若不成立，回到骨架與體塊重畫，不能先上木刻陰影。

### 階段 C：輪廓與手寫 SVG

結構通過後才整理主輪廓、器物細節、服裝與生物特徵。以有語意的群組分層；身體前後、器物與手的繪製順序應明確。白底輪廓稿要能獨立成立，避免不必要的重複線、穿線及相切。

### 階段 D：木刻明暗

至少交代主體背光、接觸／遮擋、地景／建築轉折三種暗面。排線依形體方向轉動，局部加交叉刻線；手、臉、小字保持足夠乾淨。不能靠一致間距的條紋替代布料或肌肉。

### 階段 E：上色與印刷

輪廓和明暗確認後再試獨立插畫色盤，最後套既有印刷效果。框色固定。對比套效果前／後，確認沒有因滲墨、飛白、錯版而損失指節、字腔、符號或器物邊緣。

### 階段 F：交稿與狀態

每次先交一張完整代表作，附下列資料：

- 可編輯 SVG／色版原始碼與版本號。
- 完整 PNG、120px 縮圖、結構輔助圖。
- 手與器物、足部與承重、動物頭頸等必要局部。
- 修前／修後、與隱者同尺寸對照。
- 符號核對表、改動／偏離清單、尚待解決問題。

圖稿經使用者確認後才調整核准狀態；接入正式抽牌與海報另行處理。繪圖者不應把「有輸出」或「測試通過」寫成「美術驗收通過」。
