# 力量：結構與色版修正

2026-11-16，依使用者指定修正現有 `src/print/strength.js`。兩輪修訂後已獲使用者確認，登記為 approved；尚未接入正式抽牌與海報。

## 本輪修改

- 重畫遠側與近側袖子、手腕、掌與指；上手貼向獅子鼻樑，下手承托下顎。近側袖子在遠側之前；每一色版最後都把兩袖與雙手的區域挖空，再印膚色，避免獅子的金／橘色穿過手掌。
- 後髮先印，再由白袍、頸部與臉挖空；新增獨立前髮輪廓，放在臉之後。脖子保留淡膚色，領口／衣服不再印後髮棕色。
- 獅子吻部縮短，鼻墊與鬍鬚墊加寬，下顎變厚、臉頰更飽滿，耳朵圓化；保留抬頭朝向女子的姿勢。
- 鬃毛由幾何尖角爆炸形改為不規則毛簇；背部、腹線、臀部與近側後腿的轉折重新整理。
- 無限符號、花冠、花帶與花鏈、固定 FO/FN 框色保留；花朵仍只有色版、沒有新增墨線。
