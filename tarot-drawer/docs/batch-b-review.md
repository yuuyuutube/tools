## 依據與共同美術處理

再次閱讀 Waite《The Pictorial Key to the Tarot》[女祭司](https://sacred-texts.com/tarot/pkt/pktar02.htm)、[皇后](https://sacred-texts.com/tarot/pkt/pktar03.htm)、[皇帝](https://sacred-texts.com/tarot/pkt/pktar04.htm)、[教皇](https://sacred-texts.com/tarot/pkt/pktar05.htm)、[正義](https://sacred-texts.com/tarot/pkt/pktar11.htm)章節，並對照各頁連結的 Smith 原圖及既有逐牌重畫計劃。網站既有現代牌義文字不變；不把原典的神秘學主張當作經驗事實。

- 人物有頭顱、頸、肩、軀幹、彎肘、手腕與掌形；布料以外輪廓及坐姿衣褶交代膝、腿和重量。各張保留自身服飾、年齡、器物及環境，沒有套用小圓頭細棍四肢。
- 主輪廓以 2.4 為基準，建築／大衣袍多為 2.1–2.4，結構線 1.3–1.7，刻線 .8–.95；臉和手的小線另行收細。與同尺寸隱者實際套印並排核對。
- 暗面除了網點，另有順著衣褶、髮束、石柱、腿甲與樹幹轉向的木刻排線；袍側、座側及接觸區各有陰影。
- 新增 `engraving.js` 逐層挖空工具。每個不透明形體先從四色版挖空再著色，陰影由自己的 clipPath 裁切。器物另外清除背景刻線，避免柱線或椅背線穿入劍刃、球杖、安卡、寶球及三橫杖。
- 插畫色盤獨立；所有牌框、文字和小裝飾仍以隱者固定 FO/FN 墨色印製。沒有改動全域四色或已確認力量圖稿。

## II 女祭司 · high-priestess · seed 20261121

**敘事**：靜觀、內在知識、門檻；端坐於兩極之間，沒有教皇的外顯祝福手勢。

| 核對項目 | 圖上位置／處理 |
|---|---|
| 安靜坐者、黑白柱 | 人物中軸，肩、袖、手與膝分層；兩側柱後退 |
| 觀者左 B 黑柱、右 J 白柱 | B 在黑墨版挖白，J 用深墨；字母沒有鏡像交換 |
| TORA 卷軸、部分遮蔽 | 膝上橫卷，卷端及下緣可見；右下端被垂下的披衣遮擋，字樣保留可讀 |
| 角形月冠與中央球 | 頭頂；背景紋樣避開中央球，避免誤連成額外頭飾 |
| 胸十字與足月 | 胸口直交十字；觀者右下腳邊金色弦月 |
| 棕櫚／石榴帷幕 | 左右重複植物刺繡；不是普通純色幕 |
| 幕外水域、流動袍褶 | 幕左右與下方可見水線；袍襬與水紋相接而非畫成雙腿站姿 |

**造型調整**：服飾改為靛藍、石榴紫及月金；植物紋樣重新排列，避開臉、冠與卷軸。原典必畫元素未刪。

## III 皇后 · empress · seed 20261122

**敘事**：滋養、感官與自然豐盛。紅色軟墊、偏斜的坐姿及膝上起伏，與皇帝硬石座區分。

| 核對項目 | 圖上位置／處理 |
|---|---|
| 有重量的女性與軟墊 | 左中景；軟靠墊在背後，手肘與膝部衣褶獨立 |
| 十二星冠 | 頭上弧形排列，恰十二顆五芒星，中心不另加一星 |
| 金星心盾 | 觀者左下；心形內有完整圓、直幹與橫畫 ♀ |
| 頂端球體權杖 | 觀者左側、人物右手；握柄先印、手指後印，球與背景獨立挖空 |
| 石榴袍紋 | 袍上六處果實紋樣，冠萼與種籽有刻畫 |
| 麥田 | 前景十六組麥莖／麥粒，非普通野草 |
| 樹木與瀑布／水流 | 左右森林；右側水從高處折落，接到地面水域 |

**造型調整**：十二星由原圖緊簇式冠改為可點清的弧形冠；自然與軟墊採鼠尾草綠／玫瑰紅。仍保留冠而非額外天空星群，無必畫元素刪除。

## IV 皇帝 · emperor · seed 20261123

**敘事**：承擔、執行、現世秩序。成熟長鬍人物坐在有結構的石座，腳甲確實落在石地。

| 核對項目 | 圖上位置／處理 |
|---|---|
| 皇冠、成熟面孔、長鬍 | 中上方；鬍鬚覆胸前，臉不以圓點眼代替 |
| 四個公羊頭雕刻 | 椅背上方左右各一、扶手前面左右各一，共四個 |
| 右手安卡杖 | 觀者左；環首、橫桿及直幹可辨，握手覆在柄前 |
| 左手寶球 | 觀者右；掌心承托下緣，球體不受背景椅背排線污染 |
| 紅袍與甲冑 | 鐵鏽紅袍下露出兩側腿甲與靴；甲片方向與腿一致 |
| 硬石王座與裸岩 | 王座側面、扶手下有石面排線；背景是荒岩山地 |
| 遠處細河 | 椅後下方彎曲的冷灰水帶，非皇后的繁茂水景 |

**造型調整**：皇冠與羊頭採歐洲寓言石雕造型；不以羊頭數量附加原典未說的解釋。必畫元素未刪。

## V 教皇 · hierophant · seed 20261124

**敘事**：公開教導、制度與傳承；正面坐者與兩位背向觀者的跪坐門徒形成關係。

| 核對項目 | 圖上位置／處理 |
|---|---|
| 三重冠 | 頭上三道獨立冠帶，另有小頂十字，不把頂十字算第四層 |
| 左手三橫桿十字杖 | 觀者右；上短、中等、下長三橫桿，直幹與持握手獨立 |
| 右手祝福 | 觀者左；兩指豎起，拇指側張，其餘折回，肩肘腕連接清楚 |
| 兩把交叉鑰匙 | 袍前下一級石階、兩門徒之間；與袍襬留間隙，兩環、兩幹、匙齒均可見 |
| 兩位跪坐門徒 | 前景左右，各有頸、肩、後腦與袍背；不把兩人畫成正面無臉像 |
| 玫瑰與百合袍紋 | 觀者左門徒玫瑰、右門徒百合；不是石榴替代玫瑰 |
| 柱、儀式衣、台階 | 柱上植物石飾、沒有借用 B/J；披帶胸前與袍側有明確暗面 |

**造型調整**：以酒紅、古金及灰藍處理；門徒較低的位置以重疊背影表示跪坐，腿藏在長袍內。原典必畫元素未刪。

## XI 正義 · justice · seed 20261125

**敘事**：清醒衡量、責任及執行；人物直視、秤梁水平，與女祭司的內省區分。

| 核對項目 | 圖上位置／處理 |
|---|---|
| 未蒙眼、正面坐者 | 雙眼清楚，不使用遮眼布；肩與頸軸穩定 |
| 人物右手雙刃劍 | 觀者左；向上的劍尖、兩刃、中脊、護手及握柄分明 |
| 人物左手持秤 | 觀者右；掌下吊環接直幹與水平梁，不從手心直接長出秤盤 |
| 兩盤與吊線 | 一梁、左右各兩條吊線、兩只碗形盤，盤底相同高度 |
| 方形冠飾與紅袍 | 冠正中方飾可見，紅袍有膝上與裙襬折線 |
| 兩石柱、帷幕、台階 | 背景三層，柱不印 B/J；劍與秤先挖空再印，柱幕不穿入金屬實體 |
| 袍下露鞋 | 中下方一隻鞋，實際接觸石階 |

**造型調整**：石灰綠、暗紅與古金；天平置於人物左側空間，維持水平。無必畫元素刪除。

## 檔案與驗證

- 來源：`src/print/{high-priestess,empress,emperor,hierophant,justice}.js`；共用工具 `engraving.js`。
- 狀態、色盤、固定種子與減噪區：`src/print/registry.js`。
- 每張 900 × 1500 PNG：`assets/<card-id>-sample.png`。
- 檢視頁：`batch-b-sample.html`，包含五張總覽、原版／新版、120px、手與器物局部、PNG 下載及隱者參照。可使用 `?only=empress` 等篩選。
- 28 項測試通過；新增六項涵蓋固定框色、遮罩參照有效性及這批容易漏掉的符號／數量。另以 XML parser 檢查 30 個 SVG 色版。
- 實際印製後修正了黑柱 B 對比、冠球背景相切、皇后膝部起伏、器物背景穿線、祝福手拇指及鑰匙與袍襬相切。

技術測試不能判斷解剖、美感、表情或完整牌義；這五張仍需使用者看樣張確認，不登記為 approved／integrated。

## 第二輪：森林、水流、坐姿與手部

依使用者逐項回饋修訂，保留 `src/print/<card-id>-before-structure.js` 與 `assets/<card-id>-before-structure.png`，可由 `batch-b-sample.html?before=previous` 查看本輪修訂前後；最初原版對照仍可切回。

- **皇后背景**：移除整片條紋森林，重畫遠景林帶、分層葉冠、分岔樹幹、樹皮、根部與蕨草。瀑布改由左右岩岸包住，水線由高處連續落下，接泡沫、水潭與下游；水面以橫向漣漪和岩壁斜刻區分。十二星、球杖、心盾、麥田與石榴袍紋保留。
- **皇帝坐姿**：新增座面，軀幹在髖部收束後，布料朝前方兩膝展開；兩邊膝面各有凸起、橫向受力褶與膝下暗面。腿甲向上延伸接在膝下，再接直立小腿及落地靴。四羊頭與雙手器物保留。
- **教皇坐姿**：新增座面，重畫兩側膝部隆起、膝下垂袍及腰間放射褶；金色披帶順膝上的弧面轉折。袍襬和交叉鑰匙之間的空隙保留。
- **正義坐姿**：臀腰後退，雙膝向前形成較寬的弧面，膝下長褶再垂向露鞋與石階；天平、劍、柱幕和未蒙眼的設定保留。
- **教皇祝福手**：重新安排兩根豎起手指、側張拇指、折回的無名指與小指；以各自的輪廓和摺線交代五指，腕部仍接入原袖口。
- **女祭司雙手**：重畫袖口、腕、掌、拇指和四指，從腕部連續伸到卷軸上方；卷軸往下移並保留可讀 TORA，右下端仍被披衣半遮。局部減噪區跟著新手部位置調整。
- **皇后膝上手**：重畫彎肘後的袖子、斜向手腕與放鬆的五指，讓掌指沿膝面放下；袖口不再直接以短小三角掌收尾。

這一輪仍維持原固定種子、各張色盤與框色；PNG 重新輸出，並重新檢查完整圖與局部。

## 第三輪：椅子、植物／水的著色、持握手與露鞋

- **皇后椅子**：重畫為有連續外框的木製軟墊扶手椅。椅背木框包住嵌入式紅色軟墊；座墊坐在前緣座框上，捲形扶手由短支柱接到座框，前腿再接地面。木材、軟墊、縫邊／凹扣以不同色塊和排線分開，不再使用數塊不明的紅色梯形重疊。
- **皇后樹葉**：移除樹冠整圈黑邊，改由淺綠、深綠及偏金的受光色塊構成葉叢。較重木刻短線集中在下側、重疊和背光處，少量葉簇轉折線保留。
- **皇后瀑布／水潭**：移除水流與水波黑色描邊，改為灰青色水身、較深色水流、紙白泡沫和橫向色帶漣漪；岩壁仍有結構輪廓，與水的柔軟處理區分。皇后 B 版由苔綠微調為灰青綠，植物受光面增加金黃疊色，仍維持三個插畫色版加深色墨。
- **教皇持杖手**：掌寬、掌厚及折指區放大，使掌部體積與祝福手接近（不把伸直手指的總長當作拳頭高度）。拇指跨過握柄、其餘指節包住直杖；對應的減噪區也已調整。
- **正義雙手**：握劍手放大為完整拳握，交代拇指對握、指節與腕部；持秤手放大，食指與拇指在吊環上方捏合，吊環先畫、手指後畫，避免金屬線穿過手。兩手皆保留袖口連接。
- **正義露鞋**：重畫踝口、鞋面拱起、鞋頭、鞋底與低跟，補縫線／細繫帶、皮面短刻線及落地接觸影。
