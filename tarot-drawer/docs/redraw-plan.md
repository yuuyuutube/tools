# 小小塔羅印刷所：其餘 20 張大阿爾克那重畫計劃

版本：2026-11-16 · 狀態：研究與繪製規格完成，尚未執行這 20 張的新插畫。

## 1. 範圍、依據與讀法

目前牌組有 22 張。IX 隱者已有使用者確認的新版畫風；XVIII 月亮已有新版試畫與符號修訂，因此本次重畫清單是其餘 **20 張**，不是 22 張，也不包括九款牌背。正式抽牌仍使用舊版 22 張正面；新版樣張與正式上線是不同狀態。

本文件優先順序：本次使用者需求與已確認隱者樣張 → 本計劃 → 早期 `docs/prompt.md`。早期「小生物、圓臉點眼、積木塔」等設定保留為歷史紀錄，不能繼續當作新版人物造型指令。

### 1.1 查核來源

- **S1：原典圖像與象徵**：A. E. Waite，《The Pictorial Key to the Tarot》，Part II 各牌章節；Pamela Colman Smith 原始牌面。本次已讀各章並逐張對照附圖。[完整原文](https://tianmu.org/good-work-library/aquarian/occult-revival-and-neo-hermeticism/the-pictorial-key-to-the-tarot-arthur-edward-waite)；[附牌圖 PDF](https://benebellwen.com/wp-content/uploads/2013/02/a-e-waite-pictorial-key-to-the-tarot-1911-source-credit-sacredtexts.pdf)。以下「PDF 第幾頁」皆為此檔從 1 起算的檔案頁碼，不是原書頁碼。
- **S2：原典占卜牌義**：同書 Part III §3，正、逆位均已查閱。它與現代常用關鍵字有差異，不能把現代解讀冒稱 Waite 原句。[Part III 原文](https://sacred-texts.com/tarot/pkt/pkt0303.htm)。
- **S3：網站目前牌義**：`src/data/cards.js`，以正位核心與逆位的受阻／過度／內化來引導構圖。本次不更動既有牌義文字。
- **S4：已確認的美術依據**：`src/print/hermit.js`、`sample.html`；月亮的框色與力道修訂也作為共同驗收案例，但人物／動物結構以隱者較成熟的造型為主要基準。

原典神秘學論述、圖上可見元素、現代牌義、美術設計，是四個層次。以下「象徵連結」有些是本案依 S1／S3 作的構圖解讀，不代表所有傳統都只有這個解釋。後世慣稱的天使名字、希伯來字母對應、占星對應，不在缺乏出處時寫成唯一正解。

### 1.2 完整不等於塞滿

每張將圖像分成：

- **A：主體與關係**：刪除就會改變辨識或核心牌義，必須明確可見。
- **B：識別細節**：數量、文字、方向、器物、次要角色，必須列入逐項驗收；縮圖可合併細線，完整圖不能省略。
- **C：可調整造型**：服裝剪裁、石材、植物寫法、地景、配色、筆觸與不改義的擺位。

A／B 要刪減，先把變動及失去的意涵寫進該牌「偏離紀錄」，不能在畫完後才說是風格化。以星星的雙壺、月亮的露滴、死神旗幟為例，它們不是可有可無的背景裝飾。

## 2. 全組共同美術規格

### 2.1 人物、動物與敘事

- 歐洲寓言書、古老木刻插畫的神秘感；有一點擬真。人物有頭顱、肩、胸腔、骨盆、四肢與重量；動物有物種特徵、關節、胸背與腳掌。禁用火柴人、豆形身體配細棍手腳、點眼貼在圓頭上的快捷造型。
- 可略微拉長衣袍、簡化表情，不能以布料遮住解剖錯誤。兜帽裡要有頭顱體積；手指要能握住物件；馬、獅、鳥、犬的頭頸不能互套。
- 主角的姿態、目光與道具先講出牌義，再加裝飾。保持每張一個主焦點、兩個次焦點；小符號以清楚輪廓取得辨識，而非放大到搶主角。
- 原典的非情色裸身是「坦誠、自然、無遮蔽」的符號。戀人、星星、世界等以古典版畫方式處理；若改為薄紗、長袍或枝葉遮蔽，須記錄改義取捨，不默默換成可愛小人。太陽兒童維持非情色、自然的古典表現，不加入成人化造型。

### 2.2 線條、陰影與印刷

以 300 × 500 牌面單位計：主輪廓約 2.2–2.8，結構線 1.3–1.8，木刻排線約 0.8–1.1，必要小物約 0.7–0.9。這是起始範圍，不是所有線等粗；同尺寸與隱者並排，以實際印出來的重量校正。

每張至少明確安排三類暗面：主角／主物的背光面、物件接觸或遮擋處、地景／建築的轉折。陰影不能只靠網點、紙紋或把整張底色變深。排線沿著衣褶、毛流、肌肉、石面或水勢轉向；密度漸變，必要時交叉刻線。排線須裁在自己的形體內，不可穿過手、鬍子、前景或別的物件。

小眼睛、手指、符號字母等可用局部減噪；不能整張磨成乾淨向量圖。紙紋、飛白、套色誤差延用 `press.js`，同一結果使用固定種子，畫面與輸出一致。

### 2.3 正面統一框色，插畫獨立配色

牌面尺寸、上方牌號、拱窗、下方中英牌名與小裝飾沿用隱者。**外框、文字與裝飾固定使用實際 `INKS.N` 墨藍 `[30,40,74]` 及 `INKS.O` 朱橘 `[255,84,46]`**，以獨立 FN／FO 版印製。不能用該牌插畫的新色盤把牌框一起換色。

插畫可每張獨立選 3 個色版加 1 個深色主墨；紙白不算新增油墨。以下每張色盤是提案，不是已確認稿，也不是要求把原典的顏色一一照抄。顏色若承擔識別（黑白對子、白旗花、紅十字等），仍保留色相或可讀的明度差。

### 2.4 必做的三輪審查

1. **符號草圖**：先列全 A／B，標大小、位置、計數與方向；在未上紙紋的草圖上逐項圈出。空間不足先改構圖。
2. **結構與遮擋**：畫骨架／體塊、道具握法與前後層；檢查手臂是否長在正確肩膀、是否畫出理應被遮住的遠側肢體。劍、旗杆、杯與人物不能錯接。
3. **印刷與閱讀**：完整牌、120px 縮圖、局部放大、與隱者同尺寸並排。讓符號、形體和陰影先通過，再定稿套色。語意驗收不能只看測試綠燈。

## 4. 逐張重畫規格

### 0 · 愚者 / The Fool (`fool`)

**牌義查核**：S3 正位為開始、自由、冒險、純真；逆位為魯莽、猶豫、輕率、失向。S1 是靈魂進入經驗的旅人；S2 的愚行與疏忽較強烈。構圖要同時容納天真與真實危險，不能只畫無憂散步。

**來源**：[S1 愚者](https://sacred-texts.com/tarot/pkt/pktar00.htm)，PDF 第 47 頁；另讀 Part II §3 的行囊補述；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 懸崖邊緣與深落差：未知確實存在；前腳接近邊緣但尚未墜落。 |
| A | 朝天空／遠方望的年輕旅人：開放於經驗，而非已看清道路。 |
| A | 伴行的小白犬：警覺、自然本能，與人的向外凝望形成張力。 |
| B | 人物手持白玫瑰：純淨意圖；不能改成腳邊一朵無關野花。 |
| B | 另一手的杖與肩後小行囊：攜帶的經驗與潛在內容；行囊不是手提包。 |
| B | 背後太陽、遠山、高處空氣感：啟程的明亮與尚遠的旅途。 |
| B | 輕盈但有支撐的步姿、花紋衣、頭飾／羽毛：身份是旅人而非滑稽小丑。 |

**重畫構圖**：旅人以三分之二側身立在左中景，留右側崖外空間；小犬在腳邊前躍，遠山縮到下方。玫瑰靠胸前留白，杖從手通到肩後包袱，避免三者擠成一團。帽羽與行囊紋理可自行設計，但不遮掉臉和玫瑰。

**體態與木刻**：先畫負重腳、髖與脊柱，另一腳是試探步；小犬後腿要有蹬地關節。斗篷下側、行囊下緣與崖壁是主要暗面；崖面用直斜刻線，衣褶用弧線，天空保持透氣。色盤提案：杏黃、灰綠、赭紅與深褐墨。

**現版需修正／驗收**：把地上花移回手中，補回犬與崖外落差；不能只保留包袱輪廓。檢查兩手來源、杖沒有穿頭、腳與崖的接觸、犬四肢，以及縮圖下「走向未知」而非「跌倒」。

### I · 魔術師 / The Magician (`magician`)

**牌義查核**：S3 意志、創造、行動、資源；逆位操弄、才能未用、缺乏計畫、言行不一。S1 強調上與下的傳導及資源的運用，不是舞台戲法。

**來源**：[S1 魔術師](https://sacred-texts.com/tarot/pkt/pktar01.htm)，PDF 第 27 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 人物右手舉杖向天、左手指地：兩向傳導；以人物自己的左右為準。 |
| A | 桌上四器：權杖、聖杯、寶劍、錢幣，四者必須能分辨。 |
| B | 頭上的橫向無限符號：持續的生命／能力，不用帽上普通星星取代。 |
| B | 腰部銜尾蛇帶：循環、延續；與無限符號形成上下呼應。 |
| B | 紅外袍與淺內衣的明度層次：行動與專注兼具，人物不是黑帽玩具法師。 |
| B | 玫瑰與百合的花園，上下呼應：培養、意向與實踐。 |

**重畫構圖**：桌沿放在插畫下三分之一，四器採略俯視展示；人物站在桌後，上舉手伸到頭旁空區。四器不是四個圖標：杯有杯口、劍有柄刃、幣有五芒星、杖是獨立木杖。

**體態與木刻**：寬袖自然下垂，清楚區分肩、肘、腕與手指；指地手不能藏進桌面。袍側、桌底與器物背光用成組排線；金屬留窄亮邊。提案：朱紅、苔綠、淡金與墨褐。

**現版需修正／驗收**：擴大原版偏小的四器，回到成年寓言人物。驗收以四器清點、無限符號、銜尾蛇和雙手方向為首；桌前花不能擋住劍尖、杯底或指地手。

### II · 女祭司 / The High Priestess (`high-priestess`)

**牌義查核**：S3 直覺、潛意識、靜觀、內在智慧；逆位忽略直覺、表面理解、秘密與失聯。S1 是內在、隱秘的知識；與教皇的外顯制度不同。

**來源**：[S1 女祭司](https://sacred-texts.com/tarot/pkt/pktar02.htm)，PDF 第 28 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 安靜端坐者與黑白雙柱：門檻、兩極與其間的靜觀。 |
| B | 觀者左黑柱 B、右白柱 J：字母不可交換，也不可隨整圖鏡像。 |
| B | 膝上半遮的 TORA 書卷：部分顯露、部分隱含；保留卷軸形式，不改成完全打開的書。 |
| B | 胸前十字、頭上角形月冠及中央圓球：識別與上下呼應。 |
| B | 腳邊弦月、垂下的衣袍／水勢：反射之光與內在領域。 |
| B | 身後帷幕上的棕櫚與石榴紋，帷幕外可窺見的水面：知識被遮蔽但不完全封閉。 |

**重畫構圖**：正面人物在中軸，柱子退成兩側，不用高飽和柱搶主角。衣褶像水向下流，TORA 留可讀的一截；月冠和足月相距足夠，不讓符號合成普通首飾。

**體態與木刻**：閉靜或微垂眼神有眉骨與鼻樑；肩寬、手握卷軸與膝部體積合理。黑柱用留白刻線，白柱用細暗邊，帷幕背光與袍側排線重於臉。提案：靛紫、灰藍、石榴紅與深藍墨。

**現版需修正／驗收**：原版書本改回半遮卷軸；加柱字、完整冠式和帷幕植物。驗收黑白柱、B/J、TORA、胸十字、兩處月形、帷幕及水面，避免把靜觀畫成睡著。

### III · 皇后 / The Empress (`empress`)

**牌義查核**：S3 豐盛、滋養、創造、感官之美；逆位依賴、停滯、失養或過度保護。S1 著重可見世界的生育與豐饒，不是另一位坐著的女祭司。

**來源**：[S1 皇后](https://sacred-texts.com/tarot/pkt/pktar03.htm)，PDF 第 29 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 有份量、放鬆且具尊嚴的女性坐者，舒適軟墊與自然環境：滋養而非軍事權威。 |
| B | 十二星冠，星數可點清；不替每顆星另加未查證占星定義。 |
| B | 金星符號 ♀ 的心形盾：不能只剩愛心盾而遺失符號。 |
| B | 頂端圓球的權杖：創造與可見世界的主導。 |
| B | 成熟麥田、樹木與流動的水／瀑布：豐收、生命與滋養。 |
| B | 長袍的石榴紋與柔軟坐墊：延續繁衍與感官的語彙。 |

**重畫構圖**：略偏左的王座形成舒服斜線，右側留出水流，前景麥穗局部遮腳但不遮金星盾。華麗來自布料與植物質地，不用多加無關皇冠。

**體態與木刻**：坐姿有臀部壓入軟墊的重量，手與權杖明確相接；長袍下表現膝部起伏。以綿密弧形排線處理軟墊與布料，以稀疏直刻區分麥稈；臉亮、樹後暗。提案：麥金、鼠尾草綠、玫瑰紅、深橄欖墨。

**現版需修正／驗收**：補足星數與 ♀，讓森林／水不只成為兩個圓形樹。逐項看星冠、盾、權杖、麥田、水流、石榴紋，並和皇帝的硬石王座分出性格。

### IV · 皇帝 / The Emperor (`emperor`)

**牌義查核**：S3 秩序、權威、穩定、責任；逆位專制、僵化、控制或失序。S1 是執行、實現及現世的主導，不是單純強壯或憤怒。

**來源**：[S1 皇帝](https://sacred-texts.com/tarot/pkt/pktar04.htm)，PDF 第 30 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 戴冠的成熟統治者與硬石王座，身體近正面：結構與承擔。 |
| B | 王座四個公羊頭飾（上方兩個、扶手兩個）：保留角色專屬識別。 |
| B | 人物右手安卡形權杖、左手寶球：分辨其形狀，不做成劍／普通魔杖。 |
| B | 長鬍、紅袍與袍下露出的甲冑：經驗、生命力與防護結構。 |
| B | 裸岩山地與遠處細水：和皇后肥沃的自然對照。 |

**重畫構圖**：王座是一個穩固的大梯形，肩線與石椅不完全重合。羊頭做清楚雕刻，不變成動物坐在椅上。遠山低於頭冠，避免王冠和山尖黏住。

**體態與木刻**：鬍子覆蓋胸前，遠側手不穿袍；露出的護腿必須接到膝。主暗面在王座側、扶手下與紅袍背光面，石材用直切排線、鬍鬚用長弧線。提案：鐵鏽紅、砂岩、冷灰與深褐墨。

**現版需修正／驗收**：回復四羊頭與安卡權杖的清楚輪廓。驗收兩手器物、四羊頭、冠、甲冑與石地景；表情可以嚴肅，但不把權威直接畫成反派。

### V · 教皇 / The Hierophant (`hierophant`)

**牌義查核**：S3 傳統、信念、教導、歸屬；逆位質疑教條、盲從或走自己的路。S1 是外在制度與傳承，與女祭司的內在知識相對。

**來源**：[S1 教皇](https://sacred-texts.com/tarot/pkt/pktar05.htm)，PDF 第 31 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 正面坐者、兩柱與前方兩位跪坐門徒：傳授不是一人自言自語。 |
| B | 三重冠、三重橫桿十字權杖：層級／宗教職位的圖像識別。 |
| B | 右手祝福手勢，左手持杖；手指分組可讀，不用一塊手掌替代。 |
| B | 腳前兩把交叉鑰匙：通行、解釋與制度掌管的門。 |
| B | 門徒衣上玫瑰與百合等差異：兩位弟子可區分，不是複製貼上。 |
| B | 儀式性衣袍、座前台階與石柱：與自然場景的力量牌不同。 |

**重畫構圖**：教皇佔上中段，兩門徒以前景背影入畫，鑰匙放兩者之間留白；柱子的柱頭另作石雕，避免直接複製女祭司的 B/J 柱。

**體態與木刻**：先畫祝福手骨架與持杖手；寬袖口與肩部確實相連。門徒背部和教皇袍側用較重排線，臉與鑰匙保留明亮。提案：酒紅、古金、石灰藍與深褐墨。

**現版需修正／驗收**：人物從小角色改成可信的儀式人物；鑰匙不能被袍襬擋住。計數三層冠、三橫桿、兩門徒、兩鑰匙，並核對祝福與持杖左右。

### VI · 戀人 / The Lovers (`lovers`)

**牌義查核**：S3 連結、選擇、價值、和諧；逆位失衡、衝突、逃避或疏離。S1 的兩人、樹與上方有翼者，比單純「兩人快牽手」更完整地表現關係、坦誠與抉擇。

**來源**：[S1 戀人](https://sacred-texts.com/tarot/pkt/pktar06.htm)，PDF 第 32 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 下方兩位彼此敞開的人物，上方有翼者展臂：人與人、內在與較高意向的關係。 |
| A | 兩人的視線不同：一人看伴侶，一人望向上方；不是兩張臉同看觀者。 |
| B | 觀者左側知識樹、果實與纏樹蛇；右側生命樹。 |
| B | 生命樹的十二個明確單元：S1 文字稱十二果實，附圖畫成火焰狀葉簇；本案沿附圖作十二火舌狀枝葉，保留此差異註記。 |
| B | 頂部日光、雲與下方單峰山：三個層次的關係不能用一顆愛心取代。 |
| B | 自然坦露的古典人物：表達無遮蔽，非情色姿勢。 |

**重畫構圖**：三角形關係是主結構，兩人分左右，山峰在中下，天使在上方雲帶。放掉現版中央漂浮愛心，以目光與手勢表現連結。樹與人物間留細縫，避免蛇或樹枝變成手臂。

**體態與木刻**：古典成人比例，兩人骨盆與站姿有差異；大翼羽片有主軸。裸身體積以少量柔曲刻線呈現，樹與雲底較暗。提案：淺赭金、松綠、灰玫瑰與深紫墨。

**現版需修正／驗收**：新增有翼者、雙樹、蛇、十二單元與視線鏈。不可只把舊版小人換漂亮服裝就交稿。天使慣稱拉斐爾屬後世命名，非本次圖像成立的必要文字。

### VII · 戰車 / The Chariot (`chariot`)

**牌義查核**：S3 意志、前進、掌控、勝利；逆位失控、失向、衝動、受阻。S1 明確採兩隻斯芬克斯，表現精神／現世的勝利與仍待統合的兩極。

**來源**：[S1 戰車](https://sacred-texts.com/tarot/pkt/pktar07.htm)，PDF 第 33 頁；S2、S3。原典敘述曾提劍，附圖駕者持杖；本案器物以附圖的杖為準，保留文字／圖像差異。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 站在有輪戰車中的披甲駕者與一黑一白兩隻斯芬克斯。 |
| A | 相反的黑白對子同屬一輛車，沒有顯眼的韁繩：掌控不能只靠拉繩圖解。 |
| B | 頭冠的星形、肩上雙月面、胸甲與持杖：駕者的職位及兩極呼應。 |
| B | 星紋頂篷與四支撐柱：人物在有結構的車體中，非坐小推車。 |
| B | 車前有翼圓盤及下方盾式圖樣：小而可辨，不用任意愛心取代。 |
| B | 車輪、遠城與水帶：可分辨行進裝置及離開城界的情境。 |

**重畫構圖**：對稱但不僵直；斯芬克斯身體向兩側，頭朝前，駕者以中軸統合。車輪露出一部分即可，但不能因簡化變成浮在地上的箱子。

**體態與木刻**：斯芬克斯是人面獅身，先處理獅肩、前腿、腹與蹲姿，再畫頭巾；不能沿用雙貓。甲片、車底、黑斯芬克斯以留白刀痕及密刻表現，白者主要用暗邊。提案：靛藍、古金、灰白與墨黑。

**現版需修正／驗收**：兩貓改回黑白斯芬克斯；檢查兩者物種、四柱、頂篷、雙月肩飾、杖、車輪與前徽。不可把車體與人物腿部錯接。

### VIII · 力量 / Strength (`strength`)

**牌義查核**：S3 勇氣、耐心、溫柔力量、自信；逆位自疑、壓抑、急躁或無力。S1 強調高層本性與獅子的調和，花鏈而非暴力馴服；S2 也含勇氣與力量的負面濫用。

**來源**：[S1 力量](https://sacred-texts.com/tarot/pkt/pktar08.htm)，PDF 第 34 頁；S2、S3。編號固定 VIII，不與 XI 正義對調。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 有重量的女性人物，以雙手輕合／安撫獅口：手與嘴的接觸成立。 |
| A | 清楚可辨的成年獅子，鬃毛、肩、爪與尾，與人之間不是打鬥。 |
| B | 頭上無限符號：與魔術師呼應。 |
| B | 頭上花冠、腰間花帶及與獅相連的花鏈：柔和約束的具體圖像。 |
| B | 白衣、遠山與草地：安定的空間，與惡魔的壓迫結構相對。 |

**重畫構圖**：人物在左、獅子在右下，身體微俯但不失重；獅子頭略抬，口部在兩手間。花鏈順身體垂落，不能纏成斷肢。

**體態與木刻**：先畫雙手分別接觸上、下顎，再讓寬袖遮掉應被遮的前臂。獅口牙齒保有力量但不血腥；舌、鬃、耳、胸毛分層。主暗面在鬃底、獅腹與白袍側，毛流斜刻不等距刷滿。提案：赭橘獅、苔綠、象牙白與深棕墨。

**現版需修正／驗收**：從摸獅頭改為具體的雙手／獅口關係；獅子不能只剩可愛獅頭。驗收無限符號、花冠、花鏈、兩手與獅顎、四肢及尾巴的歸屬。

### X · 命運之輪 / Wheel of Fortune (`wheel-of-fortune`)

**牌義查核**：S3 轉機、循環、命運、變化；逆位逆境、抗拒、時機未到或失掌控。S1 說明輪的流動與輪上斯芬克斯的平衡，並非單純好運轉盤；S2 的逆位也不等於本案現代關鍵字。

**來源**：[S1 命運之輪](https://sacred-texts.com/tarot/pkt/pktar10.htm)，PDF 第 36 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 中央多環大輪，頂端持劍斯芬克斯；不能用貓取代。 |
| A | 輪左下行的蛇與輪右上升的犬首人身形象：不同方向的變化。後者常稱阿努比斯，造型以附圖為準。 |
| B | 四角有翼活物與各自書本：觀者左上人／天使、右上鷹、左下牛、右下獅。 |
| B | 外輪 T、A、R、O 與神名字母 י、ה、ו、ה 交替：以附圖逐格定位；不鏡像、不用亂碼。 |
| B | 內環水星、硫、鹽、水的煉金符號，以及輪輻與中央結構。 |
| B | 雲層分隔四活物，輪下留轉動空間；斯芬克斯坐在輪上，而非另加一座固定高台。 |

**重畫構圖**：輪佔畫寬約六成，上下行者沿外輪，不壓到字母；四角活物以胸像／頭翼加書本即可，但四者要能清點。小字需完整圖放大後可辨。

**體積與木刻**：斯芬克斯有肩爪，犬首有頸與軀幹；輪厚側和雲底用排線，金屬亮面留紙白。提案：銅金、靛青、赭紅與深藍墨。

**現版需修正／驗收**：撤掉貓，補全外輪文字、內環符號、四活物與書本；驗收數量與方向高於花紋美觀。與世界牌四角的觀者方位保持一致。

### XI · 正義 / Justice (`justice`)

**牌義查核**：S3 公平、真相、因果、責任；逆位偏見、逃責、不公、失衡。S1 是依行為衡量的道德原則，與女祭司的神秘門檻不同。S2 另有法律與過度嚴苛的含義。

**來源**：[S1 正義](https://sacred-texts.com/tarot/pkt/pktar11.htm)，PDF 第 37 頁；S2、S3。編號固定 XI。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 正面清醒的坐者，不蒙眼：有意識地看清並裁決。 |
| A | 人物右手直立雙刃劍、左手持水平天平；觀者看到劍在左、秤在右。 |
| B | 兩只秤盤、完整吊線與橫梁，讓衡量確實成立。 |
| B | 冠上的方形飾、紅袍與內衣、石座台階：秩序與執行的結構。 |
| B | 兩根石柱與後方帷幕，柱間留開口；不借用 B/J 字母。 |
| B | 袍下露出的一隻鞋：身體與地面有接點，非漂浮上半身。 |

**重畫構圖**：劍垂直近畫框，天平在另一側空白區，不讓秤線穿手；主角眼平直視，肩不歪以免無意暗示秤失衡。兩側並非複製鏡像，器物責任不同。

**體態與木刻**：握劍手拇指和護手關係清楚，持秤手真的承吊環。袍褶與石柱轉折加重，劍刃保留一條亮線。提案：暗紅、古金、石灰綠與深紫墨。

**現版需修正／驗收**：從圓頭小人改成有眉骨與骨架的裁決者。檢查未蒙眼、雙刃劍、左右手、兩秤盤、鞋與柱幕，不能誤畫成女祭司持武器。

### XII · 倒吊人 / The Hanged Man (`hanged-man`)

**牌義查核**：S3 暫停、換角度、臣服、放下；逆位停滯、無謂犧牲、拖延、抗拒。S1 明確是生命懸止而非死亡，臉應安然入定而非受刑痛苦。

**來源**：[S1 倒吊人](https://sacred-texts.com/tarot/pkt/pktar12.htm)，PDF 第 38 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 由一腳倒掛於有葉的活木 Tau／T 形架：不是枯木絞架。 |
| A | 頭下腳上、另一腿交疊成角、雙手在背後：整體姿態是牌的識別。 |
| B | 頭部光環與平靜表情：覺察、轉換視角。 |
| B | 掛點、繩與腳踝的真實接觸；不畫頸部繩索。 |
| B | 淺藍上衣、紅腿衣等可辨色塊，頭下方仍有空氣／地面間距。 |

**重畫構圖**：活木橫架橫過上方，人物居中，頭在下三分之一；葉子長在木架上，不是旁邊獨立盆栽。光環不和框線重合。

**體態與木刻**：先畫倒置骨架與被提拉的骨盆，再畫彎腿和背後雙臂；衣服受重力向肩與頭垂，不使用站立者衣褶倒貼。綁腳附近、腰側、木架下方是暗面。提案：灰藍、磚紅、木褐與深藍墨。

**現版需修正／驗收**：保留現有活木／光環意向，但重建全身。檢查單腳、交腿、藏手、活葉、T 架、平靜表情；不要出現第三隻腳、斷腰或處刑聯想。

### XIII · 死神 / Death (`death`)

**牌義查核**：S3 結束、轉變、告別、新生；逆位抗拒、停滯、放不下。S1 使用騎士、玫瑰旗與不滅日光表現轉化；並非所有結束都等於恐怖災難。S2 的歷史占卜措辭更直接，本案不把它用作疾病／死亡預言。

**來源**：[S1 死神](https://sacred-texts.com/tarot/pkt/pktar13.htm)，PDF 第 39 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 披黑甲的骷髏騎士與白馬：不可由站立小骷髏全數替代。 |
| A | 黑旗上的白色五瓣玫瑰：生命與轉化；旗上花必須可讀。 |
| A | 遠方兩塔之間的日光：畫面仍有通往新階段的出口。 |
| B | 地上倒下的王者與掉落王冠、迎向騎士的主教、孩子與年輕女性：不同身分面對同一過渡。 |
| B | 河流及遠處船隻，構成過境的景深，不只一排地上嫩芽。 |
| B | 騎士沒有可見收割武器；不自動加鐮刀，誤混另一套死神圖像。 |

**重畫構圖**：騎士與馬側行，旗在上方留白，右前方人物分高低層。日出安排在馬頭、旗與山之間的獨立缺口；不容旗或斗篷遮掉大半。

**體態與木刻**：白馬先驗骨架、頸背與四肢，再加甲騎士；骷髏有頭顱與顎骨，不用笑臉骨面具。黑甲用白色刀痕，白馬以肩腹暗面刻線，遠人降低細節但保留身份道具。提案：骨白、黑藍、淡金與灰綠。

**現版需修正／驗收**：原「拿花的斗篷骷髏與嫩芽」不足以承載完整 RWS 敘事，改回騎士場景。清點馬、旗、五瓣花、四類人物、王冠、雙塔日光、河船；不血腥也不能省到只剩一朵花。

### XIV · 節制 / Temperance (`temperance`)

**牌義查核**：S3 平衡、調和、耐心、適度；逆位過度、失衡、急躁或不協調。S1 是兩端生命本質的調和，人物帶超越性別的安定，並非調酒表演。

**來源**：[S1 節制](https://sacred-texts.com/tarot/pkt/pktar14.htm)，PDF 第 40 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 有翼人形，以兩只杯讓水連續流轉；兩杯與水線均不可少。 |
| A | 一足在地、一足在水：跨兩種領域的實際接觸。 |
| B | 額頭日輪標記、胸前方形內三角：符號須與布料紋理區分。 |
| B | 岸邊鳶尾、水面與通往遠山的小路：自然、過渡與方向。 |
| B | 山端明光中的冠形：遠方目標，不是無關太陽表情。 |
| B | 紅色／深色大翼與白袍：翼根從背部起，不是從手腕長出。 |

**重畫構圖**：天使略偏右，雙杯在胸前形成斜線，腳下岸線橫向切過一足；小路在左側空區連到山冠。水流可有寓言式不尋常角度，但必須可追蹤由杯口到杯口。

**體態與木刻**：先畫平衡重心、兩肘與握杯手，確保杯沿和指節不混成同一輪廓。翅膀羽軸有結構；袍內褶、翼根與岸下排線較重。提案：水綠、赭紅、淡金與深青墨。

**現版需修正／驗收**：補足日輪、胸徽、遠山冠和鳶尾。用水線追蹤、兩杯清點、腳踩介面測試，避免水穿杯底、腳不接地或遠側手憑空出現。

### XV · 惡魔 / The Devil (`devil`)

**牌義查核**：S3 束縛、慾望、執著、誘惑；逆位覺察與解脫。S1 的受縛者仍有人的理智，不是永遠不能離開；S2 歷史逆義不同，不把本案逆義寫成古典唯一解。

**來源**：[S1 惡魔](https://sacred-texts.com/tarot/pkt/pktar15.htm)，PDF 第 41 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 有羊角、羊面、蝙蝠翼的惡魔在黑色台座上，腳下兩位有人性表情的受縛者。 |
| A | 台座環扣接出兩條鏈，繞到兩人頸部；頸圈寬鬆可解脫，是本案解讀重點。 |
| B | 額上倒五芒星，方向必須朝下；不能沿用正向幸運星。 |
| B | 人物自己的右手舉起、左手持倒向地面的火炬，和教皇的祝福形成反向呼應。 |
| B | 兩受縛者有角與尾：一端果實、一端火焰的差異要清楚。 |
| B | 附圖的台座、獸足與黑暗背景；Waite 另提腹部水星記號，列為文字來源細節，採用時需做小符號局部，不誇張成主徽。 |

**重畫構圖**：惡魔上方為倒三角，兩人構成下方對子；鏈條在亮地帶，可一眼追到兩個頸圈。借用戀人的位置關係，讓自由與執著形成組內對照。

**體態與木刻**：羊面、蝙蝠翼膜、獸爪各有真實構造；兩人的手腳不能被鏈誤當肢體。暗背景與黑翼以留白刻線、毛皮用短斜刀，火炬留亮。提案：炭黑、暗紫、銅紅與霧金。

**現版需修正／驗收**：去掉得意可愛小惡魔感，保留人性而非獵奇；兩鏈、兩頸圈、兩種尾端、倒五星、反向手勢與倒炬逐項核對。恐怖氣氛不靠血腥。

### XVI · 高塔 / The Tower (`tower`)

**牌義查核**：S3 突變、瓦解、覺醒、重建；逆位延遲崩解、壓迫或內在震動。S1 是虛假／僵固結構被撕裂，S2 強調非預期災變。畫面要有震裂，不能只剩玩具積木掉落。

**來源**：[S1 高塔](https://sacred-texts.com/tarot/pkt/pktar16.htm)，PDF 第 42 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 高處石塔遭閃電擊中，塔體有斷裂與窗火；閃電接觸點可追蹤。 |
| A | 塔頂皇冠被震飛：權威／防護失去原位，不能留在塔上當固定屋頂。 |
| A | 兩位墜落者位於不同方向：不是一個小人和幾塊石頭。 |
| B | 兩側二十二枚火舌／Yod 狀火滴，依附圖分成十二與十的兩組；不能隨機少畫成五顆。 |
| B | 暗雲、黑夜、峭岩基座與局部碎石，強化高度和突然性。 |
| B | 墜落者衣裝／頭飾與姿勢有差異，保留人的驚愕與失去重心。 |

**重畫構圖**：石塔偏中軸，閃電走斜線，皇冠和兩人形成散開的三角。先排好二十二火滴的位置，再安排雲與碎石；不能把火滴誤當普通星點。

**體態與木刻**：墜落者仍有胸腔、骨盆和四肢，不畫成細棍散件；碎石與斷面符合塔的結構。塔側密斜刻、雲底交叉刻、雷擊處留白；避免整張黑成一塊。提案：墨黑、石灰藍、朱紅與硫黃。

**現版需修正／驗收**：積木塔換成石砌高塔；清點兩人、飛冠、二十二火滴、閃電與斷裂。倒轉檢查仍可讀為失去結構，而非畫錯的斜塔。

### XVII · 星星 / The Star (`star`)

**牌義查核**：S3 希望、療癒、信任、靈感；逆位失信、受阻、自疑。S1 除希望，更強調自由流出的生命之水與無遮蔽的真實；S2 同時保留失落與希望兩種歷史說法，不可只引用其中一種當全部。

**來源**：[S1 星星](https://sacred-texts.com/tarot/pkt/pktar17.htm)，PDF 第 43 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 一顆大八芒星、七顆小八芒星：總計八顆，不以四角閃光混充。 |
| A | 女性人物持兩只壺，水分別流向池塘與土地；不是一只澆花壺。 |
| A | 人物一膝在地、另一足接觸水面，身體跨在兩個領域。 |
| B | 土地上的水分成五道支流；池塘水流形成同心漣漪。 |
| B | 後方樹／灌木上一隻鳥、遠丘及自然植被：生命恢復的環境。 |
| B | 坦露、安靜的古典人物，非性感姿勢；不把星星種進土裡代替天空星群。 |

**重畫構圖**：大星位於上方稍偏左，人物跪在右下，兩壺分向左右下；鳥樹置於遠側。五支地流水線先畫，再在間隙放草。星群與人物頭之間留空，不變成冠冕。

**體態與木刻**：肩、肘、腕與壺柄分開，重心落在膝與足。土壤刻線沿水道，水面水平刻線，身體暗面柔曲排線；天空比月亮明亮，但主輪廓同樣有份量。提案：湖青、淡金、鼠尾草綠與深藍墨。

**現版需修正／驗收**：徹底改掉「替地上星星澆水」構圖，恢復雙壺／雙流向。逐項數 1+7 八芒星、兩壺、五支流、鳥、膝與足；水不能穿壺或從手心流出。

### XIX · 太陽 / The Sun (`sun`)

**牌義查核**：S3 喜悅、活力、清晰、成功；逆位短暫低潮、延遲或過度樂觀。S1 強調直接之光與孩子的純真，與月亮的反射光構成對照；S2 的逆位常是較弱的同類好意。

**來源**：[S1 太陽](https://sacred-texts.com/tarot/pkt/pktar19.htm)，PDF 第 45 頁；另對照 Part I 的直／波交替光芒說明；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 有臉的大太陽與交替的直／波形光芒；按附圖保留放射節奏，不改成普通四角星。 |
| A | 自然、非情色的孩子坐在白馬上：生命力與坦誠，不是站地上揮旗的小角色。 |
| B | 紅色大旗、完整旗杆與持握關係；旗不是額外背景布。 |
| B | 孩子花冠／羽飾與張開的姿態：喜悅、信任與自由。 |
| B | 圍牆上方四株向日葵及其莖葉，形成有界的花園。 |
| B | 牆磚、遠景與白馬步姿，馬不戴過度控制性的裝備。 |

**重畫構圖**：太陽佔上三分之一，兒童／白馬在下半部，旗往右上延伸但不遮日面。四向日葵沿牆清楚錯開。太陽光芒的每段照附圖畫入向量草圖，不能在成品臨時省略；不為光芒數字附會無來源的牌義。

**體態與木刻**：白馬是本張最高結構風險，先驗步態、前後腿與頸背；孩子骨盆確實坐在馬背，不浮坐。白馬腹部、旗褶和牆側有明確排線，白馬受光面大留白。提案：日金、朱紅、橄欖綠與深赭墨。

**現版需修正／驗收**：恢復白馬與騎乘兒童，向日葵改回四株；太陽表情清明而不搞笑。清點孩子、白馬、紅旗、四花、牆、頭飾與直波光芒，和月亮並排看明暗及主題差異。

### XX · 審判 / Judgement (`judgement`)

**牌義查核**：S3 覺醒、召喚、重生、清算；逆位自疑、逃召、自責或遲疑。S1 是回應更高召喚的整體轉化，不是天使在開派對，也不只有外界對人的懲罰。

**來源**：[S1 審判](https://sacred-texts.com/tarot/pkt/pktar20.htm)，PDF 第 46 頁；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 雲中有翼者吹響號角，號角與嘴、雙手的接觸成立。 |
| A | 地／水際開棺而起的人群，以共同回應表現重生；箱子必須讀成開放棺槨。 |
| B | 號角垂掛白旗及紅十字，方向跟著旗布，不能丟掉十字。 |
| B | 前景三人：觀者左成人男性、右成人女性、中間背向觀者的孩子；遠處另有呼應的人群。 |
| B | 起身者的仰望、張臂與敬畏，不是各做無關手勢。 |
| B | 水域／谷地、遠山與雲帶，串連上下兩界。 |

**重畫構圖**：上方天使與斜號角，下方以前三後三等遠近分組處理；保留多於三人的整體回應，但遠人可小輪廓化。讓紅十字旗落在空區，號口不要被羽翼擋住。

**體態與木刻**：吹奏者的手、嘴、號角先做局部驗證。下方人物有不同胸腔、肩寬與手掌；棺壁透視和站起的骨盆位置相符。雲底、翼根、棺內及山側加重排線，裸身用古典明暗。提案：灰藍、骨白、深紅與墨紫。

**現版需修正／驗收**：箱子探頭小人改為起身人群，補旗十字與遠景呼應者。天使慣稱加百列不當作原典明說；驗收嘴號、手號、旗、前三人方位、中間背影、遠人與開棺。

### XXI · 世界 / The World (`world`)

**牌義查核**：S3 完成、整合、圓滿、旅程；逆位未竟、缺收尾、停滯。S1 是整體秩序與完成後的生命狀態；不是在花圈中加一個開心角色就成立。

**來源**：[S1 世界](https://sacred-texts.com/tarot/pkt/pktar21.htm)，PDF 第 48 頁；並讀 Part I 對橢圓花環及四活物的補述；S2、S3。

| 等級 | 必畫元素與意涵 |
|---|---|
| A | 中央有身體重量與舞姿的人形，雙手各持一杖；不是只持兩顆星。 |
| A | 完整橢圓月桂花環包圍人物，與人物之間留空。 |
| B | 花環上、下紅色繫結，連續環形不變成散落幾何符號。 |
| B | 人物彎曲交疊的雙腿及飄帶，動中有平衡；和倒吊人的交腿形成組內呼應。 |
| B | 四角雲中的活物：觀者左上人／天使、右上鷹、左下牛、右下獅；與命運之輪相同方位。 |
| B | 古典坦露與繞身布帶；四活物是有體積的生物頭／翼，不是四個表情貼圖。 |

**重畫構圖**：月桂環佔畫面約八成高，四角活物在環外，中央人形長而不擠滿；雙杖與花環不相切。布帶走 S 線但不遮掉雙杖及交腿。

**體態與木刻**：先驗骨盆方向、承重／交疊腿與肩軸，舞者不是被吊住；環葉有枝條方向。身體背光用弧形短排線，葉背與雲底密刻，四活物輪廓重於細紋。提案：月桂綠、灰紫、朱紅與深藍墨。

**現版需修正／驗收**：恢復月桂環、紅結與雙杖，去掉以隨機星／圓／三角串成環的做法。清點四活物及固定方位、兩杖、上下結、完整環、交腿與飄帶，確保與命運之輪同族但不重複構圖。

## 6. 技術落地與交付流程

1. 每張新建 `src/print/<card-id>.js`，輸出 `<name>Plates(card)` 與插畫色盤；使用 `printFrame(card)`，以 `FO/FN` 固定外框色印製。不要為了單張新色盤修改全域 `INKS`。
2. 建立新版正面登記表，明列 `legacy / sample / approved / integrated` 狀態、色版、種子、資產與偏離紀錄。未確認樣張保留舊圖可切換，不能靠檔名猜哪版已上線。
3. 先輸出 PNG 再接正式 UI，避免每次展牌都跑多張高解析逐像素印刷。海報讀同一組來源／固定種子，不能畫面看新版、下載卻是舊 SVG。
4. 每張都提供舊圖、隱者參照、完整新圖、120px、主要手／動物／器物局部；此階段不必一次替換整副。
5. 圖稿驗收後再接正式 `app.js`、`poster.js`、圖鑑與分享圖。九款牌背的選擇器是另一項工作，不能把「收藏預覽已有九款」寫成「抽牌已能切九款」。
6. 必要技術驗證：牌圖可載入、沒有 NaN／undefined、固定種子穩定、正逆位方向、單／三張、鍵盤、手機選牌、下載與分享海報。語意驗收仍須人工逐項點數，不用「所有牌面有輸出」測試冒充。
7. 最終校對整組角色的頭身、眼鼻風格、線粗、暗部比例、紙色、框色及字體。可以各有色盤，不能每張像不同產品。

## 7. 既有兩張的符號修訂（不算進本次 20 張）

2026-11-16，依使用者同意進行下列修訂；保留修訂前色版，供 `symbol-review.html` 比較。

- **隱者**：燈內火焰已改為六芒星；提燈及握燈手向外略移並抬高，燈身維持直立。保留寬袖、既有頭部輪廓及被身體遮住的遠側握杖手，沒有另加穿過身體的手臂。
- **月亮**：月面明亮部分改至觀者右側，只有月面本體翻向，雙塔和地景不翻轉；光芒為十六道主芒＋十六道副芒，十五露滴保留並避開光芒；犬與狼頭頸微仰，腳掌／坐姿保留。側臉、狗狼與光芒仍需最終美術確認，不將符號數量通過等同於整張圖已定稿。
