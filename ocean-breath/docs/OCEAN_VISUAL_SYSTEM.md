# 海洋視覺系統

## 美術語言

延續 laundry-weather、stamp-tour、retro-printer：極簡幾何、大面積純色色塊、有限色盤、少量印刷感。

- **純色，不用漸層**。天空是兩塊色：大片天色＋貼地平線的一條寬帶。
- **山用受光面表現體積**：每座峰頂右側（或左側）一塊三角形，是淺色半透明色塊，不畫陰影漸層。
- **網點只用在一兩處**（例如花蓮最前面那道山脊的背光面、澎湖台地的側面），30° 斜網、低透明度。
- **錯版**：太陽有一個略微位移的第二色圓（multiply 混色）；大字標題有粉紅與藍兩層位移字影。
- **紙張顆粒**：整頁一層 180px 的雜點，multiply、低透明度。
- **波峰亮線**：每道波浪上方一條斷續的淺色線，像多印了一版。

UI 也延續同一套：暖灰紙底、白紙卡、圓形小鈕、SVG 線條圖示（沒有 emoji），沒有裝飾性文字與眉標，能用圖示表達的地方不寫字。所有選擇（展示情境、圖片方向、時間範圍）都是自製的分段按鈕，沒有原生 select／radio／checkbox／alert／confirm。

## 色彩系統

`src/palettes.js`：每片海一組白天與夜晚的完整色盤，晨昏只換天空三色（天色、地平線色、太陽），其他由日夜色依比例混合再帶 10% 天光。所有色塊以 `fill` 屬性寫入、CSS 以 5 秒過渡，天色變化不跳。

| 海岸 | 色彩性格 |
| --- | --- |
| 花蓮 | 霧青綠 × 米白 × 陶土紅：低彩度的海，陶土色太陽與幾顆石頭點綴 |
| 宜蘭 | 湖水綠 × 乳黃 × 深藍灰：清爽，龜山島是最深的一塊 |
| 基隆 | 粉灰 × 深酒紅 × 奶油白：復古海報，燈塔的酒紅條紋 |
| 淡水 | 淡薰衣草紫 × 午夜藍 × 米色：暮色感，觀音山是午夜藍 |
| 台南 | 淺橄欖綠 × 炭黑 × 珊瑚粉：實驗性的平面設計，炭黑細線的蚵棚 |
| 澎湖 | 灰紫 × 芥末黃 × 深墨綠：沉靜神祕，芥末色的台地頂與被風吹斜的草 |

海溫只帶來最多 6% 的冷暖色偏，是溫度感，不是溫度圖。

## 場景構圖

圖層順序（`src/scene.js`）：天空 → 星星 → 日月（裁在地平線以上）→ 雲 → 遠景 → 海面（底色＋四道色帶＋波峰亮線＋浪花）→ 反光 → 海中物件（會被淹的礁石、木樁、蚵棚）→ 岸 → 潮間帶（裁切在岸的形狀內）→ 湧浪 → 前景 → 海鳥。

| 海岸 | 遠景 | 潮汐會改變的東西 | 前景 | 專屬微動態 |
| --- | --- | --- | --- | --- |
| 花蓮 | 三層中央山脈落進海裡 | 礁石露出程度、礫石灘寬度、潮線附近的石頭 | 圓滾滾的礫石、濱草 | 海鳥較常出現 |
| 宜蘭 | 龜山島（龜殼、龜首、龜尾）與北邊淡淡的海岸 | 沙灘寬度、沙紋 | 沙丘、濱草、貝殼 | 一道道平行白浪由遠而近 |
| 基隆 | 基隆嶼、右側山、防波堤與紅白燈塔 | 蕈狀岩的柱身、豆腐岩一格格露出 | 岩角 | 燈塔閃光，夜晚有光束 |
| 淡水 | 觀音山與八里小屋 | 舊碼頭木樁、泥灘 | 紅樹林、蘆葦 | 小船極慢地漂（裝飾） |
| 台南 | 很低的地平線、城市與樹林剪影 | 沙洲浮出、蚵棚竹樁、潮間帶沙紋與水窪 | 白鷺鷥 | 白鷺鷥偶爾低頭 |
| 澎湖 | 小島與白燈塔、玄武岩柱狀台地 | 台地腳下的水位、石滬（退潮才現形） | 小坡、石塊、被風吹斜的草 | 草擺動比其他地方大 |

**直式（手機）不是縮小**：每片海的 `layout()` 依 `tall` 另外安排地平線、山與島的寬度、岸線高度與前景位置，讓岸邊出現在資訊卡上方，像一張獨立的直式海報。分享圖也用同一套重新排版。

## 動畫規則

三種時間尺度：

1. **潮汐（數小時）**：只改岸線位置、潮間帶露出範圍、物件的淹沒程度。以真實時間計算，不加速；半小時內只看得出輪廓慢慢改變。
2. **海面起伏（數秒）**：每道波浪是兩組不同波長、反向移動的波，波峰較窄、波谷較寬，再乘上一層緩慢的雜訊包絡，讓浪有大有小；每道色帶的上下起伏有相位差，形成由遠而近的湧浪。
3. **細節**：浪花（只在最近兩道、浪大的波峰）、湧上岸又退去（快上慢退）、濕沙痕、反光閃爍、日月的海面反光帶、星星。

其他規則：

- requestAnimationFrame，上限每秒 30 格；分頁在背景時停止動畫與輪詢。
- `prefers-reduced-motion`：只畫一張靜態海景，資料更新時重畫。
- 資料改變時參數用約 2.5 秒的時間常數過渡，不跳；拖曳時間軸時直接到位。
- 切換海岸：新的一片海淡入並微微滑入（1.6 秒），舊的淡出後移除。
- 海鳥一次一到兩隻，白天與晨昏才有，間隔 30–140 秒。

## 資料映射（`src/visual.js`）

| 資料 | 畫面 | 限制 |
| --- | --- | --- |
| 潮汐預報（相鄰滿乾潮的視覺插值） | 岸線位置、潮間帶、淹沒程度 | 0–1 正規化；當天潮差 / 平常潮差 調整幅度（0.6–1.15）；資料不足時停在中間 |
| 潮位觀測（預報範圍外） | 同上 | 以前後一天的實測高低正規化 |
| 浪高 | 波浪幅度、浪花多寡、湧浪距離 | 0.18 + 0.82 × (1 − e^(−h/1.5))，最大 1；沒有資料時 0.32 |
| 波浪週期 | 起伏與湧浪節奏 | 5–14 秒；沒有資料時 8 秒 |
| 風速 | 雲的速度、草的擺動 | 1 − e^(−w/7) |
| 海溫 | 海面極小色偏 | ±6% |
| 當地時間＋經緯度 | 天色（夜／晨／日／昏）、日月位置 | 太陽高度角 −8° 與 10° 分界；日月位置依方位角相對海岸面向換算 |

潮汐系統與波浪系統互相獨立：浪高不會改變水位，潮位不會改變浪的大小。
