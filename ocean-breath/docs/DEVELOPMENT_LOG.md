## 重要技術決策

- **SVG + 少量 JS**，沒有 Canvas 與 3D。每格只改四道波浪、浪花、湧浪與雲的屬性；潮線只在水位變化時重算。
- 顏色用 `fill` 屬性而非 CSS class，分享圖直接序列化 SVG 就有正確顏色。
- 潮汐與波浪兩套參數獨立。插值水位只用在畫面，不顯示成數字。
- 潮位不跨站遞補；觀測潮位與預報潮高不相減。
- 伺服器沿用 laundry-weather 的模式：公開檔案白名單、CSP、上游錯誤不帶網址與金鑰。

## 已知限制

- 未以真實金鑰驗證 REST 端點（見上）。
- 月亮位置是用月齡粗略推算，形狀（月相）是準的，位置只是大概。
- 日出日落用簡化公式，誤差約一兩分鐘。
- 30 天歷史需要時間累積；GitHub 排程可能延遲。
- 長時間播放只在瀏覽器裡觀察數分鐘，沒有做數小時的記憶體量測。
