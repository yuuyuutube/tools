# INK INK｜工作室 NPC 角色個性提案

更新日期：2026-11-14

這份文件保存本次討論的三位角色：絹印師傅、墨團學徒、隔壁桌常客。內容包含個性、說話方式、台詞、互動構想，以及目前的 SVG 造型版本，方便之後考慮是否加入 `/tools/retro-printer`。

目前使用者喜歡三位角色及個性提案，仍在考慮如何採用。**造型試作已完成；角色是否加入正式網站、出場位置與互動範圍尚未定案。** 下列互動都屬於提案，不代表正式網站已經實作。

## 一、角色在這個作品裡的價值

INK INK 的核心是親手完成絹印：選圖、製版、選墨與調墨、選媒材、對位、刮印、掀框、等乾，最後帶走自己的作品。

角色可以讓這個體驗多出「走進一間有人生活的工作室」的感覺。他們各自有工作、喜好與創作，也能讓使用者在調墨、等乾與欣賞成品時，發生一點自然的小交流。

與 `/tools/stamp-tour` 的站務員相比，三位角色可以有自己的節奏。站務員熱情地接待旅客、帶活動、慶祝；工作室裡的人則可以安靜一些、有自己的私心，想聊天時再靠近。

| 角色 | 個性的核心 | 帶來的體驗 | 最自然的交流時機 |
| --- | --- | --- | --- |
| 絹印師傅 | 對墨水很龜毛，對客人很寬容 | 職人的溫度、被認真對待的感覺 | 調墨、等乾、完成後 |
| 墨團學徒 | 明明自己就是墨，卻很想學會印刷 | 童話感、材料與創作的情感連結 | 選色、調墨、成品揭曉 |
| 隔壁桌常客 | 每天都來，永遠在印奇怪的東西 | 陪伴感、荒謬幽默、持續發展的小故事 | 等乾、主動閒聊、再次遇見 |

## 二、01 絹印師傅

### 一句話設定

**一位對墨水很龜毛、對客人很寬容，默默收集所有試印紙的絹印師傅。**

### 個性與反差

初看像是一位嚴格的職人，接觸後才發現，他很珍惜印歪、混色與試印時意外出現的圖案。

他的原則是：**材料和工具要好好照顧，但作品可以自由發生。**

他有自己的收藏、創作與審美。客人的作品讓他想起什麼，他就說一點；有時也只是把東西放好、替你找一個好位置。

他特別偏愛群青，卻努力假裝自己很客觀。這個小私心可以在選色時偶爾露餡。

### 說話方式

- 短句、平淡、留一點空白。
- 親切藏在具體的小動作與觀察裡。
- 不需要一直讚美，也不把每一張作品分成好壞。
- 分享自己的經驗時，偶爾有一點認真的荒謬感。

### 台詞提案

| 時機 | 台詞 |
| --- | --- |
| 選了群青 | 「嗯。這個好。」 |
| 後來換成別色 | 「……這個也好。」 |
| 調墨還沒有攪勻 | 「這樣會有色紋。喜歡就留著。」 |
| 等乾時拿出自己的試印紙 | 「這張原本是拿來墊桌子的。後來捨不得。」 |
| 一直按吹風機 | 「急著帶回家啊。」 |
| 完成一張作品 | 「要再印一張嗎？同一個版，也不會印出一樣的。」 |
| 展示一張奇怪的試印紙 | 「本來要印一隻鳥。網框放反了。現在是別的東西。」 |
| 把使用者的作品掛到牆上 | 「這裡光比較好。」 |

### 招牌互動：寶貝廢紙

使用者點他，他拿出一張自己珍藏的試印紙，說一句短短的來歷。

一張紙、一個小故事，讓人慢慢認識他的創作與喜好。原本拿來墊桌子的紙，或是放反網框的試印，都可能成為他捨不得丟掉的收藏。

這些紙也可以延續 INK INK 原本的印刷語言：疊色、錯位、飛白與意外構圖。

### 招牌場面：幫作品找一個好位置

使用者完成作品、回到入口，發現師傅已經把它掛到作品牆上。點他，他看了一眼，只說：「這裡光比較好。」

這個場面是讓角色替既有的作品牆增加人味的提案，尚未加入正式流程。

### 目前造型與動態

- 群青工作帽、花白鬢角、臉頰的一小塊藍墨。
- 保留站務員畫風的圓潤臉型、小圓點眼睛與簡單色塊。
- 依使用者調整：加上小灰鬍子，移除嘴巴。
- 在角色預覽裡，說話時小鬍子輕輕上下動，結束後回到原位。
- SVG：[print-master.svg](./print-master.svg)

## 三、02 墨團學徒

### 一句話設定

**一小團很想學會印刷的墨，認真、愛逞強，明明自己就是墨，還很努力研究墨水。**

### 個性與願望

它留在調墨台旁，對顏色、混色和印出來的東西充滿好奇。它會低頭研究自己的身體，也想知道自己最後會變成什麼作品。

它最可愛的願望是：「我以後也要變成一張作品。」

### 說話方式

- 直接、認真、帶一點天真的自我觀察。
- 對自己的顏色與條紋很有意見。
- 想參與創作，喜歡發現自己跟作品之間的關係。

### 台詞提案

| 時機 | 台詞 |
| --- | --- |
| 身體隨選色改變 | 「原來今天我是這個顏色。」 |
| 混墨還留有色紋 | 「先別攪，我覺得這條紋很好看。」 |
| 看見使用者刮印 | 「我以後也要變成一張作品。」 |
| 完成作品、發現相同顏色 | 「這次有我的顏色耶。」 |

### 招牌互動：身體反映正在調的墨

選粉紅，它就變成粉紅；混得不勻，身上就留下條紋。它看著自己的身體，對當下的材料狀態說一句話。

這可以讓「選色」多出情感連結，也讓混色狀態變得容易感受。目前預覽只展示固定的紫色身體與混色色紋，**尚未連動正式網站的選色、調墨資料**。

### 美術方向與目前造型

- 平面色塊、疊色與簡潔五官，跟 INK INK 的印刷語言一致。
- 使用者希望是毛球形狀；已把初稿偏火焰、墨滴的輪廓改成**圓蓬蓬、四周有短毛邊的毛球**。
- 目前是紫色毛球，身上帶粉紅與群青的混色色紋。
- SVG：[inkling.svg](./inkling.svg)

### 採用時的考量

這位角色會為工作室加入比較明顯的童話感。如果希望保留接近真實設計工作室的氣質，可以先比較它與師傅、常客各自帶來的氛圍，再決定出場程度。

## 四、03 隔壁桌常客

### 一句話設定

**跟你一起使用工作室、每天都來，卻永遠在印奇怪東西的文青長髮男。**

### 個性與創作動機

他知道一點技術，但最在意的是自己的荒謬創作計畫。你在印你的作品，他也在做自己的事情。

例如，他已經連續來了一星期，只為了印一件寫著「今天沒有特別的事」的 T 恤。

他的幽默來自一本正經地投入很奇怪的創作，生活裡也有朋友、送禮與作品的後續。

### 說話方式

- 自然、平靜，把荒謬事情當成正常的創作近況。
- 有一點文青感、慢悠悠的節奏。
- 可以隨著再次遇見，接續上次提過的事情。

### 台詞提案

| 時機 | 台詞 |
| --- | --- |
| 分享今天的創作計畫 | 「我今天要印一張海報，通知大家我沒有事情要通知。」 |
| 展示準備送人的作品 | 「這張是送朋友的。他還不知道自己需要它。」 |
| 問他怎麼還沒印完 | 「我在等墨乾。順便想一下人生。」 |
| 第二次聊到上次的禮物 | 「上次那張送出去了。朋友說謝謝，但語氣有點疑惑。」 |

預覽頁為了呈現短句節奏，部分句子有縮短；以上保存最初的完整台詞提案。

### 招牌互動：等乾時的隔壁桌聊天

使用者自己印自己的，想聊才點他。他偶爾展示一張自己的進度，讓人記得工作室裡也有另一個人在創作。

如果日後加入連續小故事，可以從「今天要印什麼」發展到「印完了沒有」「送出去之後對方的反應」。

### 目前造型

- 粉紅針織帽、帶一點微捲的長髮、雙眉、歪歪的笑。
- 臉型依使用者要求，改成略方的圓角矩形，不必完全沿用站務員的包子臉輪廓。
- 沿用同一套簡單色塊與小五官畫風。

### 三種瀏海版本

三款都是**同一位角色的造型候選**，不代表三位不同的常客。原版完整保留，尚未選定最後使用哪一款。

| 版本 | 造型特徵 | SVG |
| --- | --- | --- |
| 03A 原版 | 雙眉、雙眼露出，微捲長髮 | [studio-regular.svg](./studio-regular.svg) |
| 03B 遮一眼 | 斜側的微捲瀏海，遮住畫面左側的一隻眼睛 | [studio-regular-one-eye.svg](./studio-regular-one-eye.svg) |
| 03C 遮雙眼 | 厚厚的波浪瀏海遮住雙眼，下方仍露出笑嘴 | [studio-regular-both-eyes.svg](./studio-regular-both-eyes.svg) |

兩款新瀏海以實際的 SVG 圖層遮住眼睛；開心表情也會被瀏海覆蓋。

## 五、當時的推薦組合與嘗試方式

最初的推薦是：**以絹印師傅為主要角色，把一點常客式的荒謬感放進他的收藏故事裡。** 這是提案建議，使用者尚未決定採用方式。

若之後想先試一小部分，可以從「等乾時出現」和「完成後留一句話」開始，感受角色是否讓人更想待在這間工作室。

如果選擇同時保留三位，他們各自已經有不同的交流重點：師傅分享材料、收藏與經驗；墨團關注顏色與成為作品的願望；常客談自己的創作近況。出場安排仍需另外討論。
